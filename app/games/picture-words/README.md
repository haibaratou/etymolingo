# Pictlingo

画像から文字をつないで、英語または確認済みの日本語の読みを答えるパズルです。
入口は `../picture-words.html`。リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。

## 画像・解説・出題言語は別々に判定

- `catalog.js` は現在のPNG画像をすべて保持します。解説未作成、読み未確認、古い更新日を理由に画像をカタログから削除しません
- 正確な単語・画像の対応が確定した行だけが出題候補です。別画像、対応未確定、個別の不一致を保留した画像は詳細を閲覧できますが出題しません
- 英語の現在の文字盤対応は英字1〜14文字です。大文字の原表記を保持し、一文字の `I` と `a` にも対応します。長い語や空白・記号などを含む語はカタログに残し、形式未対応と表示します
- 日本語は `availability.ja.playable` と確認済みのかなの答えに従います。候補読みや未確認読みを推測して使用しません。英語のみの問題でも同じ画像を維持し、日本語への切替は無効にします
- 解説の `reviewed` / `missing` / `stale` / `held` は出題可否と別です。正解時に確認済み解説だけを表示・読み上げます。それ以外は `解説未作成` と表示し、語義や見出し語で解説を代用しません
- 「聞く」は利用可能な選択言語の単語発音です。解説の自動音声とは独立し、文字や答えを開示しません

## 正確な画像と直接リンク

- HTTPS/localhostでは、正本語彙と索引のバインディングを確認し、選択したPNGの署名・SHA-256・Git blob SHA-1を検証してから遊べます
- 解説データだけが更新された場合、画像は利用可能なまま古い解説の表示・音声を止めます。画像または語彙・索引が変わった場合は読み込みエラーを明示します
- `file://` では確認済み解説の遅延画像パックをハッシュ検証します。それ以外は対応するローカルPNGを必要時に読み込みます。この場合に画像ハッシュや解説を確認済みと称しません
- URLは `?word=<正確なID>` または `?word=<正確なID>&lang=en|ja`。言語省略時は英語です。未知ID・不正な重複パラメータ・利用不可の言語はエラーを表示し、別の問題へ自動置換しません
- 画像ファイル名と安定IDは別です。同じ綴りの語もIDで区別し、画像URLは各パス要素をエンコードします

## 操作と保存

文字を隣接マスで一筆につなぎます。「まぜる」「答え」「聞く」、日別の獲得ページ、辞書の検索・48件ページ切替、難易度、音声、テーマ、レイアウトを保持しています。正解後は従来の「次」から進めます。

保存キーは `word-bloom-v1`。星、回答履歴、日別発見、既存IDを保持し、未出題や保留の行の保存記録を削除しません。保存できない環境でも遊べます。音声は端末の音声合成を使います。

オフライン保存は利用者が明示した時だけ、既存のハッシュ検証付き画像パックを最大20件・4.5MB以内で保存します。パックのない画像を保存済みとして扱いません。過去の保存キャッシュは削除しません。

## 再生成と検証

共通画像カタログの正本は `app/data/build_generated_image_catalog.py` です。出力の更新は次を使います。

```sh
python app/games/picture-words/refresh_reviewed_catalog.py
python app/games/picture-words/refresh_reviewed_catalog.py --check
node --check app/games/picture-words/game.js
node --test app/games/picture-words/*.test.cjs
```

`reviewed-scenes.js` は画像構造の検証、言語対応、実際のPNGバイト検証、解説の独立判定を担当します。`difficulty.js` は並び・難度・セーブ移行、`gesture.js` は文字盤、`progression.js` は獲得履歴、`pronunciation.js` は音声、`offline.js` は明示保存を担当します。画像や正本辞書はランタイムで変更しません。
