# WORD BLOOM / ことばの庭

一枚のイラストを見て、円形の文字盤をなぞって答えるパズル。
入口は `../picture-words.html`。既存ゲームやサイトの入口は変更しない独立版です。

## 遊ぶ

リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、
`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。
出題データは通常の JavaScript として同梱しているため、HTML を直接開いても読み込めます。
画像は既存の `assets/word/` を相対参照します。ビルドや外部サービスは不要です。

- 日本語（ひらがな）・英語（アルファベット）各60問、10問ずつ6つの庭。
- 指を離すと判定。戻ると選択を取り消し。同じ文字は別の丸を使います。
- タップ、キーボードの Tab / Enter / Backspace でも操作できます。
- 並べ替え、無料の一文字ヒント、任意のステージ選択、日英対訳のコレクション。
- 誤答やヒントがなければ星3つ。ヒント・誤答ありは星1〜2つ。ベスト結果を保持。
- 言語ごとの進行と効果音の設定を `word-bloom-v1` にローカル保存。
- Web Audio の音階・和音、選択時の弾み、光る軌跡、文字の飛翔、花びら。
- `prefers-reduced-motion` では動きを抑制。効果音はユーザー操作から開始。
- イラスト読み込み失敗時は再試行または次の絵に移れます。

## データの由来

参照は `app/games/word-suika_jp.html` と、その出題元
`app/data/generated-etymon/word-suika-ja.json`。
`build_catalog.py` の `CHOICES` は **読みと画像識別子のペア**で語義を選びます。
`w`（読み）・`ja`（表記）・`pic`（画像識別子）は元データの値をそのまま保存。
絵を目視確認した身近な名詞60語に絞っています。
英語の答えは今回選んだ画像識別子に一致する名詞です。

たとえば参照辞書の「にじ」は `second`、「かえる」は `return` に対応するため、
虹・蛙の問題としては使っていません。同綴り・同音の別義を自動採用しないでください。
元の画像や語源データは変更しません。`app/data/pie/` を読む必要はありません。

出題データを更新するときだけ、参照辞書を用意して実行します。
（このPRのベースに参照辞書がない場合も、ゲームは同梱 `catalog.js` だけで動作します。）

```sh
python app/games/picture-words/build_catalog.py --dictionary path/to/word-suika-ja.json
```

## 実装と確認

- `game.js`：状態遷移、Pointer Events、効果音、描画、保存、言語切替。
- `gesture.js`：高速スワイプの線分判定と選択・取り消し。移動イベント間の文字も拾います。
- `style.css`：PCは左右2列、スマートフォンは縦1列。
- `catalog.js`：レビュー済みの辞書抜粋。実行時に大きな辞書を読み込みません。

```sh
node --test app/games/picture-words/gesture.test.cjs
node --check app/games/picture-words/game.js
```
