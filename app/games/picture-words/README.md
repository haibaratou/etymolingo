# WORD BLOOM / ことばの庭

イラストから文字をつなぎ、毎日の発見で自分の辞書を埋めるモバイルパズル。
入口は `../picture-words.html`。ゲーム以外の画面・辞書・イラストは変更しません。

## 起動

リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、
`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。
同梱の `catalog.js` と既存の `assets/word/` を使用し、ビルドや音声APIキーは不要です。

## 毎日の収集

- 画面上部に「今日のページ」を常設。初めて獲得した単語の絵が10枠を埋めます。
- 10語ごとにページ完成の紙吹雪とファンファーレ。11語目から次のページへ進めます。日ごとの上限はありません。
- 日付は端末の現地時間。翌日は新しいページになり、過去の単語・星・発見日・連続日数は保存します。
- 同じ語を再正解したり別の言語で正解しても、その日の新規発見数を水増ししません。
- 以前のセーブで獲得した語の日時は推測しません。語と星はそのまま引き継ぎます。
- 辞書は「今日・獲得済み・未獲得・すべて」、検索、48件ずつのページ切替に対応。
- 獲得済みカードから発音を聞き直し、語源辞書 `etymon-explorer.html` の検索結果へ移動できます。

## 出題と難易度

- 英語 **7,204語**。既存80語のID・答えを保ち、同じ英語・同じ画像が重複して出題候補を増やさないようにしています。
- 日本語は **316語**。既存80語と、意味・画像・かな表記が一致する読みだけを使用します。
- 読みのない語は英語で遊びます。日本語ボタンを無効化し、読みを推測しません。
- 初回は英語・おまかせ発見。保存済みの言語は保持します。旧版の固定ランク設定はおまかせへ移行します。
- 未獲得を優先し、表示履歴も保存。再読み込みや画像スキップで同じ小さな問題群に戻りません。
- 選択ランクを集めきっても、別ランクの未獲得語を出します。全候補を巡回したあとで復習に入ります。
- おまかせは短く比較的なじみのある語を優先し、収集とともに幅を広げます。全候補に出題可能性があります。
- 8段階の難度は綴り・読みの長さ、小書き文字、重複文字によるゲーム用指標です。語数が増えてもほぼ全語が最高ランクになることはありません。

## 操作と画面

- 絵から答えを考えて、文字をなぞってつなぎます。最後までつないで離すと判定、途中で離すと取消。
- 6文字までは1輪、7〜14文字は2輪。内側6文字を使うと外側が解放されます。
- 重複文字は別タイル。同じ文字が連続するときは別の丸へ進むか、選択中の丸から外へ出て戻ります。
- 文字盤下に「まぜる・辞書・ヒント」を横一列に配置。小型端末は縦スクロールし、ボタンを重ねません。
- ヒントを使っても収集できます。中央の矢印またはBackspaceで1文字戻し、キーボードはTab/Enterでも遊べます。
- 絵の下には反対言語の答えだけを伏字で表示。余分な言語ラベルは付けません。
- 正解直後に文字が跳ねて解答欄へ入り、獲得カードと今日の10枠が現れます。通常は約1.9秒、ページ完成時は約3.3秒で次の別画像へ進みます。「次へ」でも進めます。
- ミス・ヒントなしの正解でCOMBO。音程と紙吹雪が増え、5の倍数で追加演出。
- 設定や辞書を開く間、タブが非表示の間は自動進行を停止。動きを減らす端末設定に対応。
- ブラウザーの音声合成を使用。音声の有無・振動・実際の指の操作感は端末依存です。

## データの再生成

```sh
python app/games/picture-words/build_catalog.py
python app/games/picture-words/build_catalog.py --check
```

`app/data/generated-etymon/words.json`、`word-suika-ja.json`、
`assets/word/illustration-index.js` と実在するPNG一覧を照合します。
同形異義語は語根込みの索引またはファイル名台帳の対応だけを使います。
共有画像名を推測したり、alt画像を主画像として採用したりしません。
元台帳から保存した例外対応はジェネレーター内に保持し、任意の新しい台帳は
`--art-ledger path/to/word-art-todo.csv` で渡せます。

綴り2〜14字の名詞・動詞・形容詞を中心に、和訳がある実在画像を対象とし、
空白・記号・固有名詞表記・明示的な誤綴などを除外します。
画像や元辞書の意味・語根・レア度を編集せず、`app/data/pie/` は読みません。

## 保存・実装・検証

保存キーは `word-bloom-v1`。旧80語の星はIDで維持します。
`routeVersion: 2` は新しい並び、`discovery` は表示履歴・日別発見IDです。
保存を禁止したブラウザーでもプレイできますが、再読み込み後には残りません。

- `game.js`: 画面、入力、演出、辞書、進行の統合。
- `progression.js`: 重複回避、未獲得優先、日付、10語ページ、連続日数。
- `difficulty.js`: カタログ順、難度、旧セーブ移行。
- `gesture.js`: スワイプ判定、重複文字、2輪配置。
- `pronunciation.js`: 発音、キャンセル、音声エラー対処。

```sh
node --check app/games/picture-words/game.js
node --test app/games/picture-words/*.test.cjs
python -m unittest discover -s app/games/picture-words -p test_catalog.py
python app/games/picture-words/build_catalog.py --check
```

回帰検証は全画像の存在・PNG署名・同形異義語の対応・読みの制限、全対応言語の文字盤、
語数拡張時の難度、旧セーブ、再読込/スキップ後の出題、日付変更、重複獲得、10/11語の境界を含みます。
