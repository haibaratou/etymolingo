# WORD BLOOM / ことばの庭

イラストから文字をつなぎ、毎日の発見で自分の辞書を埋めるモバイルパズル。
入口は `../picture-words.html`。ゲーム以外の画面・辞書・イラストは変更しません。

## 起動

リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、
`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。
同梱の `catalog.js` と既存の `assets/word/` を使用し、ビルドや音声APIキーは不要です。
スマホは「遊ぶ」のタップで開始。右上の×で開始画面へ戻ります。
ブラウザーの全画面終了案内を発生させないため、Fullscreen API は使用しません。
URLバーなしで遊ぶ場合はブラウザーからホーム画面に追加して起動します。
manifest は standalone を指定しています（対応はブラウザー依存）。

## 毎日の収集

- 画面上部に「今日のページ」を常設。初めて獲得した単語の絵が10枠を埋めます。
- 10語ごとにページ完成の紙吹雪とファンファーレ。11語目から次のページへ進めます。日ごとの上限はありません。
- 日付は端末の現地時間。翌日は新しいページになり、過去の単語・星・発見日・連続日数は保存します。
- 同じ語を再正解したり別の言語で正解しても、その日の新規発見数を水増ししません。
- 以前のセーブで獲得した語の日時は推測しません。語と星はそのまま引き継ぎます。
- 辞書は「今日・獲得済み・未獲得・すべて」、検索、48件ずつのページ切替に対応。
- 獲得済みカードから発音を聞き直し、語源辞書 `etymon-explorer.html` の検索結果へ移動できます。

## 出題と難易度

- 出題は英語とかなの答えが両方そろった **1,859語**に統一。指定台帳で実際の辞書表示画像が **2026年9月11日（日本時間）以降に更新済み**と確認できた語だけを出題します。
- 日本語のかな文字盤で解けるものは **1,859語**。従来の158語に加え、カタカナ語義のかな化、および日本語辞書の見出しと語義が完全一致して読みが一つに確定する語を採用します。複数読みや長い定義文から読みを推測しません。
- 最初の80語のIDはセーブ互換用に保持。条件外の語は出題・問題選択から除外し、保存済みの星は消しません。
- すべての出題で同じ絵・同じ問題を保ったまま両言語を切り替えられます。切り替え操作では次の問題を選びません。読み未確定の1,846語は、読みが整うまで出題しません。過去の獲得記録は保持します。
- 初回は英語・おまかせ発見。保存済みの言語は保持します。旧版の固定ランク設定はおまかせへ移行します。
- 未獲得を優先し、表示履歴も保存。再読み込みや画像スキップで同じ小さな問題群に戻りません。
- 選択ランクを集めきっても、別ランクの未獲得語を出します。全候補を巡回したあとで復習に入ります。
- おまかせは短く比較的なじみのある語を優先し、収集とともに幅を広げます。全候補に出題可能性があります。
- 8段階の難度は綴り・読みの長さ、小書き文字、重複文字によるゲーム用指標です。語数が増えてもほぼ全語が最高ランクになることはありません。

## 操作と画面

- 絵から答えを考えて、文字をなぞってつなぎます。最後までつないで離すと判定、途中で離すと取消。
- 8文字までは1輪、9〜14文字は2輪。2輪は内外を同じ大きさ・濃さで固定し、内側を使うと外側が解放されます。
- 中央はタップ専用シャッフル。モバイルの上部収集・難度行は表示せず、実際の表示高さで盤面を調整します。右上のリロードで最新版へ更新し、獲得記録は維持します。
- 重複文字は別タイル。同じ文字が連続するときは別の丸へ進むか、選択中の丸から外へ出て戻ります。
- 文字盤下に「まぜる・辞書・ヒント」を横一列に配置。画面の高さに合わせて絵と文字盤を調整し、390×740ではイラスト約220px、320×568でも下端の操作まで表示します。極端に狭い画面や拡大時はスクロールできます。
- ヒントを使っても収集できます。中央の矢印またはBackspaceで1文字戻し、キーボードはTab/Enterでも遊べます。
- 絵の下には反対言語の答えだけを伏字で表示。余分な言語ラベルは付けません。
- 正解直後に文字が跳ねて解答欄へ入り、獲得カードと今日の10枠が現れます。通常は約1.9秒、ページ完成時は約3.3秒で次の別画像へ進みます。「次へ」でも進めます。
- 連続正解は正解時だけ「○問連続正解／ヒントなし・間違いなしで正解」と表示。常設COMBOバッジは出さず、起動・終了時に連続回数をリセットし、最高記録は保存します。
- 紙吹雪は毎フレーム画像領域全体を消去し、実時間で寿命を判定。画面サイズ変更・タブ非表示・次の問題・終了時にも消去します。
- 設定や辞書を開く間、タブが非表示の間は自動進行を停止。動きを減らす端末設定に対応。
- ブラウザーの音声合成を使用。音声の有無・振動・実際の指の操作感は端末依存です。

## データの再生成

```sh
python app/games/picture-words/build_catalog.py
python app/games/picture-words/build_catalog.py --check
# 台帳を更新したとき（元CSVは公開不要）
python app/games/picture-words/build_catalog.py --update-audit work/etymopedia/word-art-todo.csv
```

`app/data/generated-etymon/words.json`、`word-suika-ja.json`、
`assets/word/illustration-index.js` と実在するPNG一覧を照合します。
かなの追加候補は `app/data/ja/ja_index.json` の見出しと読みを照合します。
更新対象は `updated-art.json` に単語・語根・実表示画像名・更新日時だけを保存します。
CSVの `辞書表示画像_2026-09-10以降更新=YES` と日時の両方を確認し、
ゲームが使う画像名と一致するものに限ります。ファイルのコピー日時は判定に使いません。
日時不明・条件外を許可する代替処理はありません。
同形異義語は語根込みの索引またはファイル名台帳の対応だけを使います。
共有画像名を推測したり、alt画像を主画像として採用したりしません。
元台帳から保存した例外対応はジェネレーター内に保持し、任意の新しい台帳は
`--art-ledger path/to/word-art-todo.csv` で渡せます。

綴り2〜14字の名詞・動詞・形容詞を中心に、和訳がある実在画像を対象とし、
空白・記号・固有名詞表記・明示的な誤綴などを除外します。
画像や元辞書の意味・語根・レア度を編集せず、`app/data/pie/` は読みません。

## 保存・実装・検証

開始画面の「オフライン用に20問を保存」で、英語・かな両対応の20問と画像を端末に保存します。
ゲーム本体込みで約5MB。プレイ中の画像は自動保存しません。
通信できないときは保存済み画像のある問題だけを出題します。ゲーム本体もService Workerで保存し、圏外での再起動に対応します。
保存にはHTTPSまたはlocalhostが必要です。発音は端末に入っている音声に依存します。
オフライン用キャッシュはゲーム本体と単語画像だけを対象とし、他のページは変更しません。

保存キーは `word-bloom-v1`。旧80語の星はIDで維持します。
`routeVersion: 2` は新しい並び、`discovery` は表示履歴・日別発見IDです。
保存を禁止したブラウザーでもプレイできますが、再読み込み後には残りません。

- `game.js`: 画面、入力、演出、辞書、進行の統合。
- `progression.js`: 重複回避、未獲得優先、日付、10語ページ、連続日数。
- `difficulty.js`: カタログ順、難度、旧セーブ移行。
- `gesture.js`: スワイプ判定、重複文字、2輪配置。
- `pronunciation.js`: 発音、キャンセル、音声エラー対処。

```sh
node --check app/games/picture-words/game.js
node --test app/games/picture-words/*.test.cjs
python -m unittest discover -s app/games/picture-words -p test_catalog.py
python app/games/picture-words/build_catalog.py --check
```

回帰検証は全画像の存在・PNG署名・同形異義語の対応・読みの制限、全対応言語の文字盤、
語数拡張時の難度、旧セーブ、再読込/スキップ後の出題、日付変更、重複獲得、10/11語の境界を含みます。

プレイ中の『聞く / Listen』は選択中の言語の答えを発音します。文字の開示・ヒント消費・出題変更は行いません。自動音声がオフでも明示的な再生操作は有効です。追加音声ファイルのダウンロードはありません。



## 第一語義と画像の確認（2026-10-03）

- 新しい出題のかなは、編集済み辞書の第一語義だけに対応させます。第一語義の読みがない場合、後方の意味の読みで代用しません。
- `ja_readings` の `reviewed` の読みを優先し、自動候補や要確認の読みを自動で確認済みにはしません。
- 第一語義の読みが利用できない項目は `first_reading_unavailable`、個別に目視で不一致を確認した画像は `image_meaning_mismatch` とし、出題対象から外します。未確認であることだけを理由には外しません。
- `readiness-review.json` は25件の個別確認済みの画像不一致のみを記録します。画像SHA、観察内容、理由、再開条件を保持します。代表語義自体の確認が必要な事例は、画像が誤りであると断定しません。
- この更新で出題可能な共通プールは2,082語から1,859語へ変わります。3,963件すべてのIDと順番を保持し、過去の収集記録を削除しません。意味や画像の修正後は、同じIDで復帰させます。
- mortar は建材の新画像を使いますが、保存用IDは `mortar` のままです。辞書詳細では建材と迫撃砲をそれぞれの語義ラベル付きで表示します。
- 従来の最初の80件は確認済みの答えと収集IDを維持します。全辞書の代表順、全画像の一致を確認済みとする更新ではありません。
