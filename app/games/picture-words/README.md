# WORD BLOOM / ことばの庭

一枚のイラストを見て、円形の文字盤をなぞって答えるパズル。
入口は `../picture-words.html`。既存ゲームやサイトの入口は変更しない独立版です。

## 遊ぶ

リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、
`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。
出題データは通常の JavaScript として同梱しているため、HTML を直接開いても読み込めます。
画像は既存の `assets/word/` を相対参照します。ビルドや音声APIキーは不要です。

- 日本語（ひらがな）・英語（アルファベット）各60問、10問ずつ6つの庭。
- 指を離すと判定。戻ると選択を取り消し。同じ文字は別の丸を使います。
- タップ、キーボードの Tab / Enter / Backspace でも操作できます。
- 正解で単語を獲得し、日本語辞書・英語辞書をそれぞれ埋めていきます。
- 正解した言語で発音し、開いた図鑑の空白ページに絵と単語を登録。約1.7秒で次の未獲得問題へ自動で進みます。
- 並べ替え、無料の一文字ヒント、任意のステージ選択。
- 誤答やヒントがなければ星3つ。ヒント・誤答ありは星1〜2つ。ベスト結果を保持。
- 言語ごとの進行と音声・効果音の設定を `word-bloom-v1` にローカル保存。
- Web Audio の音階・和音、選択時の弾み、光る軌跡、文字の飛翔、花びら。
- `prefers-reduced-motion` では動きを抑制。効果音はユーザー操作から開始。
- イラスト読み込み失敗時は再試行または次の絵に移れます。

## 辞書を埋める

日本語60語・英語60語を独立して集めます。同じ絵でも両言語で正解すると、
それぞれの辞書に1ページずつ登録されます。ヒントを使っても獲得できます。
既存の `word-bloom-v1` の言語別クリア記録をそのまま獲得状況に使うので、
更新前に正解した語も失われません。再正解では語数を増やさず、最高の星だけを更新します。

- 初獲得時に図鑑を開き、空白ページにイラスト・単語・読みを出し、登録印を押します。収集数が増え、絵が下の辞書へ飛び込みます。
- 左ページには同じ言語で獲得済みのイラストを表示。再正解では「獲得済み」と表示し、語数を増やしません。
- 正解後の「次へ」ボタンや庭の途中の確認画面はありません。発音と登録演出を重ねて連続して遊べます。
- 辞書の2冊切替、獲得数・収集率、全60ページ、未獲得の空き枠。
- 五十音順 / アルファベット順で表示し、すべて・獲得済み・未獲得で絞り込み。
- 獲得語のページにイラスト・表記・読み・対訳・両言語の獲得状況を表示。
- 未獲得ページからその言語の問題へ直行。対訳も未獲得なら「英語でもゲットする」などで挑戦。
- 自動遷移はその言語の未獲得問題を優先。全語獲得後は順番に復習します。
- 演出中の図鑑やヘルプを開くと自動遷移を止め、閉じると再開。別問題・言語への移動時は古い遷移を取り消します。
- 辞書はゲーム内の60語を対象とし、元の大規模な語源辞書へは書き込みません。

## 聞いて覚える

- 正解直後にブラウザーの音声合成で読み上げます。日本語は漢字の推測読みを避け、参照辞書のひらがなの読みを使用。英語は英単語を使用します。
- 読み上げ中は効果音を小さくします。自動で次の問題が表示されても発音は途中で切らず、次の正解・手動の言語変更・辞書表示・画面を離れる操作では前の音声を止めます。
- 獲得した辞書ページに「発音を聞く」「ゆっくり」を用意。再生の連打は前の音声を置き換えます。
- 右上の音声ボタンで発音と効果音をまとめて切り替えます。マイクの利用はありません。
- 声の種類と言語の利用可否は端末・ブラウザーの音声エンジンによります。利用できない場合も問題は進み、辞書ページに再生できない旨を表示します。

APIの参照: [SpeechSynthesis.speak](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/speak)、
[言語指定](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/lang)、
[音声一覧の更新](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)。

## データの由来

参照は `app/games/word-suika_jp.html` と、その出題元
`app/data/generated-etymon/word-suika-ja.json`。
`build_catalog.py` の `CHOICES` は **読みと画像識別子のペア**で語義を選びます。
`w`（読み）・`ja`（表記）・`pic`（画像識別子）は元データの値をそのまま保存。
絵を目視確認した身近な名詞60語に絞っています。
英語の答えは今回選んだ画像識別子に一致する名詞です。

たとえば参照辞書の「にじ」は `second`、「かえる」は `return` に対応するため、
虹・蛙の問題としては使っていません。同綴り・同音の別義を自動採用しないでください。
元の画像や語源データは変更しません。`app/data/pie/` を読む必要はありません。

出題データを更新するときだけ、参照辞書を用意して実行します。
（このPRのベースに参照辞書がない場合も、ゲームは同梱 `catalog.js` だけで動作します。）

```sh
python app/games/picture-words/build_catalog.py --dictionary path/to/word-suika-ja.json
```

## 実装と確認

- `game.js`：状態遷移、Pointer Events、効果音、描画、保存、言語切替。
- `gesture.js`：高速スワイプの線分判定と選択・取り消し。移動イベント間の文字も拾います。
- `pronunciation.js`：言語に合う声の選択、通常・低速の発音、キャンセル、古いコールバックの無効化、無応答時の復帰。
- `style.css`：PCは左右2列、スマートフォンは縦1列。
- `catalog.js`：レビュー済みの辞書抜粋。実行時に大きな辞書を読み込みません。

```sh
node --test app/games/picture-words/gesture.test.cjs app/games/picture-words/pronunciation.test.cjs
node --check app/games/picture-words/game.js
node --check app/games/picture-words/pronunciation.js
```
