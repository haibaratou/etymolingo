# WORD BLOOM / ことばの庭

一枚のイラストからことばを考え、文字をなぞって日本語・英語の図鑑を埋める独立ゲーム。
入口は `../picture-words.html`。元のゲーム・イラスト・サイトの入口は変更しません。

## 起動

リポジトリ直下で `python -m http.server 8786 --bind 127.0.0.1` を実行し、
`http://127.0.0.1:8786/app/games/picture-words.html` を開きます。
同梱の `catalog.js` と既存の `assets/word/` を使用。ビルド・音声APIキーは不要です。

## 遊び方

- 80語を両言語で集める計160ページの図鑑。後半20語には難しい語・熟語を収録。
- 上部の難易度ボタンから8段階を選択。選んだランクの未獲得語だけを次の問題に出します。MYTHIC以上は金色の `★★★` でレアリティを強調します。
- 上部の「ステージ選択」ボタンから全80ステージを直接選べます。現在の番号もボタン内に表示します。
- 出題直後は現在と反対の言語だけを伏字で表示します。日本語モードなら英語、英語モードなら日本語です。「答えを開示」を押した場合だけ両方の答えを見せます。
- イラスト下の伏字・開示表示と解答欄は固定の高さを確保し、開示や日本語 / ENGLISH 切替で盤面の位置を動かしません。同じ絵を維持します。
- 文字盤にはその言語の答えに必要な文字だけを出します。ダミー文字や日英の文字数合わせはしません。
- 6文字以下は一重の円。7文字以上は内側6文字・外側に残りを配置。
- 全文字を最初から表示し、途中で入れ替えません。最長の TRANSFORMATION は内6・外8の計14文字です。
- 外側は最初だけ半透明。最初から選べて、内側6文字を使うと濃くなります。
- 選択済みの文字を通過しても入力を戻しません。同じ文字が複数ある場合は別の丸を使います。
- 指を離すと判定。途中で離した場合は即キャンセル。完全な誤答では文字盤と解答欄が揺れ、専用音が鳴ります。
- 中央の矢印 / Backspace で一文字戻せます。キーボードは Tab / Enter でも選択できます。
- 並べ替え、一文字ヒント、任意ステージ選択があります。ヒントを使っても図鑑に登録できます。
- 文字数・択数・操作説明の常設表示を省き、詳しい操作はヘルプにまとめています。
- 右上の月 / 太陽でダークモードを切替。英語モードでは文字盤を夜空の星図に変え、アルファベットを発光する星として表示します。設定は保存されます。
- イラスト表示面は全テーマで白地に固定し、透明PNGの線画や輪郭がダークモードでも見えるようにしています。
- 右上の「縦持ち」「PC」でレイアウトを固定できます。選択は保存され、端末幅に関係なく縦一列または二列の盤面を使えます。

## 獲得・発音・進行

正解すると画面最前面に大きな図鑑が開き、左ページに80枠すべての図鑑マップを表示します。
獲得済みの語はその枠だけが色付き、今取った語は右ページの絵から該当枠へ飛び込んで強く光ります。
登録印を押して収集数を増やします。背景をぼかすオーバーレイなので文字盤の位置は変わりません。
発音と演出を重ね、約1.7秒後に同じ言語の次の別イラストへ進みます。
もう一方の言語は中央の切替で好きなときに獲得できます。両言語がそろうと BILINGUAL CLEAR を表示します。
次へボタンや区切りの確認画面はありません。

- 8段階の難度・レアリティを両言語で共有。ランク名・色・カード枠・昇格演出で示します。
- 難度は綴りの長さ・小書き文字・重複などから作るゲーム内指標で、CEFRや語彙頻度の認定値ではありません。
- 日本語は辞書のひらがなの読み、英語は英単語をブラウザーの音声合成で発音。
- 発音中は効果音を小さくし、自動進行では発音を途中で切りません。手動の移動や消音では停止します。
- 図鑑の獲得済みページで通常 / ゆっくりの再生ができます。音声の有無は端末・ブラウザーによります。
- 図鑑は獲得数、空きページ、表記・読み・対訳、獲得状態による絞り込みを表示。
- 再正解では語数を増やさず、ベストの星を保存。未獲得ページからその問題へ移動できます。
- 図鑑・ヘルプを開いている間やタブが非表示の間は自動進行を停止します。
- 進行と音声設定は `word-bloom-v1` に保存。語IDで進行を引き継ぎ、出題順の変更でも獲得を維持します。
- `prefers-reduced-motion` では動きを抑制。マイクや外部の音声サービスは使いません。

## データ

参照は `app/games/word-suika_jp.html` と `app/data/generated-etymon/word-suika-ja.json`。
`build_catalog.py` の `CHOICES` では読みと画像識別子のペアで語義を選択します。
`w`（読み）、`ja`（表記）、`pic`（画像識別子）は参照辞書の値を保存します。
同綴り・同音の別義や、絵と英語の意味が一致しない候補は採用しません。
元の画像や語源データを書き換えず、`app/data/pie/` は読みません。

```sh
python app/games/picture-words/build_catalog.py --dictionary path/to/word-suika-ja.json
```

## 実装・検証

- `game.js`：描画、入力、効果音、図鑑、保存、進行。
- `gesture.js`：高速スワイプの線分判定、選択済み文字の通過、文字の二重円配置。
- `difficulty.js`：出題順、難度、言語別の必要文字数、旧セーブの移行。
- `pronunciation.js`：声の選択、再生、キャンセル、古いイベント・無応答への対処。

```sh
node --check app/games/picture-words/game.js
node --test app/games/picture-words/gesture.test.cjs app/games/picture-words/rings.test.cjs app/games/picture-words/difficulty.test.cjs app/games/picture-words/pronunciation.test.cjs
```
