# 英語で言い換える：説明文の管理

これは英語の語義説明であり、同義語一覧や画像の場面文ではありません。
`english-paraphrase-reviews.json` は各項目の第一語義に対応する編集記録です。
綴り・語根ID・辞書index・収録品詞・元の日英語義・語義SHA・対象品詞・編集法・AIレビュー記録を保持します。
既存の英語欄が適切なら再利用し、自己反復・同義語だけ・別義・画像場面文は定義として一括承認しません。

内容はAIによる意味の編集レビューです。独立したAIレビューも実施していますが、外部辞書による確認や人による全件保証、実測検証を意味しません。自動テストはID結合・出力・表示・リンク等の検証であり、意味の正しさの証明ではありません。

曖昧な収録値や別義の不一致は `status=hold` と理由を残し、画面に説明の確認待ちを表示します。収録品詞の不一致があっても日本語義が明確なら、元タグを変えず対象品詞と不一致理由を記録します。

公開用の `generated-etymon/english-paraphrases.js` は次の限定コマンドで再生成します。

```powershell
python tools/build_english_paraphrases.py --report-dir work/build-reports/english-paraphrases
```

入力は公開済み `generated-etymon/words.json` と編集記録だけです。入力SHAを固定し、変化した場合は停止します。禁止PIE領域への依存はありません。元語義・品詞・画像・学習区分・出題資格・学習履歴を変更しません。

リンクは読み込まれた辞書データの既存IDを使います。同綴・大文字小文字の複数候補は選択画面へ進み、文頭の大文字だけを根拠に意味を決めません。未収録の語や未確認の活用形を推測した別IDへ結びません。

出題対象を優先して整備しています。全辞書の全語義を整備したものではありません。作業ごとの対応件数・保留・残件は監査出力に保存します。
