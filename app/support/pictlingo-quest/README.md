# Pictlingo Quest（ピクトリンゴ・クエスト）

旧Questの実装・素材を保持したフォルダです。旧 `pictlingo-quest.html` は現在存在しません。ゲーム入口は `../../pictlingo-game.html`。このフォルダの `quest-data.js` は現在もPictlingoの図鑑に使われています。

以下の遊び方・保存キーは旧Quest実装の記録です。フォルダを丸ごと削除・保管すると現行Pictlingoの並びデータも失われるため、依存を確認してください。

## 方針（2026-10-19 全面作り直し）
- **なぞってつなぐ＋ずかん だけ**。キャラ演出・台詞・紙吹雪/粒子・時間制限(HP)・ガチャ・ジェム・他の問題形式はすべて廃止。
- 1カラム（最大幅520px）を画面中央に。文字盤は空きスペースに合わせて JS でサイズを決め、必ず中央に置く。

## 遊び方
- **あそぶ**：★1〜★5（単語のレア度）を選ぶ → 終わりなく出題。✕（または Esc）でいつでも戻る。進み具合は毎問保存。
  - 入力は元の Pictlingo パズルと同じ：六角タイルに答えの文字だけを隣り合う道順で並べ、一筆でなぞって指を離すと判定。途中で離すとキャンセル。まちがえたら同じ問題で続行（マスが赤く揺れるだけ）。判定と道順生成は `picture-words/gesture.js` を共有。
  - 下の3ボタンは元のパズルと同じ：**まぜる／聞く（単語の発音）／答え**（正しい順に光る。見た語は連続記録に数えず、少しあとでもう一度出る）。
  - **正解後**：答えのマスが緑に。★・No.・「ずかんに登録」、確認済みの**解説文（英＋日）**を出し、単語→英文の順に読み上げる。解説がある語は「つぎへ」（または Enter）で進む。解説が無い語は1.8秒で自動で次へ。発音ボタン：単語／文を聞く／ゆっくり。
  - 出題：その★の出題可の英単語（固有名詞=大文字始まりは絵から当てられないので除外）。未登録の語を優先、1プレイ中は同じ語をくり返さない。
  - **記録**：★ごとに「正解した語数」と「最高連続正解」。その★で累計15語正解すると次の★が開く。ホーム下の「全難易度を開放」でいつでも全部遊べる。
  - 右上の🔊で音声と効果音をまとめてオン／オフ。効果音は文字を選ぶ音・正解・不正解の3つだけ。
- **ずかん**：全17,114語に No.（身近な順の通し番号）と★（上位6%★1まいにち語／18%★2よくみる語／36%★3ときどき語／60%★4レア語／残り★5げきレア語。word-drop と同じ区切り）。★タブ・ぜんぶ/登録済み/未登録・ページ送り。未登録は影絵。登録済みをタップで大きな絵・発音・解説・Pictpedia へのリンク。

## ファイル
| ファイル | 内容 |
|---|---|
| `quest.js` / `quest.css` | ゲーム本体 |
| `quest-data.js` | 出題データ（**生成物。手で編集しない**） |
| `build_quest_data.py` | `picture-words/catalog.js` ＋ `eigo-no-e/categories.py` → `quest-data.js` |
| `chars/` | （旧版のキャラ画像。現在は未使用） |
| `thumbs/` | eigo-no-e に軽量サムネイルが無いテーマ語の256px WebP（`--thumbs` で生成） |

## 再生成
```sh
python app/support/pictlingo-quest/build_quest_data.py --thumbs   # catalog.js や categories.py を更新したら
python app/support/pictlingo-quest/build_quest_data.py --check
```
- 出題に使うのは `availability.en.playable` が true かつ英字1〜14文字の語だけ（保留・確認中の語は出さない）。
- ガチャ・図鑑は `bindingStatus: bound` の全画像。解説文は `description.status: reviewed` のものだけ。

## 保存
`localStorage` の `pictlingo-quest-v2`（旧 v1 のずかん登録は初回に引き継ぐ）。既存パズルの `word-bloom-v1` とは独立。
