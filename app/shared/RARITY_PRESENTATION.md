# 英単語レア度の共通表示

`rarity-presentation.js` と `.css` は `app/etymopedia.html` のピル、緑・青・紫・虹色・黒金の配色、6〜9秒のグラデーションを共通化した表示専用部品です。元の数値・出題資格・ゲーム効果・学習区分・履歴を変更しません。

`EtymonRarity.numeric(r, context)` は辞書の有限な正の数値rを、元画面と同じ境界400/600/800/1000/1400/1800で表示します。境界値は高い側です。欠損・不正値・99999の欠損番兵は「未確認」であり、最高レア度を推測しません。これは独自学習レベルとは別の指標です。

既存ゲームの `EtymonRarity.band(stars, scale, label, context)` は、呼び出し元が既に計算した段階と名前を受け取ります。ゲーム側の閾値・母集団・星数を再計算しません。5段階は色の展開だけを調整し、5の星を7へ増やしません。7段階も既存の分位判定を保持します。

contextは `list`（静止・小さなピル）、`detail`（大きめ）、`game`（既存カード上の帯）です。大量の一覧でグラデーションを動かさず、`prefers-reduced-motion: reduce` では全ての新しい動きが停止します。強制配色にも対応し、色だけに依存せず星・語ラベル・アクセシブルな説明を併記します。

適用：Pictpediaの一覧・詳細、語源辞書一覧のレア度欄、Picture Wordsの既存5段階のカード・獲得画面・辞書タブ、WordDrop英語モードの既存5段階タブ・結果、Etymon Slashの既存7段階カード。

元のエティモペディアは参照元として保持しています。WordDrop日本語モードは別の日本語辞書順位なので対象外です。Quest／Word Block Battleは現行でレア度バッジを非表示にしており、その意図を変えません。Word Forgeの10段階は抽選重みと結び付く別モデルのため今回の適用範囲外です。Word Suikaの合体段階、Wild Wordopiaのモンスター、箱庭の収集レア度、他の漢字プロジェクト等にも英単語rの段階を流用していません。

Pictpediaの辞書専用リンク先にはrを含まない小型データもあります。その場合は値を捏造せず未確認表示です。WordDropとSlashのfileモード検証は既存内蔵データを使い、HTTP限定データの読み込みは従来どおりです。
