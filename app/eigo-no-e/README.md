# Pictpedia — 英単語のイラスト辞典

正式な編集先は `app/eigo-no-e.html` と `app/eigo-no-e/` です。
トップ画像とシンプルなカテゴリーカードを維持し、現在の生成済みPNGをすべて閲覧できます。

## 起動・検査

公開リポジトリのルートで実行します。

```sh
python3 -m pip install -r app/eigo-no-e/requirements.txt
python3 app/eigo-no-e/build.py
python3 app/eigo-no-e/build.py --check
python3 app/eigo-no-e/test_build.py
node --test app/eigo-no-e/catalog-validation.test.cjs app/eigo-no-e/search.test.cjs app/eigo-no-e/all-images.test.cjs
node --check app/eigo-no-e/app.js
python3 -m http.server 8000
```

`http://localhost:8000/app/eigo-no-e.html` で開きます。
`?preview=mobile` は390px幅のCSS確認用で、実機テストの代わりではありません。
HTMLを直接開く `file://` ではビルド時に画像ハッシュまで照合した保存版を利用し、禁止される `fetch(file:)` を実行しません。正本やPNG変更後は再ビルドが必要です。
HTTPSでの取得失敗時に保存版へ黙って切り替えることはありません。

## 収録と表示

- `schema: 4` の `data.words` に、正本の単語に対応する画像、別画像・旧版、対応確認中の画像を収録します
- 単語の項目数と物理PNGの枚数は別の値です。同じつづりでも語根・画像の異なるIDを統合しません
- 解説のない画像も除外せず、詳細と該当カードには `解説未作成` と表示します
- 確認中の画像を、ファイル名から推測した英単語や和訳で表示しません
- 既知の画像・語義不一致や保留は閲覧可能のまま、解説表示とパズル開始を止めます
- 確認済み解説だけを、現在の正本・場面文・画像対応・画像ハッシュと照合して表示します。WordNet、類義語、語源を解説の代用にしません

一覧は60枚ずつ表示し、サムネイルと元PNGは遅延読み込みします。全PNGの取得・ハッシュ検査は起動時に行いません。既存の検査済みWebPがない画像は、対応する元PNGを表示します。

## 検索

- 単語検索: 見出し語、正本の第一義、対応する読み
- あいまい検索: 見出し語、和訳、読み、タグ、カテゴリー名、確認済み解説の一部

大小文字・全半角・かな表記を正規化した、入力キーワード全体の部分一致です。文章の単語分割、語幹化、翻訳、意味の推測は行いません。空の解説や保留中の解説は検索に混ぜません。

## パズルと読み上げ

英語・日本語それぞれの `availability` を利用します。解説の有無だけで遊べなくしません。
英語は正本と同じ英単語、日本語は検査済みのかな回答がある言語のみ有効です。
HTTPSでは選択したPNGの実体ハッシュを確かめてからリンクを有効にします。ゲーム側も同じIDと選択言語を検査し、別の単語や言語へ置き換えません。
単語の発音は明示的なボタン操作だけで再生し、空の文字や未作成解説は読み上げません。

## 更新元

正本の語義・読み、場面文、画像対応表、元PNGは、公開リポジトリの生成・レビュー経路が更新元です。
`build.py` が `data.js`、ビルドマニフェスト、サムネイル対応、HTMLのデータ版番号を更新します。
生成物と必要な画像を一つの公開単位にまとめ、中間状態を公開しないでください。
