# 漢字SURVIVOR（Godot版）

HTML版プロトタイプ（`../prototype/kanji-survivor.html`）を Godot 4.7 へ移したものです。遊びのルールは HTML版の最新版と同じです。演出を「墨・和紙・朱印・金箔」の世界でまとめ直しています。

- 起動: `ゲームを開始.cmd`（初回だけ素材の取り込みに少し時間がかかります）
- 自動戦闘を眺める: `自動戦闘で観る.cmd`（主人公を選んで「始める」か Enter で自動戦闘が始まります。記録は保存しません）
- 動作確認: `テストを実行.cmd`（画面なしで自動戦闘を4分ぶん高速に回します）

Godot は Grand Type Order と同じ順で探します。
1. 環境変数 `KS_GODOT`（なければ `GTO_GODOT`）
2. このフォルダか親フォルダの `tools/Godot.exe`
3. PATH の `godot` / `godot4`
4. 親階層の `apl/Godot*`
5. 同じドライブの一段下のフォルダにある `apl/Godot*` や `tools/Godot.exe`（Grand Type Order に置いた Godot をそのまま使えます）

## 操作

| キー | 動作 |
|---|---|
| A–Z | 字の下の英単語を打つ。次の文字が合う単語は全部1文字進む。日本語入力がオンでも英字として読む |
| Enter | タイトル・結果画面から開始 |
| Esc | 一時停止／再開 |
| Tab | 作字台を開く／閉じる（右上の「作字台」ボタンでも。開いている間は時が止まる） |
| F6 | 自動戦闘 ON/OFF |
| マウス | 右上の「自」「音」「やり直す」「一時停止」、タイトルの主人公カード、結果画面のボタン |

## 演出（HTML版から変えたところ）

- 和紙: 紙のむら・細かな粒・楮の繊維を描くシェーダーと、ワールドに固定した原稿用紙の朱の升目があります。紙の縁は少し焼けています。
- 漢詩の夜: 墨の闇に金の升目と、ゆっくり瞬く金の粉が出ます。
- 生きている字: 字ごとにシェーダーで動かします。
  - 意味どおりにうねる・しなる・揺らめく（犬は駆け、蛇はうねり、木はしなり、火は揺らめく）。
  - 縁が墨のかすれで少し欠け、芯が濃く、和紙の縁取りが付きます。
  - 現れるときは、墨がにじむように浮かび上がります。
- 字が砕ける: 字の画像そのものを三角の破片に割って飛ばし、墨の粒を散らします。
- 墨のにじみ: 縁の濃い墨だまりと繊維に沿ったにじみを持つ6種の染みが、地面に広がって残ります。
- 斬撃: 太さが入り→中→払いで変わる筆の線に、かすれた毛筋が付きます。
- 落款: 倒した字に朱の印を押し、ポンと鳴ります。
- 見出し: 筆で引いた朱の帯が、横から流れて止まります。
- 漢詩:
  - 画面上端の墨の帯に今の二句の漢字を置き、金箔の粉が漂います。英訳は怪物の下の札に出ます。
  - 句の字は墨で書かれてから金に変わります。
  - 句の景色（巨大な月・夕日・滝・銀河など）は帯の後ろ、画面全体に出ます。
- 合体（三択）: 選んだ素材に朱の「合」の印が押されます。
- 合体の演出: 墨の渦と金の粉の中で字が寄り合い、光の輪が広がって新しい字が現れ、最後に「合」の落款を押します。
- 主人公: 甲骨文は、筆圧の変わる線と、線に沿った柔らかな朱の光で描きます。
- 音（すべて自作の合成音）:
  - 斬るたびに琴が五音音階を上っていきます。
  - 打鍵は筆先、突進は風、被弾は低い胴鳴り、漢詩は銅鑼と太鼓で鳴ります。
  - BGMは、昼が琴の間（ま）、漢詩の夜が低い持続音と鈴です。
  - 決戦の始まりで梵鐘が鳴ります。

## 野と緩急

- 敵の出方には波があります。画面上の「静・増・群・凪」が今の波です。
  - 静: まばら。増: だんだん増える。群: 一方向から押し寄せる（来る前に方角が出ます）。凪: 止む。
- 野には動かない草木（草・木・林・森・竹・花・禾）が群れて生えています。打てば斬れますが、追ってはきません。林や森は敵を通さない壁になります。
## オープニング

- 説明の文章は出さず、字の動きと映画のカット割り（遠景・寄り・顔のアップ・スロー・暗転・あおり・肩ごし）で見せる（約28秒、黒帯つき）。カットは main.gd の CUTS 表で調整できる。

- 甲骨の文字たち（羊・人・女・子・魚・犬・牛）が山あいの村で暮らしている。夜、漢字の軍勢（兵・刃・戈・殺・鬼・魔…）が攻め寄せ、村を焼き、文字たちを斬り殺し、子と魚を網にかけて連れ去る。すべてを命じた漢字の「王」が姿を見せ、ひとり生き残った人が朱く燃えて復讐を誓う（約20秒、キーで飛ばせる）。

## 主人公

- 人・魚・水（象形文字）。水は最初から選べます。
- 水の系統: 水＋水→沝、沝＋水→淼、水＋木→沐、水＋工→江（江＋鳥→鴻）、水＋中→沖、水＋青→清、水＋目→泪、水＋皮→波（波＋女→婆）。

## 字の日本語の意味

- 合体画面などに出す日本語の意味（訓読み）は data/game.json の JP_GLOSS で直せる（例: 袱 → ふろしき）。

## 魂の使役と、仲間の合体

- **主人公は進化しない**（ずっと象形文字のまま）。三択の画面も「字魂転生」として、左には使役している仲間だけを並べる（主人公の字と「＋」は出さない）。漢字を破壊し、その**魂**を使役して仲間を増やす。
- 字を倒したり部品を崩したりすると、その字の白い魂が抜け出して主人公へ吸い込まれる（「魂」）。魂はバラバラにした最小の字（部品）でしか手に入らない。鬱や林をそのまま得ることはできず、木を三つ集めて 木＋木＝林、林＋木＝森 と組み上げる。
- **三択には、魂を手に入れた字（それまでに倒した字）しか出ない**（命だけは例外）。
- 三択で選んだ字は**字魂転生**でよみがえる: 主人公のそばの地面に墨の淵が広がり、朱の環に縛られた黒い字が罅をまとって這い上がり、仲間になる。よみがえった仲間には朱の罅が残る。
- **犬は純粋な仲間**（合体しない）。犬も倒して魂を手に入れると三択に出る（魂を得たら優先して出る）。
- **自機の字**: 選んだ主人公の字（人・魚・子・大・女・王）は、最初の三択にかならず出る（以後もときどき）。選ぶとその字が仲間になって戦う（人＝投石、魚＝獣…性能は下の「漢字クラフト」）。作字台では自機の字が箱に「∞」でいつでもあり、減らない（ただし自機の字どうしは組めない。もう一つは魂を使う）。人なら休・信・伏・付…、魚なら漁・鮮・鯨・鯉…、女なら好・妙・姫…と、選んだ主人公で作れる字の系統が変わる（人 111字、水 131字、女 43字、王 26字、大 17字、魚 16字、子 10字）。水の主人公はこれまでどおり水の仲間が出る。
- **合体は自動では起きない。作字台で自分の意思で作る**（マインクラフトの作業台のように）。
  - 魂は**数でたまる**（字を壊すたびに、その部品の魂が一つずつ箱に入る）。三択で仲間にしても魂は減らない。
  - 作字台（Tab）を開くと時が止まる。上の「魂の箱」から字を二つ台に置く（字の下の英単語を打つ／クリック／矢印＋Space）。字になる組み合わせなら、その場で新しい字ができる。ならなければ「木＋火 では字にならない」と出る。
  - 材料は箱の魂から先に使う。足りなければ仲間の字も材料にできる（その仲間の Lv が1下がり、0 になれば離れる）。
  - できた字は仲間になる（戦いに戻ると字魂転生でよみがえる）。すでに仲間なら Lv が上がる。
  - 下の「**字典**」に、いま作れる字と、前に作った字が並ぶ。朱の枠＝いま作れる（数字キー 1〜9 かクリックで作る）、灰＝前に作った字（足りない材料は朱）。字に触れると意味と技が出る。作った字は記録に残る。
  - 組み合わせは字典 `data/kanji_db.json` のすべての字（約1,950通り）。できた字の性能は下の「漢字クラフト」。
  - 字典や箱の訓読みは data/game.json の JP_GLOSS で直せる。
  - 試験: `--craft --ckeys=firezodiac --cclose`（魂を配って作字台を開き、英単語を打って作る）。自動戦闘では、12秒ごとに作れる字を一つ作る。
- 木や水はそれだけでは最弱だが、いろいろな字と結びついて強くなる。水の系統の行き着く先は「滅」。
- 合体の一覧（data/game.json の ALLY_FUSE。「A／B」はどちらでもよい）:
  - 火 ＋ 火 ＝ **炎**（flame）: 火と火が合わさって炎に。火の道が業火になる（火の力 +4）
  - 木 ＋ 木 ＝ **林**（grove）: 木と木が並んで林に。植える木が太い林の壁になる（木の力 +4）
  - 木 ＋ 人 ＝ **休**（rest）: 人が木に寄りかかる。木のそばで休むと命が戻る（20秒ごとに1）。木の力 +2
  - 木 ＋ 目 ＝ **相**（mutual）: 木を見る目。木に触れた字の周りの字も弾かれる。木の力 +3
  - 木 ＋ 日 ＝ **東**（east）: 木の間から日が昇る。木に触れた字は焼かれて1文字削られる。木の力 +3
  - 木 ＋ 田 ＝ **果**（fruit）: 木に実がなる。木が砕けると墨（経験値）の実を落とす。木の力 +3
  - 木 ＋ 寸 ＝ **村**（village）: 木を手で植えて村に。木を植える間隔が短くなる。木の力 +3
  - 林 ＋ 木 ＝ **森**（forest）: 林が森に。木が大きく太い森の壁になる（木の力 +8）
  - 林 ＋ 火 ＝ **焚**（burn）: 林を焚く。木に触れた字は燃え移る（木の力 +5）
  - 林 ＋ 示 ＝ **禁**（forbid）: 林の結界。木に触れた字は長く動けなくなり、木は三度まで砕けない（木の力 +5）
  - 日 ＋ 月 ＝ **明**（bright）: 日と月がひとつに。光の結界が広がり、5秒ごとに画面中の字を照らして削る
  - 戌 ＋ 口 ＝ **咸**（all）: 「みな」の字。4秒ごとに画面中のすべての字の末尾を1文字削る
  - 火 ＋ 戌 ＝ **烕**（extinguish）: 火が戌（いぬ）の刻に尽きる。2.5秒ごとに一番近い字を丸ごと消し去る
  - 水 ＋ 水 ＝ **沝**（twin streams）: 二筋の流れ。水の波紋が強くなる（水の力 +2）
  - 水 ＋ 木 ＝ **沐**（bathe）: 水を浴びる木。波紋が強くなり、波紋を浴びた字は長く鈍る（水の力 +2）
  - 水 ＋ 目 ＝ **泪**（tears）: 涙。波紋が強くなる（水の力 +2）
  - 水 ＋ 工 ＝ **江**（river）: 大河。波紋が強く、遠くまで届く（水の力 +3）
  - 沝 ＋ 水 ＝ **淼**（vast water）: 果てしない水。大きな波紋が二重に広がる（水の力 +4）
  - 沐 ＋ 木 ＝ **淋**（drench）: 浴びせる水。大きな波紋（水の力 +4）
  - 水 ＋ 炎 ＝ **淡**（pale）: 水と炎。字を淡く溶かす大きな波紋（水の力 +4）
  - 沝／沐／泪／江／淡 ＋ 咸 ＝ **減**（decrease）: 減らす。波紋に加え、3秒ごとに画面中の字の英単語を1文字ずつ減らす（水の力 +5）
  - 淼／淋／淡／減 ＋ 烕 ＝ **滅**（annihilate）: 滅ぼす。1.4秒ごとに一番近い字を丸ごと滅ぼし、周りの字も崩す（水の力 +7）

## 合体の演出

- 部品が、できあがる字の中の自分の位置（偏・旁・冠・脚・構え）へ飛び込み、押し合って一つの字に溶け合います。
- 例: 人＋犬＝伏なら、人が細い偏になって左に、犬が右に入り、伏になります。

## 決戦

- 漢詩が来ると画面が暗くなり、雑魚は闇の字（闇・鬼・魔・影・呪・死・魂・鬱など）に変わります。
- 漢詩は画面の上端に張り付きます。大きな金の二句と、そのすぐ下に光る札の英文。英文を打ち切るたびに詩が砕けて次の二句に変わり、全句で読み解けば勝ちです。
- **蚩尤（水墨画）が右から迫ってきます。触れると命が減ります**（触れた後は少し怯んで離れる）。字へ突っ込んだり十字キーで動いたりして逃げながら、英文を打ち切ります。画面の外にいる時は、縁に朱の「蚩」の印で方角が出ます。英文を打ち切るたびに蚩尤は怯んで押し返され、詩を読むほど墨が焼けて欠け、読み解くと墨に還ります。
- 試験: `--onitest --oniwait=14 --idle`（すぐ決戦を始め、蚩尤と主人公の位置と命を出す）
- 英文を打ち切るたびに、画面の雑魚の単語が末尾から1文字減って押し返されます。

## 移動（十字キー）

- 十字キー（↑↓←→）で上下左右に少しステップします。押しっぱなしで続けて動き、二つ押せば斜めにも動きます。
- ステップはただの移動で、攻撃ではありません。敵の字に触れれば傷を負います（字を打って突っ込む間だけは当たりません）。

## 景（ステージ）

- **第一景 森林**（STAGE 1 — THE FOREST）: 甲骨の村を焼かれ、森へ逃れた人。木々や森の獣が文字となって行く手を阻む。木偏の字が茂る緑の迷い森。木の部品を崩すと、画面中の木偏の字へ連鎖する。 部首: 木。草木: 草・木・林・森・竹・花・松・杉。
- **第二景 大河**（STAGE 2 — THE GREAT RIVER）: さらわれた魚の気配を追って大河へ。さんずい（水）と魚偏の字が流れに乗って押し寄せる。水の部品を崩すと、画面中のさんずいの字へ連鎖して一斉に崩れる。 部首: 水・魚。草木: 草・葦・蓮・石・竹。
- **第三景 王城**（STAGE 3 — THE KING'S CITADEL）: 漢字の王の都。兵・刃・戈の軍勢、王に仕える臣と民、門と城壁。武と権威の字が整然と攻めてくる。最後に待つのは王そのもの。戈・金・宀の部品を崩すと、同じ部首の字へ連鎖する。 部首: 戈・金・宀。草木: 石・門・塔・草・旗。
- 景は漢詩（ボス）を読み解くたびに進む。景の部首を持つ字は、まずその部首がはがれ、画面中の同じ部首の字へ近い順に連鎖して一斉に崩れる（「水 連鎖 ×7」）。出る字・部首・草木は data/game.json の STAGES で変えられる。
- 決戦（漢詩）の間は闇の字が絶えず押し寄せる（最大24体）。

## 囚われのひらがな（物語の分岐イベント・準備中）

- 物語の終盤の分岐イベントで使う。「囚」の檻のかなを、ローマ字（sakura など）を打って解き放つ。戦わず、舞い上がって空へ帰る（命 +1）。檻の生成と解放の処理（spawn_kana_cage / use_obj "kana"）だけ用意してあり、いまは野には出ない。

## 字の状態（相性で解く。説明は出さず、初めての時だけ少しゆっくりになって小さく知らせる）

- **氷**: 六角の氷の殻をまとう。仲間に「炎」がいないと、斬撃も仲間の攻撃も弾かれる（「弾」）。炎がいれば当たった瞬間に溶けて「水」に化ける（湯気。氷→水）。
- **毒**: 禍々しい紫の墨をまとう。斬ると自分も毒を浴びて命が1減る。仲間に「清」（水＋青）がいれば、見つけしだい浄めて消し去る。
- **闇**: 現れると画面全体が闇に沈み、主人公のまわり以外は見えにくくなる（倒すまで）。仲間に光（日・明）がいれば、闇へ光が射し、照らし続けて倒す。森林では後半から約80秒ごとに現れる。

## 相性（困った字と、自動で解く仲間）と試験場

起動画面の「効果の試験場」で、相性・仲間の効果・字の動きの個性をその場で試せる（主人公は倒れない）。下の札で「◀ 前／次 ▶」「仲間あり／なし（Lv を上げる・合体・出し直す）」「→ 相性／仲間／個性」「終わる」。キーは Tab 次へ（Shift+Tab 前へ）、Space 切り替え、F1 相性・仲間・個性の切り替え。

| 困った字 | 困った振る舞い | 解く仲間（作り方） | 解いた結果 |
|---|---|---|---|
| 氷 | 炎がないと攻撃を弾く | 炎（火＋火） | 溶けて水に |
| 毒 | 斬ると毒を浴びる | 清（水＋青） | 浄めて消す |
| 闇 | 全体が闇に沈む | 明（日＋月）・日 | 照らして消す |
| 霧 | まわりの字の英単語を隠す | 嵐（山＋風） | 吹き払って雨に |
| 鬼 | ときどき姿を消して狙えない | 桃（木＋兆） | 桃で祓う |
| 呪 | いるあいだ主人公の踏み込みが鈍る | 祝（示＋兄。兄は呪を崩すと手に入る） | 祝いに変わり命 +1 |
| 炎 | 通った跡に火を残す（踏むと火傷） | 水・水の系統 | 鎮めて火に |
| 枯 | 近くの仲間の木を枯らす | 雨 | よみがえって木に |
| 雷 | 主人公めがけて雷を落とす（予兆の輪） | 金 | 金が雷を引き受け、雷は消える |
| 岩 | 最初は固くて壊せない（斬撃も仲間の攻撃も弾く） | 戌（もとは鉞。森林から敵の「戌」を倒すと魂が手に入る） | 手に入れると岩に罅が入り、割れて石になる |

- 解く仲間がいると、その仲間から困った字へ色つきの光の筋が伸び、約1.2秒で解く。初めての時だけ少しゆっくりになり、「氷 → 水　炎で溶けた」のように小さく出る。
- 嵐は3秒ごとに突風で近くの字を吹き払い、桃は2.5秒ごとに桃を投げ、祝は40秒ごとに命が戻る。

## 字ごとの動きの個性（試験場の「個性」で見られる）

- 突進（牛・虎・猪・鹿・象・熊）: 近づくと身構えて震え、一直線に突進して通り過ぎる。
- 間合い（弓・砲・雲）: 距離を取って回り込み、一字を弾のように撃つ（弓→矢、砲→石、雲→雨）。弾の字も英単語を打てばその場で斬れる。刀がいれば、近づく弾を斬り落とす。雲は嵐が吹き払う。
- 跳躍（蛙・猿）: 間をおいて大きく跳ぶ。　渦（風・嵐・渦）: 渦を巻きながら近づく。
- 潜行（鼠・蟻）: 地にもぐって速く近づき（土が跳ねるだけで見えない・狙えない）、顔を出して止まる。
- 臆病（羊・兎・狐）: 近づかれると逃げる。　瞬き（霊・鬼・幽）: ふっと消えて近くに現れる。
- 毒の跡（蛇）: 通った跡に毒溜まりを残す（踏むと命が減る）。清がいれば浄められて消える。
- ほかに、ゆれ（影）・はばたき（鳥…）・根（草木）・疾走（犬・馬・猫）。

## 字で解く仕掛け（「文字遊戯」のように、字で絵を変えて攻略する）

- **水墨画の川**: 景ごとに決めた場所に川が流れ、向こう岸に宝がある（下の「景の配置」）。主人公は川を渡れない。
- 仲間に**橋**（木＋喬。喬は「橋」の敵を崩すと魂が手に入る）がいれば、川に近づくと橋の字が架かり、その上だけ渡れる。
- 今後、ほかの字で解く仕掛け（山に「穴」、闇に「灯」など）を足していく。

## 漢字クラフト（字の性能は部品の足し算）と、字の試験場

- 常用・人名用の字とその部品、約3,100字すべてに性能がある（`data/kanji_db.json`）。字を一つずつ作り込むのではなく、**部品（素）の足し算**で決まる。
- **系統（12）**: 素はどれかの系統に入る。系統ごとに技が一つある。
  - 波（水・冫・雨…）波紋 ／ 炎（火）燃える道 ／ 樹（木・竹・艸…）木の壁 ／ 光（日・月・目…）回る光 ／ 刃（刀・戈・斤…）斬りこみ ／ 矢（弓・矢・羽…）矢 ／ 声（口・言・耳…）叫び ／ 獣（犬・馬・鳥・虫…）獣 ／ 岩（土・山・石・金…）落石 ／ 霊（示・心・鬼…）結界 ／ 人（人・手・又・足…）投石 ／ 門（宀・門・糸・衣…）囲い
- **本体**: 字を組み立てる部品のうち、偏・冠・外側から見て最初の素の系統。その技を全力で使う。
- **脇の技**: 残りの素は、その素の技が小さく付く（同じ系統が重なるほど強い）。例: 淡（水＋炎）＝波紋＋燃える道×2、明（日＋月）＝回る光＋回る光、滅（水＋烕）＝波紋＋斬りこみ＋燃える道。
  - 波紋を浴びた字は濡れ、濡れた字が削られると近くの濡れた字も一緒に削られる（水の連鎖）。炎に触れた字は燃え続け、燃え移る。
- **能力値（7）**: 素の系統ごとに一つ上がる。威力（一撃で削る文字数）・範囲・速さ・数・持続・貫通・押し。素の数（格）が多い字ほど全体が強い。同じ字を重ねて作ると Lv が上がる。
- **作字台**: 箱の字を二つ（左・上が一つ目、右・下が二つ目。逆でもよい）重ねると、その組み立ての字ができる（約1,950通り）。できた字は仲間として、この性能で戦う。
- **字の試験場**（起動画面の「字の試験場」）: どの字でも、その場で仲間にして字の群れにぶつけて試せる（主人公は倒れない）。
  - 左: 字の一覧。英語を打って探す／系統の札で絞る／↑↓で選ぶ（PageUp/Down で速く）。
  - 右: 字の性能。組み立て、素（系統の色と上がる能力値）、本体の技と脇の技、能力値と、その意味（一撃で何文字・広さ何倍…）、この字を材料にできる字。
  - 下: 場面 1 囲まれる／2 群れ／3 硬い字／4 速い字／5 湧き続ける。全滅までの秒数・削った文字・毎秒・主人公に触れた回数が出て、前の結果と比べられる。
  - Enter で試す字を入れかえ、Tab で足す（4つまで、組み合わせを試せる）。←→ で Lv。Space でもう一度。Esc で戻る。
  - 試験: `--kl --klch=淡,明 --klsc=0 --klwait=12`（字・場面を決めて、数字を出す）

## 景の配置と全体マップ（レベルデザイン）

- 野は区画ごとに無限に作られる。草木や小物は景ごとに決まった種から作るので、同じ景なら毎回同じ並びになる。
- それとは別に、**data/game.json の MAPS** に「どこに何を置くか」を景ごとに書く。座標は景に入った地点（出発点）からの区画数（x 右・y 下、小数可）。
  - `guard`（待ち伏せの字。主人公が近づくまで動かない）／`rock`（岩の壁。n 個。戌がいないと壊せない）／`obj`（宝など）／`grove`（群生する草木）／`river`（x〜x1 に流れる川）。`note` は全体マップに出る説明。
  - 主人公がその区画に近づいた時に置かれる。景が変わると、見えない所の前の景の待ち伏せと川は消える。
- **全体マップ（開発用）**: 起動画面の「全体マップ」か、遊んでいる最中に **F2**。左に区画の格子・出発点・川・配置（置かれる前のものは「未配置」）・いまいる字・画面の範囲、右に景の説明・出る字・困った字と解く仲間・魂と仲間を出す。**＋／−** で拡大・縮小。マップを開いている間は時間が止まる。

## 群れの字

- 巳（へび）は長い行列で、虫は大群で、鳥は雁行で、馬・牛・兵は横一列で押し寄せます（群れは部品に分かれない易しい字だけ。王城では兵の列）。草木の字は歩かず、根を張っては地にもぐり、一歩先に生え直して迫ります。群れの字は一体ずつ打てる字で（札は頭にだけ出る）、同じ単語なので打ち切ると見えている群れ全員へ順番に突っ込んで斬る（連撃が伸びる）。頭を倒すと残りはばらばらに襲ってくる。

## 武器（仲間の字）

- 右下の字の箱の上に、その字が与えたダメージ（削った文字の数）の合計が小さく出る。

- 武器は最大Lv8（力はLv5）。武器ごとに別々に削るので、重ねるほど字が速く崩れます。Lv3・6で一度に削る文字が増えます。
- 刀: 主人公の周りを刀が回り（Lv8で五振り）、触れた字を斬って弾き飛ばします。
- 矢: 狙わずに、左・右と順番に真横へ放ちます。Lvで本数（最大五本）が増えて縦に並び、貫きます。
- 火: 主人公の通った跡が火の道になり、Lv1でも約3秒燃え残ります。踏み込んだ字は燃え移って燃え続け（0.5秒ごとに末尾を焼く）、近くの字へ延焼します。Lv4から主人公の周りに炎の輪が噴き上がります。
- 水: 波紋で押し返して鈍らせ、Lv5から二重に広がります。
- 日: 主人公の周りを広く焼き、Lv5から陽の光線が四方に走ります。
- 木: 攻撃しません。主人公と字の群れの間に藍の木を植えます。木は根元から縦に伸び、触れた字を大きく弾き飛ばして、身代わりに砕けて消えます（傷はつけない）。しばらくすると上か下に次の木が生え、縦の並木に増えていきます。Lv4から林、Lv7から森が生まれるようになります。
- 月・雨・田も間隔・範囲・数が伸びます。

## 野の宝

- 野にときどき「宝 treasure」があります。打つとそこまで駆けて、金の墨と命 +1。

## 敵の大きさ

- 部品が多い字ほど大きく、部品5つ以上の鬱などは化物のように巨大です。

## 水墨画の素材

- 字以外の絵（詩の景色・墨の染みとしぶき・斬撃の筆・雨雲・網・タイトルの山水）は水墨画です。
- `art/CODEX_ART_TASK.md` の指示で Codex が生成し、`art/incoming/` に置いた原画を、白地を透明にして `assets/art/` に入れています。
- 詩の景色は、紺紙金泥のように夜の闇へ淡い金銀で浮かべます。

## 構成

| ファイル | 中身 |
|---|---|
| `scripts/main.gd` | 遊び全体（状態・敵・主人公・仲間・漢詩・三択・合体・自動戦闘・描画・画面） |
| `scripts/kd.gd` | データ読み込み（`data/game.json`）と、字の構成・進化の計算 |
| `scripts/glyph_bank.gd` | 起動時に字の画像をまとめて作る（敵・仲間はこの画像にシェーダーをかける） |
| `scripts/oracle.gd` | 甲骨文を筆の線で描く（データは `data/jgw.json`） |
| `scripts/monster.gd` | 決戦の怪物（渾沌・蚩尤・饕餮）を線と面で描く |
| `scripts/sfx.gd` | 効果音と BGM |
| `shaders/living.gdshader` | 生きている字（字形のうねり・墨のかすれ・和紙の縁取り・にじみ出し） |
| `shaders/paper.gdshader` | 和紙と原稿用紙、漢詩の夜 |
| `assets/` | `tools/make_assets.py` で作った効果音・BGM・墨の染み・筆の帯・落款の縁 |
| `data/` | HTML版から書き出した字のデータ（画数・構成・進化系統・漢詩など） |

記録（最高記録・アンロック・選んだ主人公・画面の動き）は Godot の user フォルダの `ks_meta.json` に保存します。HTML版とは別の記録です。
