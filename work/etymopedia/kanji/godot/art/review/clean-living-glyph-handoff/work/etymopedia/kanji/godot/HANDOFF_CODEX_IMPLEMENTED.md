# 漢字SURVIVOR 実装の引き継ぎ（2026-10-13）

> 最新の修正は [GLYPH_WORLD_HANDOFF.md](GLYPH_WORLD_HANDOFF.md) を参照。主攻撃は生きている文字の配置と接触へ置き換えた。以下の画像主体の報告は前回時点の記録。

この文書は `HANDOFF_CODEX.md` を読んだ後の実装追補。今回のユーザー指定は、部首の継承・クラフトの面白さ・強化で派手になる見栄え・漢字そのものの弾・文字を物や地形として使うこと。
元の作字レシピ、敵の格とHP、主人公の非進化、作字台でだけ仲間を作る規則は維持した。

## 起動

- 通常: `ゲームを開始.cmd`。
- 新しい技の比較: `新しい技を観る.cmd`。初期は林のLv1。矢印で歩いて木の道を作り、＋／−でLvを変え、1〜5で敵の場面を変える。左で字を選び、Enterで入れ替える。
- 作字: Tab。魂を組み合わせると即座に仲間になり、同じ字を重ねればLvが上がる。継承と次の強化を字典の詳細で見る。
- 古城: 通常プレイに出る壁の字は壊せない。門の `gate` を打つと「開」が残り、通行できる。中の宝を打つ。

## コード

- `scripts/kraft.gd`: 通常は部首の動き。227字の明確な指定と134字の英語意味照合、そのほかは部首の自然な継承動作。全2,645仲間にプロファイルを持つが、全字の固有字義技を完成させたという意味ではない。
- `scripts/semantic_combat.gd`: 認識しやすい攻撃、実際の漢字の弾、継承する接触作用、Lvで変わる筋・群れ・連続波。効果数には上限があり、当たり判定は既存のHP/部品分解経路を通る。
- `traits`: ほかの部品の系統・個数・効果・元の字。水の濡れと連鎖、火の燃焼、木の根、光の遅延、刃の後方への斬撃などを技に合成する。
- `transform`: 珍しい作字の方向転換。滅は溜めた前方の奔流、爆は予告して一撃、囚は前方の捕縛、朧は残る霧、災は水火の交替。レシピは既存の字典からだけ取る。
- `scripts/glyph_gimmicks.gd`: 壁・門・開・宝の古城。高速移動の連続衝突、入力→突進→開門、敵の通行、復帰時の門の維持を扱う。
- `scripts/ink_world.gd` と `shaders/paper.gdshader`: 承認済みの山水画を戦場の余白に置き、朱の升目を薄くする。
- `tools/import_semantic_atlas.py`: 生成した原画の切り抜き・白地透過。絵の生成は内蔵画像生成ツール。プロンプト・保存先は `art/SEMANTIC_ART.md`。

## 確認

`VALIDATION_CODEX.md` に実行した確認と限界を記録する。`tools/test_semantics.gd` は作字・材料消費・同じ字の強化・HPでの部品分解・継承する作用・Lv1の向き・実際の入力による開門を検証する。

甲骨文の `scripts/oracle.gd` と `data/jgw.json` は今回変更せず、開始時のハッシュと一致。指定された1,203字のデータの識別子と来歴も点検した。
