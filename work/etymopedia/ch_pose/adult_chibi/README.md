# 大人デフォルメ版 — sexy.pngと同じくらいの頭身

二人が成長した大人版です。`assets/word/sexy.png`を頭身と画風の参照にし、大きめの頭・コンパクトな体・短めの手足に揃えています。
男の子15種類・女の子15種類、計30枚の個別・全身・背景透過PNGです。

- `boy_blue/`: 茶髪、青いジャケット、アイボリーのシャツ、茶色の長ズボン、青い靴。
- `girl_yellow/`: 茶色のサイドポニーテール、黄色のカーディガン、アイボリーのブラウス、コーラル色の膝丈スカート、赤茶の靴。
- `contact_sheet.jpg`: 全30枚の確認用一覧。
- `manifest.json`: ファイル一覧・寸法・透明度。
- `prompts/`: 使用プロンプトと参照画像。
