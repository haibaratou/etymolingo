## ゲームに組み込むとき
これらは独立した静止画で、連番アニメーションやGIFではありません。既存ゲームへの組み込みは未実施です。
CSSやゲーム側で、通常→正解→通常の画像切り替えに、拡大・上下移動・回転を合わせるとリアクション演出に使えます。
例: 正解は220msの小さな拡大、連続正解は160msの後ずさり、クリアは600msのジャンプ、失敗は350msのゆっくりした沈み込み、応援は300msの上下運動。
動きを減らす設定では画像切り替えのみを推奨します。

元PNGは生成解像度を維持しています。ファイルごとの寸法はmanifestを参照してください。
高さを揃えた表示領域に `object-fit: contain` で収め、足元を揃えて使ってください。
独立生成のため、頭身・余白・目の描き方などに多少の差があります。厳密なコマ間連続性が必要な用途は別途調整してください。
