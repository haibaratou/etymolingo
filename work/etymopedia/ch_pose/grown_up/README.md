# 二人が少し成長したバージョン

**このフォルダは不採用の頭身が高い初稿です。途中で生成を中止しており、下記30枚の計画は未完了です。**
ユーザー指定の `sexy.png` に合わせた大人デフォルメ版は、隣の `../adult_chibi/` に保存します。

中高生くらい（15歳前後）を想定した、男の子15種類・女の子15種類、計30枚の背景透過PNGです。
子ども版とは頭身、手足の長さ、顔立ちを変え、同じ人物と分かる髪型と配色を引き継ぎました。

- `boy_blue/`: 茶色の髪、青い長袖、茶色の長ズボン、青いスニーカー。
- `girl_yellow/`: 茶色のサイドポニーテール、黄色の長袖、コーラル色の膝丈スカート、赤茶のスニーカー。
- `contact_sheet.jpg`: 全30枚の確認用一覧。
- `manifest.json`: 寸法、透明度、内容領域、ファイル一覧。
- `prompts/`: 実際に使用したプロンプトと参照画像。
