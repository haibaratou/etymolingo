# エティモペディアのイラスト制作

## 最優先：ユーザー検品と手動コピー（2026-10-15確定）

1. Worksは `D:\Projects\etymolingo\work\etymopedia\_illust` に出力する。完成実PNGを開き、短い英日解説・行キー・保存先・実PNGのSHA256・Git blob SHA・検品日時を同じCSV行へ記録する。
2. ユーザーが `_illust` で生成画像を検品する。Worksの `reviewed` はユーザー採用・正式反映完了を意味しない。
3. 検品後、ユーザー自身が `_illust/copy_newer_pngs.cmd` で正式 `assets/word` へ複製する。**AIはCMDを実行しない。他のコマンドや取り込み処理による正式PNGへの自動コピー・置換も禁止。ユーザー検品を飛ばさない。**
4. コピー前の解説はCSVに保持し、現行正式画像の解説へ上書き反映しない。コピー後、正式PNGのSHA256が確認した `_illust` の実PNGおよび解説の記録SHA256と完全一致する行だけ採用できる。第一語義・行キー・既存レコードの競合も検証する。未コピー・不一致なら現行正式画像と解説を保持する。同名・更新時刻・状態名のみで採用しない。
5. `workflow_io.py apply` は正式PNGを読み取り照合し、同一hashの解説のみ取り込む。ユーザーコピーを代行しない。基準スナップショットは手動コピー後の正式画像と原本解説から取得する。公開書き出しは別工程。

**CMDの現状：** 読み取り確認したSRC/DSTは旧パス `D:\etymolingo\...` であり、今回の `D:\Projects\etymolingo\...` と異なる。CMDは未変更・未実行。ユーザー実行前に対象パスを確認する。現行CMDはサブフォルダーも対象とし、開始時のコピー先より更新時刻が新しいPNGを選び、フォルダー名順で後の同名ファイルを優先する。そのためコピー後の実SHA256照合は必須。

この確定手順は以下の旧記述にあるAIによるPNG反映・画像と解説の自動同時反映より優先する。


語源辞書の単語イラストを、正式な日本語語義と画像名に合わせて制作する。

## 制作の3段階

1. 担当1：代表的な第一語義を確認し、画像生成プロンプトをCSVへ保存
2. 担当2：画像生成・実物検品・短い英日解説追加を行い、実行プロンプトと結果をCSVへ保存
3. 反映バッチ：検品合格した画像・解説だけを辞書原本へ反映し、公開データを書き出す

[改訂ワークフロー](WORKFLOW.md)と[稼働中Codexへの継続指示](codex/CONTINUE.md)を参照。既存7列を先頭に保持し、追加列へ記録する。専用CSV取り込み処理は未実装で、既存の公開書き出しとは別。

## プロンプトCSVの担当別フォルダ

- [codex2（旧dotフォルダ）](codex2/README.md)：009・011・028〜030。画像生成・検品用のCSVを保持
- [codex](codex/README.md)：007・008・010・012〜027。Codexが画像生成を担当
- 000〜006は担当未確認の履歴として、`old/` に保持

担当は画像生成の担当を表す。プロンプト作成済み・画像生成済み・検品合格・公開反映済みは、それぞれ別の状態として確認する。

9月10日末以前の未更新画像は、レア度順にdotがプロンプトと画像の両方を担当する。既にプロンプトがあることだけを理由に、再生成が完了したとは扱わない。
