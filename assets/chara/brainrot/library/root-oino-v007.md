## 共有解説
「ひとつ」がこの一族の出発点。英語の one はゲルマン語派から受け継いだ数の語だ。昔の英語には今とは違う音の形があり、長い時間をかけて現在の発音になった。once は一度、only はただ一つ・それだけ、alone は一人でという意味。alone は古い「すべて」と「一つ」を合わせた表現からできている。数を一つずつ数えるだけでなく、「一回だけ」「ほかがない」「一人だけ」と、ひとつの見方を変えている。

ラテン語側では unus が「一つ」。unit はひとまとまりの単位、unique はただ一つしかない特別なものだ。uniform の uni- は「一つ」、後ろは形を表す別の要素なので、もとは同じ形にそろっていること。学校の制服も、みんなの服を同じ形にするからこの名前になる。unicorn の uni- も一つで、後ろは角。unicycle の uni- も一つで、後ろは車輪の系譜。一つの角、一つの車輪、一つにそろう形、と同じ部分が別々のものと組み合わさる。英単語全体が「ひとつ」という意味なのではないところも大事だ。

意外な仲間が onion、タマネギ。近い祖先はラテン語で一つのものや真珠を指した語で、タマネギの球にも使われた。英語に届くまでにフランス語の形を通っている。一つの球にまとまって育つ姿を思い浮かべると、数字と野菜の距離が縮まる。何枚も重なる皮が、一つの球を形づくっている。unit は一つにまとめた単位なので、何個も数えていくこともできる。unique はほかに同じものがない特別さ。alone は一人の状態だ。同じ「ひとつ」でも、数えるまとまり、ただ一つの存在、一人でいる気分では使い方が変わる。onion の球も、一枚ずつ皮をむくと、ひとまとまりの中に何層もある。
