# *(s)ker-1 切るの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

切ると、一つだったものが分かれる。その切り口から、服も形も、分け合うものも生まれるよ。shear（切る・刈る）は古英語からの枝で、shears（大ばさみ）は刈る道具。shirt（シャツ）は古英語の枝、skirt（スカート）は古ノルド語から来た枝で、もとは近い形の服の名前だった。北の言葉ではskの音が残り、英語の枝ではshになったので、今では別の服でも、音の道をたどると兄弟が見える。

share（分け前・分け合う）も切り分けたものという枝から育った。切って一人ずつへ渡すと、みんなの分け前になる。short（短い）は、切り詰めたような形に関係する言葉。sharp（鋭い）では、切るための鋭さが姿に出ている。切るための鋭さ、切ったあとの短さ、切り分けてもらった取り分。同じ動作を見る場所を変えると、別々の英単語の意味がつながるんだ。

score（点数・刻み目）は古ノルド語の切り込みから来た。木などに刻みを付けて数えれば、切った線が数の記録になる。その記録の意味が、試合の点数へ広がった。今は数字で表示しても、点数の名前の奥には、印を一つずつ切り込んで残す古い数え方があるんだね。

ラテン語の枝には肉を表すcaroがある。carnivore（肉食動物）のcarni-がこの肉の成分で、食べる側は別の一族。carnival（カーニバル）のcarni-も肉で、もとの組み合わせは肉を取り除くことへつながり、肉を控える時期の前の祝祭の名前になった。肉という素材まで来たのは、切り取ったものを表す古い枝があるから。肉を食べる動物とにぎやかな祝祭が同族なのは、肉の古い名前を分け合っているからなんだ。切る・切り分ける・切ったものという三つのつながりが見えてくるね。

- **切る**：切る働きと切り分けられる境界が、身体の最大の構造や動きで読めるようにする。
