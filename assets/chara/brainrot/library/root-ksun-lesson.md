## 共有する学習解説

この語根の意味は「共に」。ギリシャ語の syn- はいくつもの要素に付いて、一緒に何かをすることを表した。後ろの音に合わせて sym- や syl- に変わる形もあるので、見た目が少し違っても同じ先頭の働きを探せる。symbol は象徴や記号。sym- が共にで、後ろは投げる・合わせる側の別の要素だ。近い歴史には、二つを合わせて確かめる印や証しの感覚がある。

syllable は音節。syl- が共に、後ろは取ることを表す別の要素で、いくつかの音を一緒に取ってまとまりにする感覚になる。symmetry は対称・釣り合い。sym- が共にで、後ろは測る側。二つの側を合わせて尺度を取る感じだ。sympathy は共感や同情で、sym- が共に、後ろは感じる側なので、相手の気持ちを共に感じる。音がまとまる、形が釣り合う、気持ちが重なる。同じ「共に」が、音、形、気持ちの中で違う働きをしている。

syntax は語句の配列・文の構造。syn- が共にで、並べる側と組み合わさる。synthesis は合成で、共に置くことから、要素を組み合わせて新しいまとまりにする。synthetic は合成の。system はラテン語の systema を経た語。その元のギリシャ語の動詞 synistanai にある syn- が「共に」の側で、一緒に立たせるという組み立てから、働き合う仕組みへつながった。symptom は症状で、歴史には一緒に起こるものという感覚があり、syndrome は症候群、いくつもの兆候が一緒に現れるまとまり。どちらも sym-/syn- がこの語根の側で、走る・起こることを表す後ろの要素は、それぞれ別の語源だ。音、形、心、部品、兆候が集まってまとまりをつくる。syllable では音がまとまり、symmetry では左右が釣り合い、sympathy では気持ちが重なる。syntax は語句を並べ、synthesis は要素を合わせ、system は働き合う全体をつくる。前の「共に」が、取る、測る、感じる、置くなどの動きを組み合わせている。小さな先頭の要素が違う相手と組むだけで、音から仕組みまで一緒になる。

## 歌にするフック

syllable の音がそろい symbol の印が合う。symmetry が釣り合い sympathy が感じる。syntax で並べ synthesis、synthetic な system をつくる。symptom と syndrome、共に現れる兆しを見よう。

## 必ず見せる原義

- **共に**：左右に分かれた異なる体が中央でぴったり接続し、一つの働く全体になる。接合面の対応が見える組み合わせ型のクリーチャー。
