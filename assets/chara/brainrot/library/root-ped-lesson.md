# *ped- 足の学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

地面を踏む「足」。この語根は、歩く足から長さや道具の名前へ、いろいろな地域の枝を伸ばしたよ。ゲルマン語では古いpの音がfへ対応する変化があり、英語のfootになった。feetはその複数形。古い母音の変化が残っているので、足が二つでも単純に語尾を足す形ではないんだ。footballは足と球の組み合わせで、前半だけがこの一族。footballのfoot-が足の側で、球の部分は別の祖先。ラテン語では足をいう形がped-になり、pedalは足で動かすペダルにつながる。

pawnはチェスのポーンだけど、古い名は歩いて戦う兵士。騎馬の兵士と違って、自分の足で進む人から駒の名になったんだ。質屋で預ける品をいう同じ綴りは別の語だから、混ぜないでね。expeditionは遠征。expeditionの-ped-が足の側で、外へをいう先頭とは別の語根。古い動詞の中身は「足を外へ解く」、つまり足の束縛をほどいて出発の準備をすることだった。ギリシャ語の枝では足がpodの形になる。tripodは三脚で、前半が三、後半が足。tripodの-podが足、tri-「三」は別の家族だよ。

カメラの台そのものの語源ではなく、三つの支える足が名前の中にいるんだ。pilotはパイロットで、昔は船の水先案内人。pilotの昔のギリシャ語の枝では、pod-「足」をもとに見る伝統的な説明がある。語源をたどると、船を操るオールをいう古い語に、足を表す部分がいたと考えられている。今の航空機の操縦者へは、さらに後で意味が広がった。ペルシャ語の枝から来たpajamasはパジャマ。pajamasのpa-がペルシャ語の足・脚で、衣服をいう後ろとは別の祖先。もとの組み合わせは脚・足の衣服で、ズボンから寝間着の名へつながった。

足の音がf、ped、podになり、地域の違いを越えて再会する。ポーンが歩き、ペダルを踏み、三脚が支え、パジャマが足を包む。歩く足も、踏む足も、支える足も、古い「足」の名を受け継いでいるんだ！

## 歌にするフック

foot、feet、踏むpedal！　pawnが歩き、footballを追う。tripodは三つの足、pilotが船を導き、pajamasでおやすみ！

## 必ず見せる原義

- **足**：大きい足首から下の形が胴の大半を占め、踏み出す足と地面の関係を主役にする。

## 語源の根拠

### foot

Old English fot → Germanic *fōts → *ped-.

身体の足を指す語。タコという生き物の英語名を、このモチーフの同根語として追加しない。

[辞書の該当項目](https://www.etymonline.com/word/foot)

### feet

feetはその複数形。

feetはその複数形。

[辞書の該当項目](https://www.etymonline.com/word/feet)

### football

footballは足と球の組み合わせで、前半だけがこの一族。

1424年のスコットランドの法律で禁止された遊びだった。

[辞書の該当項目](https://www.etymonline.com/word/football)

### pedal

Latin pedalis from pes/pedis → *ped-.

足に関する Latin pedalis から。踏み板そのものを表す英単語で、足の姿勢だけと区別する。

[辞書の該当項目](https://www.etymonline.com/word/pedal)

### pawn

French peon → Latin pedonem/pes → *ped-.

チェスの駒を表す pawn n.2 のみ。質入れ・担保を表す pawn n.1 とは別語。

[辞書の該当項目](https://www.etymonline.com/word/pawn)

### expedition

expeditionは遠征。

中身は「足を外へ」。まず軍の出征を指し、旅の意味は1590年代から。

[辞書の該当項目](https://www.etymonline.com/word/expedition)

### tripod

Greek tripod- = tri- + pous/podos; pod- → *ped-.

三脚を表す複合語。足を表す -pod だけが ped- と同根で、tri-（三）は別語根。

[辞書の該当項目](https://www.etymonline.com/word/tripod)

### pilot

pilotはパイロットで、昔は船の水先案内人。

もとは船の水先案内人。語根は「足」で、舵取りのオールを指した。

[辞書の該当項目](https://www.etymonline.com/word/pilot)

### pajamas

Persian paejamah = pae (leg) + jamah (clothing); pae → *ped-.

Persian の pae（脚）の成分だけが対象語根。jamah（服）は別成分。

[辞書の該当項目](https://www.etymonline.com/word/pajamas)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **p**：印欧祖語のp。ゲルマン語ではfに対応する。 [辞書の根拠](https://www.collinsdictionary.com/dictionary/english/grimms-law)
- **f**：ゲルマン語f、古いpとの対応。 [辞書の根拠](https://www.collinsdictionary.com/dictionary/english/grimms-law)
- **ped**：Latin pes/pedisの足をいう枝。 [辞書の根拠](https://www.etymonline.com/word/pedal)
- **pod**：Greek pous/podosの足をいう枝。 [辞書の根拠](https://www.etymonline.com/word/tripod)
- **tri**：Latin/Greek tri-（三）はtripodの別語根側。 [辞書の根拠](https://www.etymonline.com/word/tripod)
- **pa**：Persian pā（足・脚）。 [辞書の根拠](https://www.etymonline.com/word/pajamas)
