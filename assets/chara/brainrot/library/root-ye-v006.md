手を離れたものが飛んでいく。この動作が芯にあり、どこへ投げるかによって意味が枝分かれした。61語のうち53語はロマンス語派で、ject という形をかかえ、前へ投げる、外へ投げる、投げ返すという具合に、接頭辞ごとに別の語になった。意外な身内は ease(容易さ)と、それを dis- で打ち消した disease(病気)で、こちらは「そばに横たわる」という楽な姿勢から来ている。subject が主題と臣民の両方を指すのは、原義が「下に投げられた者」だからである。
Current teaching explanation: この語根は「投げる」。手から離れたものが飛んでいく、あの動作が一族の芯だ。ラテン語の投げる動詞の枝は、英語で ject- の姿を多く残している。project の pro- は前へ、後ろの ject が投げる側。前へ突き出すことから、映像を投影することや、これから行う計画へ広がった。projector は映写機。光を前へ投げる道具として思い浮かべられるが、昔は計画する人にも使われた。計画も映像も、いまの場所から先へ送り出す感覚を持つ。

injection の in- は中へで、液体などを中へ送り込むこと。eject の e- は外へを表す接頭辞の姿で、取り出す・放出する。reject の re- は戻す向きで、受け入れずに投げ返す感じから拒む意味になった。rejection は拒絶だ。同じ投げる側でも、前へ、中へ、外へ、戻す、と向きを変えれば別の単語になる。機械で外へ出す、気持ちとして受け入れず返すといった意味へも広がっている。

subject はラテン語で下に置かれたものの系譜から、支配される人や、取り上げて考える題目などになった。sub- が下、投げる・置く側がその後ろだ。object の ob- は前に・向かっての要素で、目や心の前に差し出されたものが対象になる。反対意見を差し出す動詞の使い方もある。trajectory は投げ渡されたものの道筋、軌道。jet はフランス語の投げる動詞の系譜から、水の噴き出す流れを表し、後にジェット機へ広がった。project は前へ送り、eject は外へ出し、reject は戻す。それぞれの先頭が投げる向きを変えている。projector から出た映像は目の前へ届き、injection の液は中へ入る。subject は扱う題目、object は目や考えの前にある対象。飛び出す jet の線を追えば trajectory になる。物から映像、計画や考えへ、投げるものの種類も広がった。
