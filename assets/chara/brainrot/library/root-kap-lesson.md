# *kap- しっかり握るの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

手で「しっかり握る」、つかんで離さない。この語根の親戚は、ラテン語ではcapereという取る動詞、ゲルマン語ではhaveという持つ動詞へつながるよ。古い子音がそれぞれの言語で変化したので、cap-とhが遠く見えても同じ家族なんだ。captureは捕まえること・捕まえるで、握って取り込む動詞の枝。receiveは受け取るで、歴史的には戻してをいう部分と取る動詞の組み合わせ。receiveの-ceiveが取る側で、re-「戻して」は別の祖先。

英語にはcapだけでなくceiveやceptという形も残っている。conceptは概念で、もとは一緒に取り込む・心に宿すこと。conceptの-ceptが取る側で、共にをいう先頭は別の語根。考えを頭の中へつかみ取ることが、概念の名になったんだ。capacityは容量・能力で、どれだけつかんで収められるかをいう形から。exceptは～を除いてで、もとの動詞は外へ取り出す。exceptの-ceptも取る側で、外へをいう先頭は別の家族。

あるものを取りのけて、残りの話をする働きになった。recipeは料理の作り方。recipeは古いrecipereのcip-が取る側で、形を変えてこの名へ残った。もとはラテン語の「取れ」という命令で、医者が材料を取るように処方箋へ書く言葉だった。食べ物の作り方という現代の意味にも、材料を受け取る手つきが隠れているね。princeは王子で、古い名の後半は「取る」、前半は別の一族の「第一の」。princeは古いprincepsの-cepsがcapere「取る」の側、pri-「第一の」は別の祖先だよ。

第一の座を取る人という組み合わせだから、頭をいう似た綴りの語根とは区別しよう。ゲルマン語のheavyは重いで、持ち上げることに関わる古い形から、この握る一族へつながる。haveは持っている。ラテン語にも見た目と意味がよく似た動詞があるけれど、そちらをhaveの直系の祖先と考えるのは取り違えなんだ。捕まえる、受け取る、取りのける、心に収める。王子が取るのは第一の座、料理で取るのは材料。対象が変わっても、古い「つかむ・取る」が名前の中に残っているんだ！

## 歌にするフック

haveで持ち、captureでつかむ。receiveで受け取り、exceptで取り出す。conceptを心に、capacityの中へ。recipeの「取れ」で料理！

## 必ず見せる原義

- **しっかり握る**：大きな二つの把持部が中央の物をきつく抱え込む構造を主体にする。握る部分が全体の主輪郭になる。

## 語源の根拠

### have

この語根の親戚は、ラテン語ではcapereという取る動詞、ゲルマン語ではhaveという持つ動詞へつながるよ。

そっくりなラテン語 habere とは無関係。似ているのは偶然。

[辞書の該当項目](https://www.etymonline.com/word/have)

### capture

Latin captura/captus from capere → *kap-.

The claw symbolizes capture, not a claimed same-root claw noun.

[辞書の該当項目](https://www.etymonline.com/word/capture)

### receive

Latin recipere = re- + capere/cipere → *kap-.

Only -ceive/cipere is shared; re- has another origin. Parcel symbolizes modern receive.

[辞書の該当項目](https://www.etymonline.com/word/receive)

### concept

conceptは概念で、もとは一緒に取り込む・心に宿すこと。

ラテン語では「取り込む、身ごもる」。心に宿したものが概念になった。

[辞書の該当項目](https://www.etymonline.com/word/concept)

### capacity

capacityは容量・能力で、どれだけつかんで収められるかをいう形から。

ラテン語の「つかむ」から。どれだけ抱え込めるか、が原義。

[辞書の該当項目](https://www.etymonline.com/word/capacity)

### except

exceptは～を除いてで、もとの動詞は外へ取り出す。

原義は「外へ取り出す」。取りのけた分が「〜以外」になった。

[辞書の該当項目](https://www.etymonline.com/word/except)

### recipe

Latin recipe imperative of recipere → capere → *kap-.

The capere/cipere component is shared; no claim that book/food words are cognates.

[辞書の該当項目](https://www.etymonline.com/word/recipe)

### prince

Latin princeps = primus + capere → *kap-.

Only the capere/ceps component is shared; primus is separate. This is kap-, NOT kaput- head.

[辞書の該当項目](https://www.etymonline.com/word/prince)

### heavy

Germanic *hafiga → *kap-.

Weight object illustrates heavy; its tool name is not taught as same-root.

[辞書の該当項目](https://www.etymonline.com/word/heavy)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **capere**：Latin capere（取る）。 [辞書の根拠](https://www.etymonline.com/word/capture)
- **cap**：Latin capere（取る）側の語幹。 [辞書の根拠](https://www.etymonline.com/word/capture)
- **h**：ゲルマン語のhと古いkの子音対応。 [辞書の根拠](https://www.collinsdictionary.com/dictionary/english/grimms-law)
- **ceive**：Latin capere/cipereがフランス語を経た英語-ceive。 [辞書の根拠](https://www.etymonline.com/word/receive)
- **re**：Latin re-（返して・戻して）はこの語の別語根側。 [辞書の根拠](https://www.etymonline.com/word/receive)
- **cept**：Latin capereの過去分詞cept側。 [辞書の根拠](https://www.etymonline.com/word/concept)
- **recipere**：Latin recipere＝re-＋capereの変異形。 [辞書の根拠](https://www.etymonline.com/word/recipe)
- **cip**：Latin recipereの取る側の語幹。 [辞書の根拠](https://www.etymonline.com/word/recipe)
- **princeps**：Latin princeps＝primus＋capere。 [辞書の根拠](https://www.etymonline.com/word/prince)
- **ceps**：Latin princepsのcapereに関わる後半。 [辞書の根拠](https://www.etymonline.com/word/prince)
- **pri**：princepsの第一の側は別語根per1。 [辞書の根拠](https://www.etymonline.com/word/prince)
