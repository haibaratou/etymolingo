WORD MOTIFS: disguise, disconnect, dessert, dismantle
PIE meaning: 二つに・離れて
DATABASE DEFINITION: 印欧語根*dwo-(二)の副次形*dwis-「二度・二つに」に由来し、ラテン語dis-「離れて・ばらばらに」(同化形dif-、古フランス語des-)を生んだ。英語ではdishonest,discard,defeat,defameなど接頭辞dis-を持つ多くの語の祖先。bis(二度)、twice、doubleと同じ「2」の一族。
DATABASE COMMENTARY: 二つに割れて、もう一度ひとつには戻らない。この語根が持っていたのは、ただ遠ざかることではなく、もともと一体だったものが割れて別々の方向へ行ってしまう感じだった。英語に来た道はほぼ一本で、224語のほぼ全部がラテン語のdis-(離れて)を通っており、綴りのうえではdi-やdif-、時にはde-にまで姿を変えて入っている。意外な子孫はdinner(夕食)で、断食を「破る」ことから来た語である。disaster(災害)も、星回りが悪いほうへずれたという、占いの言葉だった。
