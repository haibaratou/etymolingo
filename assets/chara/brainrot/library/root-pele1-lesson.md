# *pelə-1 満たすの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

器のすみまで、いっぱいに「満たす」。たっぷりあることから、多い、足す、完成するという一族が育ったよ。ゲルマン語のfullはいっぱいの、fillは満たす。状態をいう言葉と、その状態にする動詞の兄弟なんだ。英語の語尾-fulもfullと同じ家族だから、beautifulは美しさに満ちた、powerfulは力に満ちたという作りをしている。beautiful・powerfulの-fulが満ちた側で、美しさや力の側は別の祖先。

carefullyは注意深くで、気を配ることに満ちた形容詞からできた副詞。carefullyにも-ful-が残るんだ。語尾だけがこの根で、前半の美しさや力や気がかりは別の語源だよ。ラテン語の枝では、満たす動詞からpleteやplyの姿が育った。completeは完全な・完成させるで、「すっかり満たす」が出発点。completeの-pleteが、ラテン語の満たす側。人数をそろえるなど、欠けた所を埋めた状態から完成の意味になった。

supplyは供給するで、「下から満たす」という古い組み合わせ。supplyの-plyが満たす側で、先頭の下からとは別の語根。足りないものを補うことが、物を届ける仕事へつながった。plusはプラス・さらにで、もとのラテン語は「より多い」。数が増えていっぱいになる感覚が、その短い名にもいるんだ。ギリシャ語の枝ではpoly-が多いを受け持つ。polygonは多角形で、前半が多い、後半が角という別の一族。polygonのpoly-が多い、角をいう後ろは別の家族だよ。

三角形でも五角形でも、複数の角を持つ形の仲間だよ。fullの器にfillで注いで、足りない所へsupply、そろえばcomplete。そこへplusで足して、多くの角をつけたpolygonへ進む。英語の単語は別々に暗記するだけでなく、満ちていく一つの場面でつなげられる。器や水やパズルそのものの英語まで同根ということではなく、満たす・多いという役目の部分が同じ祖先なんだ！

## 歌にするフック

fillでfull、足りない所へsupply。そろってcomplete、もうひとつplus！　beautiful、powerful、満ちた-ful。角がたくさんpolygon！

## 必ず見せる原義

- **満たす**：体内の大きい空洞がふちまで満たされ、全体が膨らむ満杯胴を主役にする。

## 語源の根拠

### full

Germanic *fullaz → *pele- (1).

The reservoir symbolizes full; the vessel name is not taught as same-root.

[辞書の該当項目](https://www.etymonline.com/word/full)

### fill

Germanic *fulljanan, derived from *fullaz → *pele- (1).

The pouring action illustrates fill; faucet is not a claimed derivative.

[辞書の該当項目](https://www.etymonline.com/word/fill)

### beautiful

英語の語尾-fulもfullと同じ家族だから、beautifulは美しさに満ちた、powerfulは力に満ちたという作りをしている。

beautiful の -ful は full と同じで「満ちている」の意。

[辞書の該当項目](https://www.etymonline.com/word/beautiful)

### powerful

英語の語尾-fulもfullと同じ家族だから、beautifulは美しさに満ちた、powerfulは力に満ちたという作りをしている。

アメリカの方言では「とても」の意の副詞にもなる(1822年)。

[辞書の該当項目](https://www.etymonline.com/word/powerful)

### carefully

carefullyは注意深くで、気を配ることに満ちた形容詞からできた副詞。

古英語では「悲しげに」の意。care がもと「悲しみ」だった名残。

[辞書の該当項目](https://www.etymonline.com/word/carefully)

### complete

Latin complere = com- + plere; plere → *pele- (1).

Only -plete/plere is the shared component; jigsaw pieces illustrate completed state.

[辞書の該当項目](https://www.etymonline.com/word/complete)

### supply

supplyは供給するで、「下から満たす」という古い組み合わせ。

原義は「下から満たす」。「提供する」の意味は1520年代から。

[辞書の該当項目](https://www.etymonline.com/word/supply)

### plus

Latin plus/*pleos → *pele- (1).

The plus symbol illustrates the modern plus word.

[辞書の該当項目](https://www.etymonline.com/word/plus)

### polygon

Greek polys + gonia; polys → *pele- (1).

Only poly- (many) shares this root; -gon is *genu- (1).

[辞書の該当項目](https://www.etymonline.com/word/polygon)
