# *dō- 与えるの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

与えると、相手へ何かが渡る。donate（寄付する）はラテン語の贈り物と与える動詞から来た枝で、donation（寄付）は渡した贈り物や、その行為を表す。自分の手元にあったものが相手のものになる。その動きが、物だけでなく、情報や薬の名前にも広がっているよ。

data（データ）は、ラテン語の与えられたものを表す名詞の複数形。計算や考えの材料として与えられたものが、今のデータの名になった。date（日付）も、文書が与えられ、出された日を示すラテン語の形から、フランス語を通った枝。日付と情報の綴りが似ているのは、この与えられたという形を分け合うからなんだ。果実のナツメヤシを表すdateは別の由来で、同じ綴りでも日付の枝とは別なんだ。

add（足す）は、ラテン語でそばへ与えるという組み合わせ。今の二つのdには、前のad-と与える動詞dareが合わさった形が残る。dose（服用する量）はギリシャ語で与えられるものから来た枝。antidote（解毒剤）の-dot-も、ギリシャ語の与える成分で、前のanti-は対抗する方向を足す。何を与えるかで、贈り物にも、足す量にも、薬にもなる。受け取る側へ何かが移るところは、どの語でも同じだね。

tradition（伝統）の-dit-は、ラテン語dareが形を変えた与える成分。前のtra-が向こうへを足すので、次の人へ渡せば伝統になる。treason（反逆）も同じラテン語の渡す名詞が別のフランス語の形を通った枝で、敵へ渡す意味から裏切りになる。render（与える・表現する）はフランス語rendre、その前のラテン語の変化形rendere、古いreddereへつながる。reddereはre-「返して」とdare「与える」の組み合わせで、この語根は与える側なんだ。渡す相手が次の世代なら受け継ぐ伝統、敵なら裏切り、元の相手なら返すこと。同じ与える動きから、贈り物にも情報にも、人との関係にも言葉が広がっているんだね。

## 歌にするフック

donate・donationで贈る。dataは与えられたもの、dateは出した日。addで足しdoseを与えantidoteで対抗。traditionは次へ渡しtreasonは敵へ、renderで返す！

## 必ず見せる原義

- **与える**：相手へ差し出す開いた主胴と伸びる肢。内部から外へ受け渡す流れが全体で読める。

## なるべく取り入れるモチーフ候補

以下は解説に登場する学習語と、造形へ取り入れるときの指針です。すべてを一体のキャラに描く必要はありません。

- **donation（寄付）**：寄付の硬貨を送り出す開口と受け皿を、胸と前肢へ融合。
- **data（データ）**：厚い情報記録の層と記憶装置が背骨と腹を作る。文字や数字を学習モチーフにしない。
- **dose（薬の一回分の量）**：一回分に分かれた薬の量を、透明な計量室と小さな容器状の手へ融合。実物の薬品銘柄は不要。
- **add（足す）**：既存の塊のそばへ節を与える手を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **date（日付）**：与えられた文書の日を示す暦の器官を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **donate（寄付する）**：相手へ贈り物を差し出す手を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **antidote（解毒剤）**：対抗する薬を与える器官を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **tradition（伝統）**：次の仲間へ形を手渡す節を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **treason（反逆）**：敵側へ秘密の形を渡す手を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
- **render（与える・表現する）**：受けたものを形にして返す口を、語根の「与える」が読める主構造へつながる立体の部位や動きとして融合する。
