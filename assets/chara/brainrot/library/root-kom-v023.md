DATABASE ROOT FOUNDATION (use meaning, never write text in art): 特に（過去）分詞・集合・強調を表す前置詞として、「…の近くに」「…と一緒に」という意味などを持つ印欧語根。重要な派生語は、enough, 接頭辞co-,com-,contra-を持つ単語（cooperate,complex,contradictなど）。ゲルマン語の接頭辞ga-, gi-, ge-を持つ語（古英語接頭辞ge-, y-を含む）。
そばに寄り集まる感じが芯にあり、そこから「みんなで」という集合の意味と、「すっかり」という強めの意味が同時に育った。英語に来た道はほぼロマンス語派で、600語近くが com-(共に)や co-(一緒に)の顔で入っている。company は「パンを分け合う仲間」が原義で、共にパンを持つことがそのまま会社の名になった。面白いのは、同じ語根から「向かい合って」を表す contra- が出て、反対向きの語まで生んだこと。country の原義は向かいに広がる土地で、寄り添うことと向き合うことは、もとは一つの感覚だった。
Current teaching explanation: この語根は「一緒に」。そばへ寄せて、一つにまとめる小さな言葉が、大勢の英単語に入りこんだよ。ラテン語のcom-が入口で、次の音に合わせてcon-やco-にも姿を変える。computerはコンピューター。そのcom-が「一緒に」の部分で、後ろはラテン語の「数える・計算する」につながる。もとの動詞は「一緒に数える」。しかもcomputerは、昔は計算を仕事にする人を指したんだ！　その呼び名が、計算する機械へ移った。

compassはコンパス。そのcom-も「一緒に」で、後ろは「歩幅」の枝。周囲を歩幅で測る感覚から、測る道具や方角を知る道具の名へ広がった。combineは「結び合わせる」で、com-「一緒に」に「二つずつ」の側が合わさっている。農機のコンバインも、刈り取りなどの作業を一緒にする機械だ。companyは会社や仲間。そのcom-は「共に」、後ろはラテン語の「パン」につながる。パンを分け合う仲間が、会社の呼び名にまで育った！

commonは「共通の」、communityは「共同体」。どちらもcom-を含むラテン語で、みんなで分け持つものや、同じ仲間の集まりを表す。contextは文脈。そのcon-はcom-の姿が変わった「一緒に」で、後ろは「織る」。文章の前後を織り合わせると意味が見える、と考えると覚えやすいね。

「向かい側・反対側」を表すラテン語contraにも、この祖語の親戚がいる。countryは国で、contraからフランス語を経て、向かいに広がる土地、地域、国の呼び名へ。controlは管理すること。同じ枝を経た「照合用の巻物」を指す名から、もう一本の記録を突き合わせて確かめる仕事、管理へつながった。一緒に数え、一緒に食べ、文章を織り、記録を突き合わせる。つながる部分の綴りを見れば、日常の言葉に古い「一緒に」が見つかる！
