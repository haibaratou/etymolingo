# *s(w)e- 自身の学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

自分、自分たちを指す「自身」。この語根は、ゲルマン語でself、ラテン語でse-という枝を育てたよ。自分の側へ取り分けることから、ほかと離すという働きも生まれたんだ。selfは自分自身。myselfは私自身、himselfは彼自身、itselfはそれ自身、themselvesは彼ら自身。myself・himself・itselfの-self、themselvesの-selvesが同じ自分の側だよ。古い英語ではselfも独立した語で、ほかの言葉と並んでいたものが、長い時間をかけて一語の形にまとまった。だから、人物が違っても後ろに同じselfの家族が見えるんだね。

ラテン語の枝では、よけて別にするse-が働く。separateは分ける・別の。separateのse-が離しての側で、用意する後ろとは別の語根。古い「離して」と「用意する」の組み合わせで、前半だけがこの語根。selectは選ぶで、「よけて拾う」。selectのse-がよけて、拾う後ろは別の家族。集める別の語根と力を合わせ、選びたい一つをほかから取り分ける名前になった。secretは秘密で、もとの名は「よけて分けたもの」。secretのse-がよけての側で、分ける後ろとは別の語根。

人に見せるものから別にして隠してあるから、秘密の意味になったんだ。severalは数個の・それぞれの。severalのse-も、別にする側を受け継いでいる。もとの意味は別々の。今の数個という意味も、まとまった一つの塊ではなく分かれたものをいう枝から育った。secureは安全な・固定されたで、古い組み合わせは「心配から離れた」。secureのse-が離れて、心配をいう後ろは別の家族。無事であることをいう意味から、守る・しっかり留めるという使い方にもつながる。

sureは確信している。フランス語を経て短くなった、secureと同じ古い名前の親戚なんだ！　自分の姿を映し、選んだものを取り分け、秘密を隠し、しっかり守る。自分をいう語と秘密をいう語がつながるのは、自分の側とほかの側を分ける感覚が受け継がれたから。秘密のsecretも安心のsecureも、古い「離して別にする」からつながっているんだね！

## 歌にするフック

myselfは自分、himselfは彼自身。selfを見つめ、selectで取り分け、separateで離す。secretをsecureに守れば、心配なくsure！

## 必ず見せる原義

- **自身**：自分の全体像が実際に映る大きい反射面を主胴にし、自分の側へ副部を取り込む囲込み姿勢を主体にする。

## 語源の根拠

### self

Germanic *selbaz, according to Watkins suffixed *s(w)e-.

Mirror illustrates self; mirror word itself is not claimed cognate.

[辞書の該当項目](https://www.etymonline.com/word/self)

### myself

myselfは私自身、himselfは彼自身、itselfはそれ自身、themselvesは彼ら自身。

もとは meself。herself などにつられて my- の形に変わった。

[辞書の該当項目](https://www.etymonline.com/word/myself)

### himself

myselfは私自身、himselfは彼自身、itselfはそれ自身、themselvesは彼ら自身。

もとは him self と二語。self は形容詞として活用していた。

[辞書の該当項目](https://www.etymonline.com/word/himself)

### itself

myselfは私自身、himselfは彼自身、itselfはそれ自身、themselvesは彼ら自身。

古英語の hit sylf(それ・自身)という二語がくっついてできた形。

[辞書の該当項目](https://www.etymonline.com/word/itself)

### themselves

myselfは私自身、himselfは彼自身、itselfはそれ自身、themselvesは彼ら自身。

self はもと形容詞。名詞「人」と見なされて複数形 selves になった。

[辞書の該当項目](https://www.etymonline.com/word/themselves)

### separate

Latin separare = se- + parare; se- → *s(w)e-.

Only se- shares the root; parare is *pere- (1). Zipper illustrates separation.

[辞書の該当項目](https://www.etymonline.com/word/separate)

### select

Latin seligere = se- + legere; se- → *s(w)e-.

Only se- shares the root; legere is separate. Finger/button symbolize selection.

[辞書の該当項目](https://www.etymonline.com/word/select)

### secret

Latin secretus/secernere = se- + cernere; se- → *s(w)e-.

Only se- shares the root; cernere is *krei-. Envelope illustrates concealed secret.

[辞書の該当項目](https://www.etymonline.com/word/secret)

### several

severalは数個の・それぞれの。

原義は「別々の」。ラテン語 separ 由来で、「数個の」は後の意味。

[辞書の該当項目](https://www.etymonline.com/word/several)

### secure

Latin securus = se- + cura; se- → *s(w)e-.

Only se- shares the root; cura is separate. Padlock depicts secured state.

[辞書の該当項目](https://www.etymonline.com/word/secure)

### sure

sureは確信している。

secure と綴りが分かれただけの同じ語。原義は「心配がない」。

[辞書の該当項目](https://www.etymonline.com/word/sure)
