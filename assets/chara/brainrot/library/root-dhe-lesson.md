# *dhē- 置くの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

ものを「置く」、しっかり据える。そこから、何かをする・作るという大きな一族が育ったよ。ゲルマン語の枝にいるdoは「する」で、古い置く動作が広がった言葉。deedは行いで、置かれた・行われたことを指す仲間だ。見た目が全然違うラテン語の枝にはfacere、作るという動詞がいる。もとの子音の変化や語の作り方が違うため、英語ではdoとfac-の形が並んでいるんだ。factは事実だけど、昔の名前は「行われたこと」。factoryは工場で、作る人や作る場所をいう言葉から育った。

officeはオフィス・職務。officeは古いofficiumのficが、facere「作る」の側。古い組み合わせの後半が「作る・行う」で、仕事を行う役目から働く場所の名へ広がったよ。effectは効果で、もとは「作り出されたこと」。effectの-fect-も、作る動詞が複合語の中で変わった形だよ。specificは特定のという意味で、種類を「作る」側の部分がこの根に参加している。specificの-fic-が、facere「作る」の側。

顔をいうfaceにも、ラテン語の姿・見た目という言葉がある。これを「作る」一族へ結びつける伝統的な説をこのデータベースは採っているけれど、直接の結びつきには留保があるんだ。その顔の上にある面、surfaceは表面で、同じ顔・面の言葉を使った別の組み合わせ。surfaceの-faceが顔・面の枝で、sur-「上に」は別の祖先。顔を作ったからという作り話ではなく、昔の「形・見た目」が今の顔や面へ狭まったという話だよ。さらにギリシャ語の枝にはtheme、テーマがいる。もとの意味は「置かれたもの」、話し合うために据えた題がテーマになった。

作業をする、工場で作る、話の題を置く。原義の置く手つきから言語の枝をたどれば、行動と物作りと考える題が一つの家族に見えてくる！

## 歌にするフック

置いてdo、行えばdeed。作ってfactory、できたことはfact。officeで仕事、effectは結果。themeを置いて、次は何を作る？

## 必ず見せる原義

- **置く**：大きな台座状の体に組立て部品を上から据えつける動きを主役にする。部品が空中で台へ降りる関係を明瞭にする。

## 語源の根拠

### do

ゲルマン語の枝にいるdoは「する」で、古い置く動作が広がった言葉。

語根は「置く」。その名残が do away with に残っている。

[辞書の該当項目](https://www.etymonline.com/word/do)

### deed

Old English dæd ← Proto-Germanic *dethi- ← PIE *dheti-, suffixed *dhe-.

行われた・置かれたことをいうゲルマン語の派生。

[辞書の該当項目](https://www.etymonline.com/word/deed)

### fact

factは事実だけど、昔の名前は「行われたこと」。

原義は「行われたこと」。16〜17世紀には「悪事」の意でも使った。

[辞書の該当項目](https://www.etymonline.com/word/fact)

### factory

French factorie / Late Latin factorium ← Latin factor ← facere「作る」< PIE *dhe-。

工場建物・製造設備で現代意味を描く。設備の個別名まで同根とは主張しない。

[辞書の該当項目](https://www.etymonline.com/word/factory)

### office

Latin officium（opificium の短縮）= ops + facere。facere < PIE *dhe-。

共有部分は officium の facere 部分。事務机が見える業務用建物で現代意味を示す。

[辞書の該当項目](https://www.etymonline.com/word/office)

### effect

effectは効果で、もとは「作り出されたこと」。

ex(外へ)+facere(作る)。作り出されて外に出たものが「結果」。

[辞書の該当項目](https://www.etymonline.com/word/effect)

### specific

specificは特定のという意味で、種類を「作る」側の部分がこの根に参加している。

原義は「一つの種を成す」。species(種類)から生まれた語。

[辞書の該当項目](https://www.etymonline.com/word/specific)

### face

French face ← Vulgar Latin *facia ← Latin facies、facere「作る」と関連するとされる < PIE *dhe-。

faciesはfacereの一族とされるが、Etymonlineは関連を留保付きで説明する。確定した直接派生とは断定しない。

[辞書の該当項目](https://www.etymonline.com/word/face)

### surface

その顔の上にある面、surfaceは表面で、同じ顔・面の言葉を使った別の組み合わせ。

sur(上)+face の「上の面」。ラテン語 superficies を写した造語。

[辞書の該当項目](https://www.etymonline.com/word/surface)

### theme

Greek thema (something set down) ← suffixed PIE *dhe-; via Latin/French to English.

提示して置かれた題をいうギリシャ語の枝。

[辞書の該当項目](https://www.etymonline.com/word/theme)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **facere**：Latin facere（作る）、dheの枝。 [辞書の根拠](https://www.etymonline.com/word/factory)
- **fac**：Latin facereの作る語幹。 [辞書の根拠](https://www.etymonline.com/word/factory)
- **officium**：Latin officiumにopificiumの省略形があり、facereのficが共有側。 [辞書の根拠](https://www.etymonline.com/word/office)
- **fic**：複合語で現れるLatin facereのfic側。 [辞書の根拠](https://www.etymonline.com/word/office)
- **fect**：facereの過去分詞のfect側。 [辞書の根拠](https://www.etymonline.com/word/effect)
- **sur**：French sur-（上に）はsurfaceの別語根側。 [辞書の根拠](https://www.etymonline.com/word/surface)
