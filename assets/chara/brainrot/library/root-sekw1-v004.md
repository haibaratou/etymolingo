## 共有解説
この語根の芯は「追う」。後ろからついていくことが、順番にも仲間づきあいにも広がった。ラテン語では sequi が「ついていく」。sequence は順に続く列や出来事の並びで、音や数字が一つの後に続く場面を思い浮かべられる。second は二番目。ラテン語の近い祖先は「続くもの・次のもの」という意味で、最初の後に続くから二番目になった。secondary は二次的な・第二の。時計の短い時間単位にも second が使われるのは、時間を最初に分けた分を、さらに二回目に小さく分けた歴史による。

consequence は結果。ある出来事に続いて起こることだ。consequence の sequ- がこの一族の続く側で、先頭の con- は共に・まとめてを添える要素。subsequent は後に続く。sequent- がラテン語のついていく動詞の分詞の姿で、sub- が後からという向きを添えている。種をまけば芽が出るように、出来事が次へつながる。原因の後を追いかける結果、と覚えるとつながりが見えるね。sequence、second、consequence を順に並べれば、ただの数の列から、小さな物語の順番へ進める。

ラテン語にはついていく相手、仲間を表す枝もあり、social と society の soci- がその仲間の側だ。social は社会の・人と付き合う、society は社会や集まり。association は仲間になることや団体だ。association の soci- の側が、仲間を表すこの枝に属する。一人で追いかける動きが、一緒についていく関係へ育った。suit も、フランス語の続くもの・一組の系譜から来ている。上着とズボンがそろったスーツや、トランプの同じ組などに使われ、動詞なら似合う・合うという意味。suitable は合った・ふさわしい。追うだけの祖先から、並ぶ、そろう、付き合うまで広がったのだ。学校では二番目の second が最初の後を追い、服では suit の上下が一組にそろう。相手に合うものなら suitable。人の集まりは society、付き合いに関わるものなら social。列の一つずつを追う時も、仲間に続いて進む時も、ばらばらのものが順序や関係を持っている。次に続くものを探すと、この一族の意味が身近になる。
