# *ghel-2 輝くの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

輝くものを見ると、心まで明るくなる。gold（金）は古英語の枝で、黄色く輝く金属の名。yellow（黄色）も古英語からの色の枝だ。glow（赤々と光る・輝き）も、熱いものが光る古い英語の形を受け継ぐ。金属の固い輝きと、熱く光る柔らかい輝き。今の見え方は違っても、光り方をたどると、色や材料の名前へ分かれた祖先が見えるね。

glass（ガラス）は、光を受けて輝く材料の名として古英語から来た。glitter（きらきら光る）は古ノルド語を通った枝で、細かく光る様子を表す。glare（まぶしい光・にらむ）は、古いきらめく動詞から、強すぎる光や鋭い視線へ広がった語。glad（うれしい）も、明るいという古い形から、心が明るいことへ育った。物がきらめくことと、心が晴れて嬉しくなることを、どちらも明るいと表した枝なんだね。

ギリシャ語の色の枝はchlor-。chlorophyll（葉緑素）のchlor-が緑がかった色の成分で、後ろには別の葉の言葉がついている。古い黄色や黄緑の色の区別が言語ごとに違う色名へ育ったので、金色と葉の色が一族になる。葉がこの語根なのではなく、葉の色を作る部分に注目すると、形と意味の共有箇所が見えるね。

もう一つ意外な語がmelancholy（憂うつ）。-chol-はギリシャ語の胆汁の名前で、その黄緑っぽい色の枝につながる。前のmelan-は別の黒の言葉。昔の医学では黒い胆汁が気分に関係すると考えられ、そこから憂うつな気持ちの名になった。現在の原因の説明ではなく、名付けの歴史だよ。嬉しさと憂うつという反対の気分が同族になるのは、名前の生まれた道が違うから。片方は心の明るさ、もう片方は昔の体液の色の説明を受け継ぐ。色の言葉が気持ちの名前へ育つ道にも、色々な枝があるんだね。

## 歌にするフック

gold・yellowが光りglowになる。glassがglitter、強い光はglare、明るい心はglad。chlorophyllは葉の色、melancholyは古い色の医学から気分の名！
