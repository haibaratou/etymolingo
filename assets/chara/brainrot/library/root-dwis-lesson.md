# *dwis- 二つに・離れての学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

一つだったものが「二つに・離れて」。この語根は数の二につながる形で、別々にする、元の状態をほどく力を育てたよ。ラテン語のdis-から、次の音や途中の言語によってdif-やdi-、フランス語のdes-にも姿を変えた。disconnectは「接続を切る」。そのdis-が、つながりを離す部分だ。distanceは距離で、dis-「離れて」と「立つ」が合わさった名。differenceは違い。そのdif-はdis-の姿が変わった部分で、古い組み合わせは「別々に運ぶ」。離れたものの違いをいう名になったんだ。

diseaseは病気。そのdis-は後ろの「楽な状態」を打ち消す部分。difficultは難しいで、dif-がラテン語の「簡単にできる」を打ち消している。直接物を二つに割るだけでなく、状態を否定する働きもあるんだね。disguiseは変装で、dis-が姿や様子を変える働きを受け持つ。dismantleは解体する。そのdis-に、古い「マント・覆い」の言葉が合わさり、覆いを取り去ることから物の構造を取り外す意味へ広がった。

ここで驚きの食べ物組、dinnerとdessert！　dinnerは主な食事で、古いフランス語disnerのdis-にこの家族がいる。もとの意味は「断食をやめる」。昔は朝や昼にも使われ、食事の時刻がだんだん遅くなった。dessertはデザート。フランス語desservirのdes-「取り去る」と、給仕する側の言葉から来た名前だ。食卓に出した料理や皿を片づけることから、食後の最後の一品の名になった。甘いから同じ仲間なのではなく、元の状態をほどく部分が共通なんだ。

directは「導く・まっすぐの」。そのdi-も古いdis-の変異形だけど、ここでは動作を強める働きで、後ろの「まっすぐ整える」と合わさっている。離す、否定する、強める。同じ古い部品から違う働きが育ったんだね。つなぎ目を外し、変装し、断食をやめ、食卓を片づける。綴りと意味の変化を歌えば、変装と料理の意外な親戚関係も見えてくる！

## 歌にするフック

disconnectで離し、distanceを開く。disguiseで姿を変え、dismantleでほどく。断食をやめてdinner、片づけてdessert、違いはdifference！

## 必ず見せる原義

- **二つに・離れて**：ひとつだった胴が二つの大きい節へ分かれ、左右へ離れる構造を主体にする。切れ目と離れる方向を最も大きく見せる。

## 語源の根拠

### disconnect

English dis- + connect; dis- ← Latin dis- ← *dwis-

抜けたプラグ・ソケットで動作を表す。plug自体を同根としない。

[辞書の該当項目](https://www.etymonline.com/word/disconnect)

### distance

distanceは距離で、「離れて立つ」という組み合わせだ。

はじめは「不和、いさかい」の意。空間の隔たりを指すのは後から。

[辞書の該当項目](https://www.etymonline.com/word/distance)

### difference

differenceは違いで、「別々に運ぶ」から、離れたものの違いをいう名になった。

dis(離して)+ferre(運ぶ)で「別々に運び去る」が原義。

[辞書の該当項目](https://www.etymonline.com/word/difference)

### disease

diseaseは病気だけど、古い意味は楽な状態を打ち消すこと。

ease「楽」を dis- で打ち消した語で、もとは「不快、不便」だった。

[辞書の該当項目](https://www.etymonline.com/word/disease)

### difficult

difficultは難しいで、ラテン語の「簡単にできる」を打ち消した枝につながる。

名詞 difficulty から後づけで作られた語。形容詞の方が後発だった。

[辞書の該当項目](https://www.etymonline.com/word/difficult)

### disguise

French desguiser ← des- + guise; des- ← Latin dis- ← *dwis-

maskの語まで同根としない。guiseは別の*weid-由来。

[辞書の該当項目](https://www.etymonline.com/word/disguise)

### dismantle

French desmanteler ← des- + manteler; des- ← Latin dis- ← *dwis-

取り外された構造部品で表す。

[辞書の該当項目](https://www.etymonline.com/word/dismantle)

### dinner

Old French disner ← Vulgar Latin *disieiunare ← dis- + ieiunare; dis- ← PIE *dis- ← *dwis-

皿と料理はdinnerの意味の象徴。plateや肉・野菜名まで同根とは扱わない。

[辞書の該当項目](https://www.etymonline.com/word/dinner)

### dessert

French dessert ← desservir ← des- + servir; des- ← Latin dis- ← *dwis-

ケーキやプリンはdessertの象徴。cake/pudding自体を同根とは扱わない。

[辞書の該当項目](https://www.etymonline.com/word/dessert)

### direct

directは導く・まっすぐの。

dis-(離れて)+regere(まっすぐ導く)で、まっすぐ差し向けること。

[辞書の該当項目](https://www.etymonline.com/word/direct)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **dis**：Latin dis-（離れて、分けて、否定・強調にも）。 [辞書の根拠](https://www.etymonline.com/word/dis-)
- **dif**：Latin dis-が後続fへ同化したdif-。 [辞書の根拠](https://www.etymonline.com/word/difference)
- **di**：Latin dis-の変異形di-。 [辞書の根拠](https://www.etymonline.com/word/direct)
- **des**：Old French des-、Latin dis-の後継形。 [辞書の根拠](https://www.etymonline.com/word/dessert)
- **disner**：Old French disner、断食を解くdinnerの歴史形。 [辞書の根拠](https://www.etymonline.com/word/dinner)
- **desservir**：French desservir（食卓の給仕を取り去る）、dessertの歴史形。 [辞書の根拠](https://www.etymonline.com/word/dessert)

- [Merriam-Webster: dis-](https://www.merriam-webster.com/dictionary/dis-)：ラテン語dis-/di-のapart/asunder/in twoは確認可能。さらに古いduisとの結びつきはconventionally linked、起源はuncertain originとされる。DBのdwis分類を維持し、説明では確実性を区別。
