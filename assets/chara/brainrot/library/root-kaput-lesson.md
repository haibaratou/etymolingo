# *kaput- 頭の学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

頭は体の上にあり、ものの先頭や中心にもなる。head（頭）は古英語の枝。同じ祖先がラテン語ではcaput、その形が変わるとcapit-となり、別々の言語の名前へ分かれた。captain（船長・隊長）はラテン語の首長がフランス語を通った語で、皆を率いる頭の人になる。身体の頭と、仲間の先頭に立つ人。同じ頭の意味を、物の位置から集団の役目へ広げた名前なんだね。

chief（長・主なもの）は、caputが古フランス語で形を変えて英語へ来た枝。chef（料理長）は、フランス語の料理の長を表す言い方を短くした語だから、同じ頭でも料理の仲間を率いている。chapter（章）は、ラテン語の小さな頭を表す形から、本を分ける小さな先頭の名になった。頭・船長・料理長・章の始まり。現代の綴りが離れていても、皆をまとめる頭の働きがつながっている。

capital（資本・首都・大文字）は、ラテン語で頭に属する、主なものという形から来た。主な町なら首都、文章の頭にある大きな字なら大文字、もとの大事な資金なら資本になる。cattle（牛・家畜）も、ラテン語の財産を表す同じ枝が古北フランス語で短くなった語。昔の財産という意味が家畜へ絞られたので、牛とお金が同族になるんだ。頭の意味を抜かず、主要なものから財産へ育つ道を見つけると驚きがよく伝わるね。

biceps（上腕二頭筋など）の-cepsは、ラテン語caputの頭が組み合わせの中で変わった形。前のbi-は別の二の一族なので、二つの頭、つまり筋肉の二つの起点を持つ名前になる。forehead（額）のheadは、そのまま頭で、前には別の前側の成分がつく。cabbage（キャベツ）は古北フランス語の頭から来た野菜の名で、丸い葉の塊を頭に見たんだ。その古語をラテン語caputの変化とする説明には推定も含まれる。丸い野菜の頭、筋肉の起点の頭、皆を率いる頭、大事な資金。同じ頭の祖先が、体の位置、中心になる役目、財産の名前へ育った道が分かるね。

## 歌にするフック

head・captain・chief・chefは頭の仲間。chapterは小さな頭、capitalは主な町・字・資金。cattleは財産の枝、bicepsは二つの頭、cabbageは丸い頭！

## 必ず見せる原義

- **頭**：頭が身体の最大の特徴になり、頭の形や位置が一目で分かる構造にする。

## なるべく取り入れるモチーフ候補

以下は解説に登場する学習語と、造形へ取り入れるときの指針です。すべてを一体のキャラに描く必要はありません。

- **cabbage（キャベツ）**：巻いた葉の塊そのものを大きな頭にする。
- **captain（キャプテン・船長）**：かわいい船長の顔と船長帽を頭の表情と上部構造へ融合。おじさん顔に固定しない。
- **biceps（上腕二頭筋）**：二つの起始部を持つ盛り上がった上腕の筋肉構造を前肢に融合。
- **cattle（ウシ・家畜）**：牛らしい鼻、蹄、胴の量感を下半身の本体へ融合。別の牛を添えるだけにしない。
- **capital（資本）**：仕事の元手を表す立体の硬貨と道具を収納する胸腹の構造へ融合する。頭が全体を率いる形を保ち、柱頭の造形では代用しない。
- **head（頭）**：最も大きい主構造としての頭を、語根の「頭」が読める主構造へつながる立体の部位や動きとして融合する。
- **chief（長・主なもの）**：仲間をまとめる長の頭を、語根の「頭」が読める主構造へつながる立体の部位や動きとして融合する。
- **chef（料理長）**：調理する腕を導く料理長の可愛い頭を、語根の「頭」が読める主構造へつながる立体の部位や動きとして融合する。
- **chapter（章）**：本の区切りの先頭に頭状の節がつく構造を、語根の「頭」が読める主構造へつながる立体の部位や動きとして融合する。
- **forehead（額）**：頭の前側がはっきり張り出した輪郭を、語根の「頭」が読める主構造へつながる立体の部位や動きとして融合する。
