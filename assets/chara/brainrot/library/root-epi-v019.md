# エピ・オポーネント / root-epi-v019

3語の意味を造形で表すねんどろいど体型のワイルドワード。探索候補・未採用。

## 造形
対戦盤とハードルを観察する戦術家。

## 原義
近くに

## モチーフ
- opponent（対戦相手）：向かい合う表情や対戦用グローブで描く。glove/boxは同根ではない。
- obstacle（障害物）：障害物のバー・ハードルで描く。bar/hurdleは同根ではない。
- observe（観察する）：大きな目が近くの対象をじっと見ている形でobserveを描く。eyeという語は同根ではない。servareも別語根*ser- (1)。

## 共有解説
何かの「近くに」、その相手へ向き合う。印欧祖語のこの一族は、ラテン語でob-、ギリシャ語でepi-という形を育てたよ。ラテン語には、前へ出す、ぶつかる、行く手にあるという感覚がいる。ob-は次の音に合わせてop-やof-にも変わるから、綴りが違っても同じ先頭部分のことがあるんだ。opponentは対戦相手で、「向かいに置かれた者」。opponentのop-が、向かってをいうob-の変わった形だよ。oppositeは反対側のだから、向かい合わせの同じ兄弟だ。oppositeのop-も同じ側で、置く後ろとは別の語根。

obstacleは障害物で、前に立って進みを止める物。obstacleのob-が前へ、後ろが立つ別の家族なんだ。立つ側の語根は別だけど、向かってくる先頭の意味が共通している。objectは物体・対象、そして反対するという動詞でも使う。objectのob-が前へ、後ろが投げる側だよ。もとの組み合わせは「前に投げ出す」で、目の前のものにも、相手へ突きつける反論にもなった。offerは提供する。offerのof-が相手へをいう側で、運ぶ後ろとは別の祖先。

相手の方へ運んで差し出す動詞から来た親戚だよ。observeは観察する・守るで、対象へ注意を向けて見守る古い動詞へつながる。observeのob-が対象へをいう側なんだ。obviousは明らかな。obviousのob-が前に、後ろは道の別の語根。古い名は「行く手にある」。通り道にあるから見逃しにくい、という発想なんだ。occurは起こる・思い浮かぶで、もとはこちらへ走って出会うこと。occurのoc-が、相手へ向かうob-の変わった形だよ。

opportunityは機会。opportunityのop-が向かっての側で、港をいう後ろとは別の祖先。古い名には「港に向かって」という組み合わせがあり、港へ進むのに都合のよい状態から、よい機会の意味が育った。ギリシャ語のepisodeは番組の一回・エピソード。昔の劇で合唱の間へ役者が入って来る場面を指し、何かへ加えて入るepi-が働いている。相手、障害物、差し出すもの、港、劇の入り場。向き合う小さな部分が、出会いにも対決にも物語の一回にもなるんだ！
