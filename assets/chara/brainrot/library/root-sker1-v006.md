DATABASE ROOT FOUNDATION (use meaning, never write text in art): 切ること(To cut)を表す印欧語根。shearの由来として、切ること。share(1)の由来として、部分・分割。他の重要な派生語は、screen,sharp,short,skirtなど。
刃を入れて断ち切り、切り分けた一片を取り出す。その「一片」という感覚がこの語根の芯にあって、切られたものは短くなり、縁は鋭くなる。英語にはゲルマン語派とロマンス語派からほぼ同数の36語ずつが入り、前者は「短い」「分け前」といった素朴な語に、後者はラテン語 caro「肉」の一族になった。その肉ももとは切り取った一片のことで、だから carnival「謝肉祭」は、断食前に肉を食べ納めする日としてこの語根につながっている。shirt と skirt が同じ一語の分身だというのも、どちらも布を切り取った一片だったからである。
Current teaching explanation: 切ると、一つだったものが分かれる。その切り口から、服も形も、分け合うものも生まれるよ。shear（切る・刈る）は古英語から来た言葉で、shears（大ばさみ）は刈る道具。shirt（シャツ）は古英語の枝、skirt（スカート）は古ノルド語から来た枝で、もとは近い形の服の名前だった。北の言葉ではskの音が残り、英語の枝ではshになったので、今では別の服でも、音の道をたどると兄弟が見える。

share（分け前・分け合う）も切り分けたものという枝から育った。切って一人ずつへ渡すと、みんなの分け前になる。short（短い）は、切り詰めたような形に関係する言葉。sharp（鋭い）では、切るための鋭さが姿に出ている。切るための鋭さ、切ったあとの短さ、切り分けてもらった取り分。同じ動作を見る場所を変えると、別々の英単語の意味がつながるんだ。

score（点数・刻み目）は古ノルド語の切り込みから来た。木などに刻みを付けて数えれば、切った線が数の記録になる。その記録の意味が、試合の点数へ広がった。今は数字で表示しても、点数の名前の奥には、印を一つずつ切り込んで残す古い数え方があるんだね。

ラテン語には肉を表すcaroがある。carnivore（肉食動物）のcarni-がこの肉の成分で、食べる側は別の一族。carnival（カーニバル）のcarni-も肉で、もとの組み合わせは肉を取り除くことへつながり、肉を控える時期の前の祝祭の名前になった。肉という素材まで来たのは、切り取ったものを表す古い枝があるから。肉を食べる動物とにぎやかな祝祭が同族なのは、肉の古い名前を分け合っているからなんだ。切る・切り分ける・切ったものという三つのつながりが見えてくるね。
