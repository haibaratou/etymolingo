# *wegh- 行くの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

動いて行くものは、人も荷物も運べる。wagon（荷車）はゲルマン語の枝、way（道）は古英語からの枝で、車が進む動きと、その進む道が同じ祖先を受け継いでいる。weigh（重さを量る）とweight（重さ）も古英語の枝。物を持ち上げて運ぶ、手で重さを確かめる動きから、重さを量る意味へ伸びたんだ。車と秤が同族なのは、どちらも物を動かす体の仕事があるからだよ。

ラテン語の枝にvehicle（乗り物）がある。運ぶという動詞から作られた名前で、wagonより形が大きく違うけれど、どちらも荷物や人を運ぶもの。via（〜経由で）はラテン語の道がそのまま英語に入った形だ。乗り物が道を行き、物を持ち上げて運ぶ。その動きのどこを名付けるかで、道、車、重さという違う意味が育ったんだね。

obvious（明らかな）の-vi-は、この道の枝。ラテン語で道に立ちはだかる、目の前で出会うことを表した組み合わせが、見れば分かるという意味に育った。previous（前の）の-vi-も道で、前を行くことが、時間でも前にあったことへ広がった。目の前の道と、先に行った道が、考えや時間を表す言葉になっているんだ。

convey（運ぶ・伝える）の-veyは、道を表す古いラテン語がフランス語で変わった形。convoy（護送・船団）の-voyも同じ枝から、違う形で英語に入った。道を一緒に行く言葉が、荷物を運ぶことや、守りながら集団で進むことになった。目に見える荷車だけでなく、声で意味をconveyすることもできる。物を運ぶことと意味を伝えることは、どちらも一方から他方へ届ける。動くものを変えると、行くという祖先が言葉のやり取りへも広がるんだね。

wagonがwayを行く。weighで量ったweightをvehicleが運ぶ。viaで道を通り、obviousは目の前、previousは先に。conveyで伝え、convoyで一緒に進む！

- **行く**：進む方向と移動する働きが、身体の最大の構造や動きで読めるようにする。
