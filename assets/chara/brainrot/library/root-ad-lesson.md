## 共有する学習解説

向こうの相手「～へ」近づき、ぴたっと触れる。この接近の感覚が、くっつける、加える、注意を向けるという英単語へ育ったよ。ゲルマン語の枝には場所をいうatが残り、接近や利用の機会をいうaccessも、ラテン語で「～へ進む」という枝から来た。accessのac-が、次の音に合ったad-「～へ」の姿。ラテン語の枝にはad-がいる。ad-は次の音に合わせて形を変えるので、ap-やac-が見えても、別の祖先とは限らないんだ。approachは近づく。approachのap-が「～へ」の側。古い組み合わせは「もっと近くへ」で、相手との距離が縮む動詞だ。

adhesiveは接着剤・接着するで、ラテン語の「～へ」と「くっつく」が合わさっている。adhesiveのad-が「～へ」で、くっつく側とは別の祖先。appはアプリで、applicationの短縮。app・application・applyのap-も、古いad-が次の音へ合わせた形だよ。もとの動詞applyは「～へ折りつける・当てる」から、道具や考えを使うことになった。applicationは適用・申請・アプリケーションのことで、このapplyから育った名なんだ。

attentionは注意。attentionのat-が「～へ」の側で、後ろは伸ばす別の語根。心を相手へ伸ばすと考えた名前だよ。additionは追加で、「～へ与える」、つまり今あるものへ足すこと。additionのad-が、与える先へをいう側だよ。accountは口座や説明。accountのac-が「～へ」の側。歴史をたどると数を数え上げる動詞があり、先頭の「～へ」もこの仲間だ。advertisementは広告で、気持ちを対象のほうへ向けさせる古い動詞につながる。advertisementのad-も対象へをいう側で、向きを変える後ろの語根と組になっている。

見る人の注意を引く仕事なんだね。accordionはアコーディオン。accordionのac-が「～へ」の側、心をいう後ろとは別の祖先。楽器名のもとには、音の調和を表す言葉があり、さらに心を相手へ合わせるラテン語の組み合わせへつながる。amountは量・総計だけど、古い動詞は「山へ登る」。amountは古いa montのaがadにつながり、山をいうmontは別の語源なんだ。積み上がってある量へ達することが、合計の名前になった！　接着剤、アプリ、広告、楽器、足し算。古い「～へ」という部分が、それぞれ違う相手へ寄っていく。くっつく相手も向かう先も違うけれど、その名前の先頭には、相手へ近づく古い感覚が残っているんだ！

## 語源の根拠

### at

ゲルマン語の枝には場所をいうatが残り、接近や利用の機会をいうaccessも、ラテン語で「～へ進む」という枝から来た。

ドイツ語では消えた語。北欧では逆に to を追い出して居座った。

[辞書の該当項目](https://www.etymonline.com/word/at)

### access

ゲルマン語の枝には場所をいうatが残り、接近や利用の機会をいうaccessも、ラテン語で「～へ進む」という枝から来た。

14世紀の意味は「熱の発作」。病が「やって来る」ことを指した。

[辞書の該当項目](https://www.etymonline.com/word/access)

### approach

approachは近づく。

原義は「もっと近くへ」。ラテン語 prope(近い)の比較級から。

[辞書の該当項目](https://www.etymonline.com/word/approach)

### adhesive

Latin adhaerere = ad- + haerere。ad- < PIE *ad-。

共有部分は ad-。接着剤の粘る見た目を描き、glueという別単語が同根だとは主張しない。

[辞書の該当項目](https://www.etymonline.com/word/adhesive)

### app

app ← application / apply ← Latin applicare = ad- + plicare。

appはapplicationの短縮。共有部分は歴史的ap- < ad-。端末や画面はアプリを示す図像で、phone等は同根と主張しない。

[辞書の該当項目](https://www.etymonline.com/word/app)

### application

Latin applicatio/applicare ← ad- + plicare; ad- ← PIE *ad-.

共有部はap- < ad-。「～へ」と折る・当てる側を組み合わせた。

[辞書の該当項目](https://www.etymonline.com/word/application)

### apply

French aploiier ← Latin applicare ← ad- + plicare; ad- ← PIE *ad-.

共有部はap- < ad-。折る部分は別根。接触させることから適用する意味へ。

[辞書の該当項目](https://www.etymonline.com/word/apply)

### attention

attentionは注意。

字義は「〜へ伸ばすこと」。注意とは心を対象のほうへ伸ばすことだった。

[辞書の該当項目](https://www.etymonline.com/word/attention)

### addition

additionは追加で、「～へ与える」、つまり今あるものへ足すこと。

ad-「〜へ」+ dare「与える」で、原義は「加え与えること」。

[辞書の該当項目](https://www.etymonline.com/word/addition)

### account

accountは口座や説明。

「数え上げること」が原義。もとのラテン語 putare は「枝を刈る」だった。

[辞書の該当項目](https://www.etymonline.com/word/account)

### advertisement

French avertissement / avertir ← Latin advertere = ad- + vertere。

共有部分は ad-/av-。文字なしの製品広告面で現代意味を描く。看板という別単語全体の同根性は主張しない。

[辞書の該当項目](https://www.etymonline.com/word/advertisement)

### accordion

German Akkordion ← Akkord ← accord / *accordare = ad- + cor。

共有部分は ac- < ad-。楽器の蛇腹・鍵盤で現代意味を示す。

[辞書の該当項目](https://www.etymonline.com/word/accordion)

### amount

French amonter/amont ← a mont; a ← Latin ad ← PIE *ad-.

共有部は歴史的a- < ad-。mountainをいう後半は別語根。数量へ達する動詞から量の名になった。

[辞書の該当項目](https://www.etymonline.com/word/amount)

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **ac**：ad-がk音の前でac-へ同化。 [辞書の根拠](https://www.etymonline.com/word/access)
- **ad**：Latin ad-（～へ）。 [辞書の根拠](https://www.etymonline.com/word/ad-)

- **a**：French a（～へ）、Latin adに由来。 [辞書の根拠](https://www.etymonline.com/word/amount)
- **mont**：French mont（山）は別語根。a montがamountの前段階。 [辞書の根拠](https://www.etymonline.com/word/amount)
