DATABASE ROOT FOUNDATION (use meaning, never write text in art): 印欧語根*dwo-(二)の副次形*dwis-「二度・二つに」に由来し、ラテン語dis-「離れて・ばらばらに」(同化形dif-、古フランス語des-)を生んだ。英語ではdishonest,discard,defeat,defameなど接頭辞dis-を持つ多くの語の祖先。bis(二度)、twice、doubleと同じ「2」の一族。
二つに割れて、もう一度ひとつには戻らない。この語根が持っていたのは、ただ遠ざかることではなく、もともと一体だったものが割れて別々の方向へ行ってしまう感じだった。英語に来た道はほぼ一本で、224語のほぼ全部がラテン語のdis-(離れて)を通っており、綴りのうえではdi-やdif-、時にはde-にまで姿を変えて入っている。意外な子孫はdinner(夕食)で、断食を「破る」ことから来た語である。disaster(災害)も、星回りが悪いほうへずれたという、占いの言葉だった。
Current teaching explanation: 一つだったものが「二つに・離れて」。この語根は数の二につながる形で、別々にする、元の状態をほどく力を育てたよ。ラテン語のdis-から、次の音や途中の言語によってdif-やdi-、フランス語のdes-にも姿を変えた。disconnectは「接続を切る」。そのdis-が、つながりを離す部分だ。distanceは距離で、dis-「離れて」と「立つ」が合わさった名。differenceは違い。そのdif-はdis-の姿が変わった部分で、古い組み合わせは「別々に運ぶ」。離れたものの違いをいう名になったんだ。

diseaseは病気。そのdis-は後ろの「楽な状態」を打ち消す部分。difficultは難しいで、dif-がラテン語の「簡単にできる」を打ち消している。直接物を二つに割るだけでなく、状態を否定する働きもあるんだね。disguiseは変装で、dis-が姿や様子を変える働きを受け持つ。dismantleは解体する。そのdis-に、古い「マント・覆い」の言葉が合わさり、覆いを取り去ることから物の構造を取り外す意味へ広がった。

ここで驚きの食べ物組、dinnerとdessert！　dinnerは主な食事で、古いフランス語disnerのdis-にこの家族がいる。もとの意味は「断食をやめる」。昔は朝や昼にも使われ、食事の時刻がだんだん遅くなった。dessertはデザート。フランス語desservirのdes-「取り去る」と、給仕する側の言葉から来た名前だ。食卓に出した料理や皿を片づけることから、食後の最後の一品の名になった。甘いから同じ仲間なのではなく、元の状態をほどく部分が共通なんだ。

directは「導く・まっすぐの」。そのdi-も古いdis-の変異形だけど、ここでは動作を強める働きで、後ろの「まっすぐ整える」と合わさっている。離す、否定する、強める。同じ古い部品から違う働きが育ったんだね。つなぎ目を外し、変装し、断食をやめ、食卓を片づける。綴りと意味の変化を歌えば、変装と料理の意外な親戚関係も見えてくる！
