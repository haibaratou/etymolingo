# *sed- 座るの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

腰を下ろして「座る」、その場所に留まる。この語根は、ゲルマン語ではsitやseat、ラテン語ではsedやsid、ギリシャ語では座席をいう別の形を育てたよ。sitは座る。setは置く・据えるで、古くは座らせるという動詞の形だった。自分が腰を下ろすsitと、何かをそこへ落ち着かせるsetの兄弟関係なんだ。settingは設定・背景で、物を置くことから、舞台を用意することや周りの状態をいう意味が育った。seatは座席・議席で、座る場所の名。

saddleは鞍で、動物に乗って座るための道具をいう古いゲルマン語の名前につながる。馬や革の英語まで同根ではなく、座る道具という部分が一族なんだね。nestは巣で、「下に」と「座る」の古い組み合わせにさかのぼるという有力な説明がある。nestは古いnizdoという推定形の、後ろの座る側を受け継ぐという説明だよ。安心して腰を落ち着ける所が巣になった、という経路は推定を含むんだ。ギリシャ語の座席の名に、下へをいう別の部分が付いた言葉が、ラテン語、フランス語を経てchair、椅子になった。chairは古いkathedraの-hedra「座席」の側が、ラテン語とフランス語を通って縮まった形。

座る人の役目から、議長という意味も同じ語にいる。ラテン語の枝では、そばに座ることから相談や値ぶみをする動詞が育ち、assessmentは評価という名前になった。assessmentは古いassidereの-sid-「座る」がこの家族で、そばにの先頭は別の祖先。sizeは大きさで、フランス語の定められた量・取り決めをいう名を、冠詞との切れ目を変えて受け取った親戚。sizeは古いassiseの座る・据える枝が、短い形になった名なんだ。

soilは土。soilは古いsolium「座席」の枝が、ほかの地面をいう名の影響も受けた形だよ。ラテン語の座る場所の名が、地面をいう似た形の語と混ざり、土の名になったという複雑な経路があるよ。椅子、鞍、巣から、評価や寸法へ。直接「座る」と訳せない語にも、途中で落ち着く所や定めることの枝をたどると、古い座る動作が見えてくる！

## 歌にするフック

sitしてseat、setで座らせる。chairに腰を下ろし、saddleに座り、nestへ落ち着く。assessmentで値ぶみ、sizeを決める！

## 必ず見せる原義

- **座る**：低く腰を下ろして座面に深く落ち着く大きい体を主体にし、座る体と支える面の関係を主役にする。

## 語源の根拠

### sit

この語根は、ゲルマン語ではsitやseat、ラテン語ではsedやsid、ギリシャ語では座席をいう別の形を育てたよ。

古英語の sittan には「待ち伏せる、城を包囲する」の意味もあった。

[辞書の該当項目](https://www.etymonline.com/word/sit)

### seat

English seat ← Old Norse sæti ← Proto-Germanic *sæt- ← PIE *sed- (1).

Use the place/cushion on which one sits; not an unrelated word for the upholstery fabric.

[辞書の該当項目](https://www.etymonline.com/word/seat)

### set

setは置く・据えるで、古くは座らせるという動詞の形だった。

sit の使役形で原義は「座らせる」。14世紀から混同された。

[辞書の該当項目](https://www.etymonline.com/word/set)

### setting

settingは設定・背景で、物を置くことから、舞台を用意することや周りの状態をいう意味が育った。

1300年ごろは「食事の時刻」。「背景、環境」の意は1841年から。

[辞書の該当項目](https://www.etymonline.com/word/setting)

### saddle

English saddle ← Old English sadol ← Proto-Germanic *sathulaz, derived from PIE *sed- (1) with an instrumental suffix.

The riding saddle itself is a word motif; horse and leather are not taught as same-root words.

[辞書の該当項目](https://www.etymonline.com/word/saddle)

### nest

English nest ← Old English nest ← Proto-Germanic *nistaz ← PIE *nizdo-, probably *ni 'down' + *sed- (1) 'sit'.

The sed component is shared; the ni prefix is separate. This compound analysis is marked probable by Etymonline. Eggs illustrate nest contents; egg is not a sed word.

[辞書の該当項目](https://www.etymonline.com/word/nest)

### chair

English chair ← Old French chaiere ← Latin cathedra ← Greek kathedra (kata- + hedra); hedra ← PIE *sed- (1).

Chair's historical hedra component is the sed connection; kata- is a separate component.

[辞書の該当項目](https://www.etymonline.com/word/chair)

### assessment

ラテン語の枝では、そばに座ることから相談や値ぶみをする動詞が育ち、assessmentは評価という名前になった。

もとは課税のための土地の値ぶみ。教育で使われ出したのは1956年から。

[辞書の該当項目](https://www.etymonline.com/word/assessment)

### size

sizeは大きさで、フランス語の定められた量・取り決めをいう名を、冠詞との切れ目を変えて受け取った親戚。

フランス語 l'assise の切り分けを誤って生まれた語で、語根は「座る」。

[辞書の該当項目](https://www.etymonline.com/word/size)

### soil

soilは土。

もとはラテン語の「座席」。「地面」の語 solum と混ざって土の意に。

[辞書の該当項目](https://www.etymonline.com/word/soil)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **sed**：Latin sedere（座る）の枝。 [辞書の根拠](https://www.etymonline.com/word/sedentary)
- **sid**：assidereのような複合語で母音が変わった座る側。 [辞書の根拠](https://www.etymonline.com/word/assess)
- **nizdo**：nestへつながる推定祖形。下へ＋座るという分解は推定。 [辞書の根拠](https://www.etymonline.com/word/nest)
- **kathedra**：Greek kathedra＝kata-＋hedra。 [辞書の根拠](https://www.etymonline.com/word/chair)
- **hedra**：Greek hedra（座席）、古いsのhへの音変化を含むsedの枝。 [辞書の根拠](https://www.etymonline.com/word/chair)
- **assidere**：Latin assidere（そばに座る）。 [辞書の根拠](https://www.etymonline.com/word/assess)
- **assise**：French assiseの座る・据える枝、sizeの前段階。 [辞書の根拠](https://www.etymonline.com/word/size)
- **solium**：Latin solium（座席）、soilの経路の一部。 [辞書の根拠](https://www.etymonline.com/word/soil)
