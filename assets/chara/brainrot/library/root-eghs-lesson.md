# *eghs 外への学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

中から「外へ」、ぽんと出る！ *eghsは囲いの外へ向かう動き。ラテン語のex-に育ち、短いe-や、イタリア語を通ったes-にも姿を変えて残っているよ。

exitは出口。exitのex-が「外へ」、残りは「行く」という古い言葉につながる。「外へ＋行く」だから、出口を通って外へ進む姿がぴったり。exhaustは排気。exhaustのex-が「外へ」で、後ろは「くみ出す」というラテン語につながる。中身を出し切る感じが、気体を出すことにも、力を使い切ってくたくたになることにもつながった。eraseは消す。eraseの最初のe-はex-が短くなった形で、後ろは「こすり取る」。その仲間のeraserは消しゴム。この古い組み合わせが、紙の線を取り去る動きに残っている。

意外な仲間がespresso、エスプレッソ！ なんでコーヒーが「外へ」なの？ espressoのes-をイタリア語から遡ると、ラテン語のex-に出会う。もとの動詞はexprimere。「外へ」のex-と「押す」のpremereが組み合わさった「押し出す」だ。圧力でお湯を粉に通して、濃いコーヒーを抽出する動きを思い浮かべて。コーヒー名は「注文された一杯をその場で淹れる」という意味で付いたとも説明される。言葉の系列と、飲み物の命名の話を合わせて覚えよう。

expressionは表現や表情。expressionのex-も「外へ」で、後ろは「押す」の仲間。これも同じ「押し出す」の言葉から育った！ コーヒーを押し出すespressoと、気持ちを外へ表すexpression。材料は違うのに、言葉の家系で出会えるんだ。ここで「押す」の側は別の語根だから、次の歌でその一族を訪ねることもできるね。

elevatorはエレベーター。elevatorの最初のe-はここでは「上へ」、後ろは「持ち上げる」につながる。この言葉では上方向に働くんだ。exampleは例。exampleのex-は「外へ」、残りは「取る」というラテン語の系列。大きな集まりから一つを「外へ＋取る」、取り出したものが代表の例になった。effectは効果や結果。「外へ＋作る」の組み合わせから、やり遂げて生み出した結果へ。effectのef-は、ex-が後ろの音に合わせて変わった形で、残りが「作る」の側だよ。

evidenceは証拠。evidenceのe-はex-の短い形、後ろのvid-は「見る」。この二つが組み合わさり、「よく見えて明らか」という意味へ。ここで接頭辞は意味を強める働きもしているよ。見る側の語根をたどると、「見る・知る」の一族への道になる。experienceは経験。experienceのex-がこの仲間で、後ろは「試す」という古い言葉につながる。やってみたことから知識を得る、という経験の意味が育った。

出ていく、出し切る、こすり取る、押し出す。例も効果も証拠も、違う相方と組んで育った仲間なんだ。「外へ」という昔の小さな部分が、大きく違う英単語の中で働いている。

## 歌にするフック

exit、外へ！ exhaust、出し切る！ erase、こすってeraser！ espresso、押し出す一杯、expression、表す気持ち。elevator、上へ！ example、取り出す例。effect、作った結果、evidence、見える証拠、experience、試して覚えた経験！

## 必ず見せる原義

- **外へ**：大きい閉じた胴殻から内側の体節が外へ飛び出す構造を主役にし、内外の境界と脱出方向を見せる。

## なるべく取り入れるモチーフ候補

以下は解説に登場する学習語と、造形へ取り入れるときの指針です。すべてを一体のキャラに描く必要はありません。

- **exit（出口）**：出口の開口と厚い扉枠を胴殻に融合し、体節がそこをくぐって出る。
- **exhaust（排気）**：体内から外へ出る排気の立体的な流れと排気口を連結する。
- **eraser（消しゴム）**：消しゴムの厚い塊を底面の擦る足へ融合し、こすったものが体外へ離れる動きを示す。
- **espresso（エスプレッソ）**：濃いコーヒー色の芯と金色のクレマを、開いた胴から外へせり出す体の一部にする。圧力をかける小さな金属器官から粉へお湯が通り、コーヒーが体外へ抽出される造形を選んでもよい。独立したカップを置くだけにしない。
- **elevator（エレベーター）**：厚いエレベーター扉、上下に伸びる支持骨格、持ち上がる内部の台を体に融合する。閉じた内側から上へせり出す体節として、上昇する働きが分かる形にする。
- **erase（消す）**：体の表面の線をこすり取り、削れた印が外へ離れる動きとして示す。消しゴムの部位と同じ機構として併用できる。
- **expression（表現・表情）**：体内の気持ちが色や表情として表面へ現れる顔の切り替え器官などにする。固定の点目笑顔に統一しない。
- **example（例）**：同種の小さな体節の集まりから代表の一片を取り出す機構。囲いから出す原義とまとめて表せる。
- **effect（効果・結果）**：体内の働きが外側に具体的な変化を作る仕掛け。結果がはっきり見える一部位として選べる。
- **evidence（証拠）**：内部の痕跡を透明窓やせり出す標本として示し、見れば分かる証拠を体に組み込む。見る語根への橋にもなる。
- **experience（経験）**：試した痕跡が体に積み重なる色のある体節など、経験して変化した状態を見せる。

## 語源の根拠

### exit

Latin exitus / exire = ex- + ire → ex- < PIE *eghs-。

共有部分は ex-。出口の扉は現代名詞 exit の意味を描く。door の語源は同根と主張しない。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=exit)

### exhaust

Latin exhaurire = ex- + haurire。ex- < PIE *eghs-。

共有部分は ex-。排気ガスと連結した排気口で現代の排気を描く。pipe は同根と主張しない。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=exhaust)

### eraser

eraser ← erase ← Latin eradere = ex- + radere。ex- < PIE *eghs-。

共有部分は erase の歴史的 e-/ex-。rubber 等の素材名は同根と主張しない。

[辞書の該当項目](https://ahdictionary.com/word/search.html?q=erase)

### espresso

English espresso ← Italian (caffè) espresso（esprimere「押し出す」の過去分詞）← Latin exprimere = ex-「外へ」＋premere「押す」。ex- ← PIE *eghs（変異形*eks）。

この祖語につながるのはex-/es-の側。premereは別語根。AHDは「押し出す」という経路、MWはコーヒー名をおそらく「注文ごとにその場で淹れる」と説明する。単に「速い」からとは断定しない。コーヒーとクレマは現在の飲み物を示し、cupを同語根とは教えない。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=espresso)

### elevator

English elevator ← elevate（持ち上げる）← Latin elevare = e-（ex-の形、ここでは「上へ」）＋levare「持ち上げる」。ex- ← PIE *eghs。

共有するのは歴史的なe-/ex-。持ち上げるlevareは別語根。この複合語で接頭辞は上方向の働きを持つため、「エレベーター＝外へ出る装置」と単純化しない。扉やケーブルは現代の意味を可視化する部位。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=elevate)

### erase

erase ← Latin eradere = e-/ex-「外へ」＋radere「こすり取る」。ex- ← PIE *eghs。

消す動作の基になるe-/ex-を共有。eraserはeraseから作った道具名で、同じ系列として紹介する。

[辞書の該当項目](https://ahdictionary.com/word/search.html?q=erase)

### expression

expression ← Latin expressio / expressionem ← exprimere = ex-＋premere「押す」。ex- ← PIE *eghs。

「押し出す」の動作名から、気持ちを表すことや表情へ。espressoと共通のexprimereの系列。意味変化を心の中のものが外に表れるイメージで覚える。

[辞書の該当項目](https://www.etymonline.com/word/expression)

### example

example ← Old French example ← Latin exemplum ← eximere = ex-「外へ」＋emere「取る」。ex- ← PIE *eghs。

全体から取り出したものが代表例へ。example全体がeghsの単独派生という意味ではなく、共有するのはex-。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=example)

### effect

effect ← Old French ← Latin effectus ← efficere = ex-＋facere「作る」。ex- ← PIE *eghs。

ex-のxが後続のfに寄ってeff-になる歴史的同化。やり遂げる・生み出すことから結果へ。結果という現代語義を機械的に「外」と直訳しない。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=effect)

### evidence

evidence ← Old French ← Latin evidentia ← evidens = e-/ex-＋videre「見る」。ex- ← PIE *eghs、videre ← *weid-。

ex-はここで意味を強める働きも持つ。よく見えて明らかなことから証拠へ。「外から見る」だけと断定しない。

[辞書の該当項目](https://www.etymonline.com/word/evidence)

### experience

experience ← Old French ← Latin experientia ← experiri「試す」。experiri = ex-＋試す語幹（PIE *per-3）。ex- ← PIE *eghs。

共有部分はex-。試して知るというラテン語の意味から経験へ。「外へ旅をする」が歴史的な直訳とはしない。

[辞書の該当項目](https://www.ahdictionary.com/word/search.html?q=experience)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- ***eghs**：「外へ」の祖語。変異形*eksを経てLatin ex-につながる。 [辞書の根拠](https://www.ahdictionary.com/word/indoeurop.html)
- **ex-**：祖語の「外へ」がLatinの接頭辞として残る形。別の動作を表す語と組み合わさる。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=ex-)
- **e-**：Latin ex-の短い形。eraseとelevateの経路に現れ、elevateでは「上へ」の働き。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=elevate)
- **es-**：espressoのItalian esprimereに現れる、Latin ex-由来の形。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=espresso)
- **exprimere**：Latin ex-「外へ」＋premere「押す」。「押し出す」を表し、Italian espressoの経路にある。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=espresso)
- **premere**：Latinの「押す」。この部分はeghsとは別語根であり、espressoを構成する相方。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=espresso)
- **ef-**：ex-が「作る」のfacereの頭の音に同化した形。effectの歴史形efficereではef-＋ficere。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=effect)
- **vid-**：evidenceのvid-は「見る」のLatin videreに由来する部分。eghs由来のe-/ex-とは別のweid語根。 [辞書の根拠](https://www.ahdictionary.com/word/search.html?q=evident)

- [American Heritage: eghs and Latin ex-](https://www.ahdictionary.com/word/indoeurop.html)：eghs「外へ」の変異形*eksからLatin ex-/exにつながる。premereは別のper-4側に掲載。
- [American Heritage: espresso, ex- + premere](https://www.ahdictionary.com/word/search.html?q=espresso)：Italian espresso / esprimereからLatin exprimere、ex-＋premereの経路と、圧力で粉にお湯を通す定義を確認。
- [Merriam-Webster: espresso word history](https://www.merriam-webster.com/dictionary/espresso)：コーヒー名について、おそらく注文に応じてその場で作る一杯という説明。押し出す経路と区別して命名のニュアンスを記す。
- [American Heritage: elevate, e- + levare](https://www.ahdictionary.com/word/search.html?q=elevate)：Latin elevareをe-/ex-「上へ」＋levare「持ち上げる」に分解。elevatorの上昇する働きを説明。
