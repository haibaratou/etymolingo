# *(s)teu-1 押すの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

この祖先の原義は「押す」。力を加える、突き出る、打つといった感覚の枝があり、ゲルマン語派とラテン語・ギリシャ語を経た語がデータベースで一族として整理されている。stock は株、在庫、家畜の群れなど意味が多い語だ。古い入口には幹や切り株、突き出したかたまりの感覚がある。そこから元になるもの・たくわえへ意味が広がった。livestock の stock がこの側で、全体なら飼っている家畜。生きているもののたくわえ、という組み合わせから、牛などの群れを表す。

ラテン語の枝には、熱心に力を注ぐことを表す語があり、study、勉強する・調べるへつながる。student は学ぶ人、studied はよく考えた・意図して準備したという意味でも使われる。study には、力を注ぐ・努める感覚の道がある。study の stud- は、熱心な努力を表すラテン語の studium の姿を受け継いでいる。知りたいことへ力を注ぐ場面から、学ぶ・調べる意味へ進んだ。身体の力が心の努力へ広がるところに、学ぶことと古い動作の橋がある。

ギリシャ語側では、打って付けた跡や形を表す枝が英語の type になる。印を押した形から、印刷の活字、型、種類へ進んだ。typical は典型的な、atypical は典型とは違う。atypical の a- が否定で、typ- の側が打ってできた形の一族だ。prototype は試作品・原型。proto- は最初で、type の側が形なので、最初の型という組み立てになる。押して形を付け、型をつくり、違う形を試す。その後で熱心に調べる学び手が出てくる。stock はもとになる幹やたくわえへ、study は力を注ぐ努力へ、type は打ってできた形へ、それぞれ道を進んだ。student が新しいやり方を調べ、prototype を試す。typical ならよくある型、atypical ならそこから外れる。物に力を加える感覚は、形の跡だけでなく、熱心に考えて取り組むことにもつながっている。

## 歌にするフック

stock にたくわえ livestock が集まる。study に力を注ぎ student が学ぶ。studied な準備で type を押そう。typical の型、atypical の違い、prototype で最初の形！

## 必ず見せる原義

- **押す**：押す側と押される側、その力の方向を、身体の最大の構造や動きで読めるようにする。
