# *wer-3 回すの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

向きをくるっと「回す」、ぎゅっとねじる。ゲルマン語とラテン語で別々の形を育てた語根だよ。ゲルマン語の枝には、ねじれる動きや形をいう仲間がいる。wrenchはレンチ。名のもとにある動詞はねじる・ひねるだから、ボルトを回す道具の役目とつながる。wristは手首で、回る関節の名が古いねじる一族へつながる。wreathはリース、花輪で、ねじって巻き合わせた輪をいう枝。wormはミミズなどの虫で、うねる姿の名を回す語根につなげる伝統的な説明がある。

wrongは間違っただけど、もとの意味はねじれた・曲がった。まっすぐでない形が、正しくないことの意味へ移ったんだ。worryは心配するで、古い英語ではのどを絞めることをいう動詞。苦しめることから、心を悩ませる意味が育った。語源を思い出すための話で、心配すれば首が本当にねじれるということではないよ。方向をいうforwardは前方へで、前をいう別の部分と、向きを変える古い-wardが組み合わさっている。forwardの-wardが向きをいう側で、fore-「前に」は別の家族。

ラテン語では、回す動詞がversの形を英語へ残した。versionは版・解釈で、言葉を別の言語へ向け直す、翻訳の意味を経た名前だ。diversityは多様性で、いろいろな方向へ向いていることから違いの多さをいう言葉へ。diversityのversが回す側で、離れる先頭とは別の語根。universeは宇宙。universeの-versが同じ回す側で、一つをいう先頭は別の家族だよ。前半が一つ、後半が回す側で、「一つにまとまって向いた全体」という古い名なんだ。

レンチ、手首、花輪、ミミズ、版、宇宙。語の綴りはねじれて見えても、ゲルマン語のwr-とラテン語のvers-という枝を結べば、同じ回す動きが見えてくる！

## 歌にするフック

wrenchを回し、wristをひねる。wreathを巻き、wormがうねる。wrongの曲がり、versionで向き替え、universeをひとつにまとめる！

## 語源の根拠

### wrench

Old English wrencan → *wrankjan → *wreng-/*werg- → *wer- (2); tool noun from wrench.

wrenchはレンチ。

[辞書の該当項目](https://www.etymonline.com/word/wrench)

### wrist

Old English wrist → *wristiz → *wreik- → *wer- (2).

Hands support the wrist depiction, rather than constituting another learning word.

[辞書の該当項目](https://www.etymonline.com/word/wrist)

### wreath

Old English wræth → Germanic *writh- → *wreit- → *wer- (2).

Leaves illustrate the wreath, not a claimed same-root leaf word.

[辞書の該当項目](https://www.etymonline.com/word/wreath)

### worm

Old English wyrm → Germanic *wurmiz → *wrmi-, connected by Watkins to *wer- (2).

The modern earthworm sense is depicted; worm's wider old senses are not extra motifs.

[辞書の該当項目](https://www.etymonline.com/word/worm)

### wrong

wrongは間違っただけど、もとの意味はねじれた・曲がった。

原義は「ねじれた」。「まっすぐ」の right とちょうど逆。

[辞書の該当項目](https://www.etymonline.com/word/wrong)

### worry

worryは心配するで、古い英語ではのどを絞めることをいう動詞。

古英語では「絞め殺す」。心を悩ませる意味になったのは1822年。

[辞書の該当項目](https://www.etymonline.com/word/worry)

### forward

方向をいうforwardは前方へで、前をいう別の部分と、向きを変える古い-wardが組み合わさっている。

メールを「転送する」の用法は、1757年の手紙の転送から続いている。

[辞書の該当項目](https://www.etymonline.com/word/forward)

### version

versionは版・解釈で、言葉を別の言語へ向け直す、翻訳の意味を経た名前だ。

ラテン語の「回す」から。言葉を回して移すのが翻訳、そして「版」へ。

[辞書の該当項目](https://www.etymonline.com/word/version)

### diversity

diversityは多様性で、いろいろな方向へ向いていることから違いの多さをいう言葉へ。

かつては「ひねくれ、邪悪」の意もあった。今は正反対の言葉。

[辞書の該当項目](https://www.etymonline.com/word/diversity)

### universe

Latin universum/universus = unus + vertere; vertere derives from *wer- (2).

Only the vertere/vers- component shares this root; uni- belongs to *oi-no-.

[辞書の該当項目](https://www.etymonline.com/word/universe)
