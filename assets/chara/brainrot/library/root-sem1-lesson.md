語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

「一つ・一緒に」、そして同じ。この語根では、一つにまとまることと同じ側にいることが、近い感覚だったんだ。ゲルマン語の枝から来たsomeは、いくつかの・ある～。最初からたくさんをいうだけの語ではなく、ある一つや、はっきり決めない量をいう働きが育った。someoneは誰かで、someに一人をいう別の言葉がくっついた名前。someoneのsome-がこの一族で、一人をいう後ろは別の祖先。sometimesは時々で、不定の時をいう組み合わせだから、毎回ではない時を表す。sometimesのsome-も同じ側で、時をいう後ろは別の語根。

sameは同じ。古い英語にも親戚がいたけれど、今の形の広がりには北欧の言葉の影響があると考えられているよ。ラテン語の枝にはsim-やsing-という顔がいる。similarは似ているで、一つの側にあるような近さが、似た性質の意味へつながる。sameはぴったり同じ、similarは似ているけれど違いもある、と使い分けてみよう。singleは一つだけの・独身の。ここでは一つをいう古い形が残り、音楽のシングル盤にも使う。simpleは簡単な。simpleのsim-が一つ、折る後ろの部分は別の家族。もとのラテン語の組み合わせは「一重の」で、前半が一つ、後半は折ることをいう別の語源。

重なりが少ない形から、複雑でないという意味が育ったんだ。simplyは簡単にで、simpleからできた副詞。assembleは集める・組み立てるで、ラテン語の同じ・似たをいう形から、共に寄せる動詞の枝が育った。assembleは古いassimulareのsim-が同じ・似たの側で、先頭の近づける側は別の祖先。部品がまとまって一つになる現代の意味で覚えられるね。someの不定の一つ、singleのたった一つ、sameの同じ、similarの似た、simpleの一重。

英語の意味が全部同じというわけではなく、古い一つ・共にという感覚が、違う使い方に育った親戚。同じか、よく似ているか、一つだけか。今の意味を比べると、古い「一つ」が分かれて育った道も見えてくるね！

## 歌にするフック

someのある一つ、someoneの誰か。sameは同じ、similarは似てる。singleは一つ、simpleは一重。assembleで一つにまとめよう！

## 必ず見せる原義

- **一つ・一緒に**：一枚の大きい体が一回だけ折れて一つの胴へまとまる構造を主体にし、単一性と一体化を見せる。

## 語源の根拠

### some

ゲルマン語の枝から来たsomeは、いくつかの・ある～。

語根は「一つ」。「ある一つの、ある不定の量」が出発点。

[辞書の該当項目](https://www.etymonline.com/word/some)

### someone

someoneは誰かで、someに一人をいう別の言葉がくっついた名前。

もとは some one と二語だった。一語で書かれ出すのは19世紀半ば。

[辞書の該当項目](https://www.etymonline.com/word/someone)

### sometimes

sometimesは時々で、不定の時をいう組み合わせだから、毎回ではない時を表す。

語末の s は複数ではなく、副詞をつくる古い属格の名残。

[辞書の該当項目](https://www.etymonline.com/word/sometimes)

### same

Germanic *samaz / PIE *samos → *sem- (1).

Paired identical design illustrates same. Not oi-no- one-family.

[辞書の該当項目](https://www.etymonline.com/word/same)

### similar

Latin similis from Old Latin semol → *sem- (1).

Similar parts deliberately not exact duplicates, distinguishing similar from same.

[辞書の該当項目](https://www.etymonline.com/word/similar)

### single

Latin singulus → *semgolo- → *sem- (1).

Verified single n. music-record sense; depicts one music single, not uni- or oi-no-.

[辞書の該当項目](https://www.etymonline.com/word/single)

### simple

Latin simplex = *sem- (one) + -plic- (fold).

Only sim-/sem- shares the root; fold component is different. Single fold reflects literal ancestor, simple construction modern meaning.

[辞書の該当項目](https://www.etymonline.com/word/simple)

### simply

simplyは簡単にで、simpleからできた副詞。

強意の「まったく」は simple の「部分が無い、丸ごと」の意から。

[辞書の該当項目](https://www.etymonline.com/word/simply)

### assemble

Latin assimulare = ad- + simulare from similis → *sem- (1).

Only sim-/simul- shares the root. Blocks illustrate modern assembling, block is not a claimed cognate.

[辞書の該当項目](https://www.etymonline.com/word/assemble)
