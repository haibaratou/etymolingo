## 共有する学習解説

ぐるりと「周囲に」、両側から囲む。この語根の家族は、ゲルマン語ではbyやbe-、ラテン語ではambi-、ギリシャ語ではamphi-という顔で英語に集まったよ。byはそばに・～によって。周りや近くにいる小さな語が、位置だけでなく行為の方法や行う人をいう働きも育てた。aboutは周りに・～についてで、古い英語の前置詞と、このbyの仲間、外側をいう別の部分が合わさって縮んだ形。aboutは古いbeの側がbyにつながり、外をいう側とは別の語根だよ。

話題の周りをめぐることが、そのことについて話す意味にもなるんだ。beforeは～の前にで、前をいう別の語源の前に、このbe-が付いている。betweenは～の間にで、二つずつをいう別の一族とbe-の組み合わせ。becauseはなぜならで、もとは「その理由によって」という二語だった。becomeは～になるで、この先頭部分には古くから動作を強める働きもある。becomeのbe-が、その強める働きの側。だから、どの語でも今の「周り」と直訳するわけではないよ。

ギリシャ語のamphibianは両生類。amphibianのamphi-が両側で、命をいう後ろは別の家族。前半が両側、後半が命なので、二つの環境に関わる生活をいう名前だ。amphitheaterは円形劇場で、まわりから見る劇場という組み合わせ。amphitheaterのamphi-も周囲で、劇場の部分は別の語根。ラテン語のambidextrousは両手利きの。ambidextrousのambi-が両側で、右をいう後ろとは別の祖先。もとの名は「両方が右手の」で、右手のように巧みに使えることをいった。

ambulanceは救急車だけど、古い名は歩く・移動する病院。ambulanceは古いambulareのamb-を、周りのambi-に結びつける説だよ。古い動詞の細かな分け方には推定もあるけれど、周りを歩くという枝を経て、動く病院から人を運ぶ車へ変わったんだ。両側の手、池と陸、囲んだ客席、動く救急車。周囲と両側の古い感覚が、途中の言語で違う姿になって英語に戻ってきた一族なんだね！

## 歌にするフック

byでそばに、aboutでぐるり。before、between、周りの位置。両手はambidextrous、両生類はamphibian、囲んで見るamphitheater！

## 語源の根拠

### by

この語根の家族は、ゲルマン語ではbyやbe-、ラテン語ではambi-、ギリシャ語ではamphi-という顔で英語に集まったよ。

語根は「まわり」。OED はこの前置詞に38もの語義を立てている。

[辞書の該当項目](https://www.etymonline.com/word/by)

### about

Old English abutan = on + be/bȳ + utan; bȳ → *ambhi-.

Only the be/by component shares the root. Arrow illustrates around, not a same-root arrow noun.

[辞書の該当項目](https://www.etymonline.com/word/about)

### before

beforeは～の前にで、前をいう別の語源の前に、このbe-が付いている。

中身は by +「前から」。帆船の before the mast は下級船員の暮らし。

[辞書の該当項目](https://www.etymonline.com/word/before)

### between

betweenは～の間にで、二つずつをいう別の一族とbe-の組み合わせ。

中身は by +「二つずつ」。二つのあいだ、が文字どおりの意味。

[辞書の該当項目](https://www.etymonline.com/word/between)

### because

becauseはなぜならで、もとは「その理由によって」という二語だった。

もとは by cause「その理由で」の二語。くっついて一語に。

[辞書の該当項目](https://www.etymonline.com/word/because)

### become

becomeは～になるで、この先頭部分には古くから動作を強める働きもある。

もとは「起こる」。What has become of it? に古い意味が残る。

[辞書の該当項目](https://www.etymonline.com/word/become)

### amphibian

Greek amphibios = amphi- + bios; amphi- → *ambhi-.

Only amphi- shares this root; bios is *gwei-. Frog is a modern class example, not a claimed same-root frog word.

[辞書の該当項目](https://www.etymonline.com/word/amphibian)

### amphitheater

Greek amphitheatron = amphi- + theatron; amphi- → *ambhi-.

Only amphi- shares this root; theater is a different component.

[辞書の該当項目](https://www.etymonline.com/word/amphitheater)

### ambidextrous

Latin ambidexter = ambi- + dexter; ambi- → *ambhi-.

Only ambi- shares this root; dexter is *deks-. Hands illustrate modern meaning.

[辞書の該当項目](https://www.etymonline.com/word/ambidextrous)

### ambulance

French (hôpital) ambulant ← Latin ambulare, perhaps ambi- + a verb of going; ambi- ← *ambhi-.

移動する病院から輸送車へ。ambulareの内部構造とPIE接続には推定を含む。

[辞書の該当項目](https://www.etymonline.com/word/ambulance)
