# *sterə- 広げるの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

原義は「広げる」。地面にものを敷き広げたり、順番に並べたりする動作から、ラテン語では積み上げる・組み立てる枝が育った。street は通りや街路。近い祖先は敷きならした道を表すラテン語の語で、石などを並べて通れるようにする場面がある。自然に生えた小道というだけでなく、地面に敷いてつくった道の歴史を持つ。道の上に家や店が建っても、まずは足元に広げた層から始まる一族なのだ。

structure は構造、construct は建設する・組み立てる、construction は建設や組み立て。ラテン語の積み上げる動詞の系譜から来た語で、struct- の部分がその姿を残す。construct の con- は共に・まとめてで、材料をまとめて組み立てる感覚になる。レンガを一個持つだけでは建物にはならない。どう並べ、どう重ねるかが構造を決める。橋の骨組みや体の中の組み合わせも、構造という現在の意味を見せる材料になる。広げることが、ただ平たくするだけでなく、組み上がった立体にもつながるのがこの枝の面白さだ。

instruct は教える、instruction は指示や教え。in- が中へを添え、積み上げる側と組み合わさったラテン語の動詞が、備える・教えるという意味へ育った。必要なものを整えて備える感覚が、知識を備えさせる、教える意味へ広がった。instrument は道具や楽器で、必要な働きができるよう備えたものの枝。destroy は壊すこと、destruction は破壊。同じ積み上げる側の祖先に、反対の向きが加わって解体する意味になる。敷く、積む、備える、教える、ばらす。street には石が敷かれ、construction では材料が積まれる。組み上がった structure が支え、instrument は必要な仕事をする。instruction を受け取れば、人は次のやり方を備えられる。destroy では組み合わせがほどかれ、destruction で全体が崩れる。広げた層から立つ構造へ、構造から働く仕組みへ、この一族はものの並び方を何度も変えてきた。

## 歌にするフック

street に敷いて construct、construction が立ち上がる。structure が支え instruct が教える。instruction を受け instrument が働く。destroy で崩れる destruction、また並べて組み直そう。

## 必ず見せる原義

- **広げる**：広がっていく方向と広げられる面・部分を、身体の最大の構造や動きで読めるようにする。
