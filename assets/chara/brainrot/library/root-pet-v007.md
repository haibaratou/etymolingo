DATABASE ROOT FOUNDATION (use meaning, never write text in art): 急ぐこと、または、飛ぶことをあらあわす。pen(1)などの由来として、羽根。petə-とも表記。
勢いよく飛びかかる、突き進む、そして何かを求めて向かっていく、という感覚が芯にある。英語への道はラテン語経由が45語で最も太く、求めて行くという意味の動詞を通って、競う語や願い出る語になった。ギリシャ語経由の32語は翼の意味を担っていて、helicopter(ヘリコプター)の切れ目は heli-copter ではなく helico-pter、つまり「らせん」と「翼」である。pen(ペン)の原義はずばり羽根で、鳥の羽軸で書いていた時代の名残、appetite(食欲)も同じ根から出て、何かに向かって手を伸ばすことを言った。急ぐことと飛ぶことと欲しがることが、ここでは一続きになっている。
Current teaching explanation: 急ぐ動きは、飛んで向かい、勢いよく求める動きにもなる。feather（羽）は古英語から来た枝で、飛ぶ体の羽を表す。pen（ペン）はラテン語の羽を表す言葉がフランス語を通ったもの。鳥の羽を筆記に使ったから、羽の名前が書く道具になったんだ。ゲルマン語の羽と、ラテン語を通ったペンが、同じ祖先の飛ぶ枝を分け合っている。

helicopter（ヘリコプター）の-pterは、ギリシャ語の翼の成分。前のhelico-は別のらせんの枝で、翼の-pterを合わせるとらせんの翼という名前になる。羽で飛ぶことと、回る翼で飛ぶことが、同じ翼の言葉を分け合っているんだね。

ラテン語の別の枝ではpetereが「向かう・求める」。petition（願い出・署名の請願）は、求めることを表す言葉になった。appetite（食欲）の-pet-もその求める成分で、何かへ向かって手を伸ばす意味が、食べたい気持ちへ広がった。食べ物そのものがこの語根なのではなく、欲しくてぐいっと向かう体の動きがつながっているよ。

compete（競う）の-pet-は一緒に求める古い組み合わせから来た。competition（競争）にも同じ-pet-が見えるので、同じ目標へ向かう人たちが競争する意味が分かる。repeat（繰り返す）はラテン語で再び求める言葉から、フランス語を通った形で、-peatに古いpetereの音が変わって残る。羽で飛んで向かうこと、欲しいものを求めて向かうこと、もう一度同じところへ向かうこと。急いで進む動きが、羽の名前と、求める気持ちの名前へ分かれた一族なんだね。
