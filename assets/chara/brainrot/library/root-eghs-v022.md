DATABASE DEFINITION: 外に、外への意味を表す印欧語根。接頭辞ex-（effort,except,expectなど）の由来として「…の外へ」「…から離れて」の意。接頭辞extra-（extraditeなど）の由来として「外側に」の意。他の重要な派生語は、exotic,strange,extremeなど。
DATABASE COMMENTARY: 囲いの内側から外へ出る動き。そこから、取り出す・現れる・やり遂げるという意味が枝分かれした。英語に来た道は400語がロマンス語派で、そのほとんどが ex-(外へ)という一つの顔をしている。example はもともと全体から取り出した一片のことで、その頭が落ちた形が sample、同じ語から二つの単語が生まれた。極めつきは escape で、原義は「マントを脱ぎ捨てる」、追っ手に上着だけ残して外へ抜けるのが、この語根らしい逃げ方だった。
