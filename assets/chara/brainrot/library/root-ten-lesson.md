# *ten- 伸ばすの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

ぴんと「伸ばす」。伸ばしたまま張って、しっかり持ちこたえる。この語根の二つの動きは、ラテン語で伸ばす動詞と保つ動詞の枝に分かれ、英語にtendやtainの姿を残したよ。tentはテント。張り伸ばしたものをいうラテン語の形が、布を張る住まいの名になった。attentionは注意で、「相手へ伸ばす」という組み合わせ。attentionのtenが伸ばす側で、at-「～へ」は別の祖先だよ。心を相手の方へ伸ばすと、注意を向ける感覚が見えるね。

extentは範囲で、外へ広げた広がりをいう枝から来た。extentの-tentが伸ばす側で、外への部品は別の語根。物を保つほうの枝にはcontainer、容器がいる。containerの-tain-が、古いtenere「保つ」の側。一緒に中へ保持する動詞から、入れておく道具の名前ができたんだ。contentは内容で、同じように中に保持されたもの。contentの-tentも保つ側で、前半の共には別の語根。満足したという意味もあり、手持ちに気持ちが収まる感覚でつながる。

maintainは維持するで、ラテン語の「手で持つ」をいう組み合わせからフランス語を経た。maintainの-tainが保つ側、手をいう前半とは別の祖先。obtainは得るだけど、古い動詞はしっかり持つ・保つという意味だよ。obtainの-tainも保つ側だよ。tennisはテニス。tennisは古いtenez「受け取って」のten-を受け継ぐという説なんだ。フランス語の「受け取って」という、持つ動詞の呼びかけに由来する有力な説がある。

球を相手へ渡す声が競技名になった、という面白い経路だけれど、唯一の確定説とは言い切らないんだ。ギリシャ語の枝ではtone、音色・調子が生まれた。もとの意味は張ること。張った弦が音を出すから、伸ばすことが音につながったんだね。ゲルマン語のthinは薄いで、伸ばす語根に結びつく。伸びた形が薄くなるイメージで覚えられる。布、容器、弦、手持ちのもの。伸ばして張ることと、手元に保ち続けることが、一つの古い語根から広がったんだ！

## 歌にするフック

tentを張ってtoneを鳴らす。attentionを伸ばし、extentを広げる。containerで保ち、maintainで握る。tennisの呼び声、受け取って！

## 必ず見せる原義

- **伸ばす**：大きな伸縮胴が両端から引かれて長くなり、張力を保つ姿勢を主体にする。

## 語源の根拠

### tent

French tente ← Latin tenta/tentus ← tendere ← PIE *ten-

張られたキャンプ用テントそのもの。数字tenは別語根で除外。

[辞書の該当項目](https://www.etymonline.com/word/tent)

### attention

attentionは注意で、「相手へ伸ばす」という組み合わせ。

字義は「〜へ伸ばすこと」。注意とは心を対象のほうへ伸ばすことだった。

[辞書の該当項目](https://www.etymonline.com/word/attention)

### extent

extentは範囲で、外へ広げた広がりをいう枝から来た。

1300年ごろは土地の課税評価額のこと。「程度」の意は1590年代。

[辞書の該当項目](https://www.etymonline.com/word/extent)

### container

container ← contain ← Latin continere ← con- + tenere ← PIE *ten-

con-は別語根。物が入る容器を描く。

[辞書の該当項目](https://www.etymonline.com/word/container)

### content

contentは内容で、同じように中に保持されたもの。

原義は「中に収まる」。欲が手持ちに収まるから「満足した」の意も出た。

[辞書の該当項目](https://www.etymonline.com/word/content)

### maintain

maintainは維持するで、ラテン語の「手で持つ」をいう組み合わせからフランス語を経た。

ラテン語 manu tenere「手で持つ」から。握り続けるのが維持。

[辞書の該当項目](https://www.etymonline.com/word/maintain)

### obtain

obtainは得るだけど、古い動詞はしっかり持つ・保つという意味だよ。

ラテン語では「しっかり持ち続ける」。持ちこたえた末に手に入る。

[辞書の該当項目](https://www.etymonline.com/word/obtain)

### tennis

Anglo-French tenetz ← French tenez/tenir ← Latin tenere ← PIE *ten-

Etymonlineはサービス時のtenez説をmost likelyとし、古い辞書の異論も記載する。現在の有力説として扱う。racket/ballの語源を同根としない。

[辞書の該当項目](https://www.etymonline.com/word/tennis)

### tone

Latin tonus ← Greek tonos/teinein ← PIE *ten-

張られた弦や振動する弦で音を表す。guitarやharpを同根としない。

[辞書の該当項目](https://www.etymonline.com/word/tone)

### thin

ゲルマン語のthinは薄いで、伸ばす語根に結びつく。

語根は「引き伸ばす」。引っぱって延ばせば薄くなる、という発想。

[辞書の該当項目](https://www.etymonline.com/word/thin)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **tend**：Latin tendere（伸ばす）の枝に残るtend。 [辞書の根拠](https://www.etymonline.com/word/tent)
- **tain**：Latin tenere（保つ）がフランス語を経て-tain-となる枝。 [辞書の根拠](https://www.etymonline.com/word/contain)
- **ten**：Latin tendere/tenereの語幹の一部。 [辞書の根拠](https://www.etymonline.com/word/tent)
- **at**：Latin ad-から同化したat-（～へ）はattentionの別語根側。 [辞書の根拠](https://www.etymonline.com/word/attention)
- **tenere**：Latin tenere（保つ）。 [辞書の根拠](https://www.etymonline.com/word/contain)
- **tenez**：French tenez（受け取って）、tennisの有力語源説。 [辞書の根拠](https://www.etymonline.com/word/tennis)
