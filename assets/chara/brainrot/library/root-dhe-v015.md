# デー・ファクトリー / root-dhe-v015

3語の意味を造形で表すねんどろいど体型のワイルドワード。探索候補・未採用。

## 造形
工場と事務所を動かす顔のある機械の監督。

## 原義
置く

## モチーフ
- factory（工場）：工場建物・製造設備で現代意味を描く。設備の個別名まで同根とは主張しない。
- office（オフィス）：共有部分は officium の facere 部分。事務机が見える業務用建物で現代意味を示す。
- face（顔）：faciesはfacereの一族とされるが、Etymonlineは関連を留保付きで説明する。確定した直接派生とは断定しない。

## 共有解説
ものを「置く」、しっかり据える。そこから、何かをする・作るという大きな一族が育ったよ。ゲルマン語にいるdoは「する」で、古い置く動作が広がった言葉。deedは行いで、置かれた・行われたことを指す仲間だ。見た目が全然違うラテン語にはfacere、作るという動詞がいる。もとの子音の変化や語の作り方が違うため、英語ではdoとfac-の形が並んでいるんだ。factは事実だけど、昔の名前は「行われたこと」。factoryは工場で、作る人や作る場所をいう言葉から育った。

officeはオフィス・職務。officeは古いofficiumのficが、facere「作る」の側。古い組み合わせの後半が「作る・行う」で、仕事を行う役目から働く場所の名へ広がったよ。effectは効果で、もとは「作り出されたこと」。effectの-fect-も、作る動詞が複合語の中で変わった形だよ。specificは特定のという意味で、種類を「作る」側の部分がこの根に参加している。specificの-fic-が、facere「作る」の側。

顔をいうfaceにも、ラテン語の姿・見た目という言葉がある。これを「作る」一族へ結びつける伝統的な説をこのデータベースは採っているけれど、直接の結びつきには留保があるんだ。その顔の上にある面、surfaceは表面で、同じ顔・面の言葉を使った別の組み合わせ。surfaceの-faceが顔・面の枝で、sur-「上に」は別の祖先。顔を作ったからという作り話ではなく、昔の「形・見た目」が今の顔や面へ狭まったという話だよ。さらにギリシャ語にはtheme、テーマがいる。もとの意味は「置かれたもの」、話し合うために据えた題がテーマになった。

作業をする、工場で作る、話の題を置く。原義の置く手つきから言語の枝をたどれば、行動と物作りと考える題が一つの家族に見えてくる！
