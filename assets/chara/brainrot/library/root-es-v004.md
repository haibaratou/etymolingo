## 共有解説
この語根の意味は「存在する」。ものすごく古く、ものすごく小さな「ある・〜である」が、今の英語にも生きている。is と am は、相手や主語に合わせて形を変える「〜である」の動詞の仲間だ。現在の英語では一つの動詞の形を習うけれど、その活用には歴史の違う祖先の形も合流している。ここでは同じ祖先につながる is と am に注目する。いること、あること、何かであることを、毎日の短い文で支えている。

ラテン語では esse が「ある」。present はラテン語の praesens「前にいる」の形から、目の前にいる・今のという意味へ進んだ。語末の sent の側に、esse の「ある」が分詞の形で残っている。presence はそこにいること、存在感。absent は不在の。ab- が離れてで、sent の側は存在の分詞形なので、そこから離れているという組み合わせだ。目の前の人の姿から、いまという時間や、部屋に感じる気配まで広がる。essence は本質で、ess- がラテン語の「ある」の側。essential は本質的な・欠かせない。ラテン語で「あること・本質」を表す枝から、あるものをそのものにしている重要な性質へつながった。存在という難しい言葉も、「ここにいる」「これがないと困る」と具体的な場面から入れる。

possible は可能な、impossible は不可能な。possible の poss- はラテン語の posse「できる」の姿を受け継ぐ。この動詞は「力ある」と esse「ある」の組み合わせなので、語の中に存在の祖先がいる。impossible の im- が否定を添えるので、この一族に属するのは可能性を支える「ある」の側。interest は興味や関心、また利子。ラテン語の interest は「間にある・重要である」という動詞形で、最後の est が「ある」の側。その関わりの感覚が利益や関心へ広がったが、利益への細かな意味の道には分からないところも残る。yes は古い英語の gese を経た肯定で、後半の si が「そうあれ」という存在の願いの形だと説明される。先頭の「そう」と、あるを願う側が組み合わさった。is と am は日々の短い文で存在を伝える。present ならそこにいて、absent なら離れている。possible なら起こりうるし、impossible ならできない。essence はそのものらしさの本質、interest は自分との関わり。あることを伝え、ありうることを考え、そうあってほしいと肯定する。小さな「ある」が、存在と可能性を支えている。
