# *ure 後ろにの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

原義は「後ろに」。いったん進んでから後ろへ戻ると、同じことを「再び」できる。この二つを受け持つラテン語のre-が、英語へ大勢の仲間を連れてきたよ。さらに古い祖語の形には別説があるけれど、歴史的なre-を共有する関係は追えるんだ。returnは「戻る」で、re-が「後ろへ」、後ろの回す言葉と合わさって向きを戻す。rememberは「覚えている・思い出す」。そのre-は「再び」の側で、心に留める言葉と合わさり、思い起こすことを表した。

recordは記録や音楽レコード。そのre-は「戻して」で、後ろはラテン語の「心臓」。もとの意味は「心へ戻す、思い出す」だった。昔は心臓を記憶の宿る場所と見ていたんだね。responseは返答。そのre-は「返して」で、もとは相手の誓いへ誓いを返すこと。reportは報告で、re-「後ろへ」に「運ぶ」が合わさり、知らせを持ち帰ることだった。refereeは審判。そのre-を含む「話を持ち戻して判断を仰ぐ」動詞から、判断を任せられる人の名になったよ。

researchは研究で、re-には「再び・念入りに」の働きがあり、後ろは「探す」。resultは結果。そのre-は「後ろへ」で、後ろの「跳ぶ」と合わさった古い動詞は「跳ね返る」。働きかけて戻ってきたものが結果、と覚えるとつながるね。refrigeratorは冷蔵庫。そのre-には動作を強める働きがあり、後ろの「冷たくする」というラテン語の枝と合わさっている。全部を機械的に「もう一度」と訳すわけではないんだ。

restaurantはレストラン！　そのre-も「元へ戻す」側の古い動詞から来たけれど、最初から店を指したわけではない。体を元気に戻す食べ物、特に滋養のあるスープを指す呼び名から、食事をする店の名になった。戻る体、戻る知らせ、戻る思い出。どの語も後ろの部分まで同じ祖先ではないけれど、re-の働きをたどると、一枚のレコードから報告、研究、食事へ歌をつなげられる！

## 歌にするフック

returnで戻り、rememberで思い出す。recordへ心、reportへ知らせ。responseを返し、researchでもう一度。restaurantで元気を戻そう！

## 必ず見せる原義

- **後ろに**：前へ伸びた体が大きく折り返し、頭と動力の向きが自分の後端へ戻る折返し姿勢を主体にする。

## 語源の根拠

### return

returnは戻るで、向きをもう一度回す組み合わせ。

re-「後ろへ」+ turn「回る」で、もとは向きを変えることだった。

[辞書の該当項目](https://www.etymonline.com/word/return)

### remember

rememberは覚えている・思い出すで、記憶をもう一度心に置く感覚がある。

re(再び)+memor(心にとめる)で「もう一度心に置く」。

[辞書の該当項目](https://www.etymonline.com/word/remember)

### record

record noun ← record verb ← Latin recordari＝re-＋cor（heart）。

共有部分はre-。cor（heart）側は別語源。共有するre-のPIE遡及は、現行DBの*ureを保持。Etymonlineには*wret/*wert説もあり、単一の確定説として断定しない。

[辞書の該当項目](https://www.etymonline.com/word/record)

### response

responseは返答で、もとは相手の誓いへ誓いを返すこと。

re(返して)+spondere(誓う)。答えるとは誓いを返すことだった。

[辞書の該当項目](https://www.etymonline.com/word/response)

### report

reportは報告で、知らせを後ろへ運んで持ち帰ることだった。

原義は「後ろへ運ぶ」。当初は人が運んでくる噂話のことも指した。

[辞書の該当項目](https://www.etymonline.com/word/report)

### referee

referee ← refer ← Latin referre＝re-（back）＋ferre（carry）。

共有部分はre-。縞の服はrefereeの人物役割を示す識別で、服の別名称まで同根とはしない。共有するre-のPIE遡及は、現行DBの*ureを保持。Etymonlineには*wret/*wert説もあり、単一の確定説として断定しない。

[辞書の該当項目](https://www.etymonline.com/word/referee)

### research

researchは研究。

re-「再び」+ search。念入りに「探し直す」ことが原義。

[辞書の該当項目](https://www.etymonline.com/word/research)

### result

resultは結果だけど、古い動詞の中身は「跳ね返る」。

原義は「跳ね返ってくる」。「跳ぶ」の語根から「結果」の意に。

[辞書の該当項目](https://www.etymonline.com/word/result)

### refrigerator

refrigerator ← refrigerate ← Latin refrigerare＝re-＋frigerare（make cool）。

共有部分はre-。frigerare側は別語源。共有するre-のPIE遡及は、現行DBの*ureを保持。Etymonlineには*wret/*wert説もあり、単一の確定説として断定しない。

[辞書の該当項目](https://www.etymonline.com/word/refrigerator)

### restaurant

French restaurant ← restaurer ← Latin restaurare＝re-＋staurare。

共有部分はre-。食べ物単体ではなく店の入口・店内を描く。共有するre-のPIE遡及は、現行DBの*ureを保持。Etymonlineには*wret/*wert説もあり、単一の確定説として断定しない。

[辞書の該当項目](https://www.etymonline.com/word/restaurant)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **re**：Latin re-（後ろへ・再び）。PIEの最終形には複数説あり。 [辞書の根拠](https://www.etymonline.com/word/re-)

- [American Heritage: re-](https://ahdictionary.com/word/indoeurop.html)：re-/red-はラテン語の結合形。さらに古い復元形wret/wertへの経路はconceivablyとされるため、PIE段階を確定説として扱わない。DBのureラベルは保持。
