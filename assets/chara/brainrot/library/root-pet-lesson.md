# *pet- 急ぐの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

急ぐ動きは、飛んで向かい、勢いよく求める動きにもなる。feather（羽）は古英語から来た枝で、飛ぶ体の羽を表す。pen（ペン）はラテン語の羽を表す言葉がフランス語を通ったもの。鳥の羽を筆記に使ったから、羽の名前が書く道具になったんだ。ゲルマン語の羽と、ラテン語を通ったペンが、同じ祖先の飛ぶ枝を分け合っている。

helicopter（ヘリコプター）の-pterは、ギリシャ語の翼の成分。前のhelico-は別のらせんの枝で、翼の-pterを合わせるとらせんの翼という名前になる。羽で飛ぶことと、回る翼で飛ぶことが、同じ翼の言葉を分け合っているんだね。

ラテン語の別の枝ではpetereが「向かう・求める」。petition（願い出・署名の請願）は、求めることを表す言葉になった。appetite（食欲）の-pet-もその求める成分で、何かへ向かって手を伸ばす意味が、食べたい気持ちへ広がった。食べ物そのものがこの語根なのではなく、欲しくてぐいっと向かう体の動きがつながっているよ。

compete（競う）の-pet-は一緒に求める古い組み合わせから来た。competition（競争）にも同じ-pet-が見えるので、同じ目標へ向かう人たちが競争する意味が分かる。repeat（繰り返す）はラテン語で再び求める言葉から、フランス語を通った形で、-peatに古いpetereの音が変わって残る。羽で飛んで向かうこと、欲しいものを求めて向かうこと、もう一度同じところへ向かうこと。急いで進む動きが、羽の名前と、求める気持ちの名前へ分かれた一族なんだね。

## 歌にするフック

featherで飛び、penで書く。helicopterは翼で進む。petitionで願い、appetiteで求め、compete・competitionで同じ目標へ。repeatはもう一度求める！

## 必ず見せる原義

- **急ぐ**：勢いよく急いで進む姿を、最大の姿勢や移動の構造で読めるようにする。

以下は解説に登場する学習語と、造形へ取り入れるときの指針です。すべてを一体のキャラに描く必要はありません。

- **feather（羽毛が生える）**：立体の羽が腕と尾そのものを構成。
- **pen（ペン）**：羽軸がそのまま筆記用ペンの尖った脚と口へ連続する。動物の囲いの意味は使わない。
- **helicopter（ヘリコプター）**：回転翼と乗り物の胴が頭と腹に融合し、急いで飛ぶ主構造へつなげる。
- **appetite（食欲）**：欲しいものへ伸びる口と肢を、語根の「急ぐ」が読める主構造へつながる立体の部位や動きとして融合する。
- **petition（請願）**：望みを示して差し出す腕を、語根の「急ぐ」が読める主構造へつながる立体の部位や動きとして融合する。
- **compete（競う）**：同じ目標へ並んで急ぐ二本の脚を、語根の「急ぐ」が読める主構造へつながる立体の部位や動きとして融合する。
- **competition（競争）**：一つの目標を囲んで向かう複数の肢を、語根の「急ぐ」が読める主構造へつながる立体の部位や動きとして融合する。
- **repeat（繰り返す）**：同じ目標へ再び戻る翼を、語根の「急ぐ」が読める主構造へつながる立体の部位や動きとして融合する。
