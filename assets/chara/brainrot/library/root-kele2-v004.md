## 共有解説
この一族の原義は「叫ぶ」。大声は遠くの人を呼び、知らせを伝え、みんなを集めるためにも使われた。ラテン語の叫ぶ動詞の枝から claim、主張する・権利を求めるという語が来る。自分の言い分を声に出す姿が入口だ。acclaim は大きな賛辞や歓迎。ac- は相手へ向かう要素が音の形を変えたもので、叫ぶ側が claim とつながる。exclaim は思わず叫ぶこと、ex- が外へを添える。歓声も驚きの声も、違う気持ちを大声で表している。

clear は澄んだ、はっきりした。近い祖先のラテン語には、明るいだけでなく、はっきり聞こえる・響くという意味もあった。clarity は明瞭さ。水が澄むことと説明が分かりやすいことが、一つの語の中に並んでいる。declare は宣言する・明らかにする、declaration は宣言。この二つの clar- の側は、はっきりする枝に属する。「叫ぶ」の祖先が、声の大きさだけでなく、聞こえやすさ、さらに見えやすさ・分かりやすさまで広がったのがおもしろい。透明な窓やよく通る声は、別々の「はっきり」を表せる。

calendar にも声の歴史がある。calendar の cal- の側には、ラテン語で呼ぶことを表す枝の姿が残る。ローマで月の最初の日を告げる呼びかけの系譜から、日付の表や暦へつながった。紙の数字を見ているのに、祖先には「日を告げる声」がいるのだ。class は、ラテン語で呼び集めた人々の組や区分を表す枝から来た。学校のクラスは今の使い方で、呼びかけて人をまとめる感覚はもっと古い。classroom の class がその側で、部屋を表す後ろの語は別の一族だ。日付を告げ、人を集め、声をはっきり届ける。calendar で新しい日を知り、class の仲間が集まる。classroom では先生の声が聞こえ、はっきりした説明なら clear、分かりやすさは clarity。試合では acclaim の歓声、驚いた時には exclaim。権利を claim し、決まったことを declare する。声は日付、人の集まり、喜び、自分の言い分を運び、やがて明らかなことの名前にもなった。
