## 共有する学習解説

この語根の意味は「輝く」。明るい空、昼、天の神へも広がった一族だ。ラテン語では dies が日を表し、その枝から diary、日記が来る。毎日の出来事を残すので、日を数える歴史が名前に入っている。dial は時計の文字盤や目盛り盤。近い祖先には日々のことを表すラテン語の形があり、日時計の盤から、様々な計器の目盛りへ広がった。光る空を見て一日を知る場面が、日記と時計をつなぐ。

フランス語ではラテン語の日の語が jour へ変わった。journal の jour- がこの日の側で、日々の記録や日刊の紙面を指す。journalist はその報道を書く人。journey もこの日の枝から来ていて、昔は一日の移動や一日の仕事を表した。それが旅の長さ全般へ広がったので、今日の旅が何日あっても使える。一日歩き、その日を記し、日々の知らせを届ける。日記、旅、報道は今は別の話題でも、毎日の時間が共通の道になっている。journey の距離は一日分から長い旅全般へ、journal の記録は日々の出来事へ広がった。日を数える言葉は、歩く長さと書く記録の両方を受け持っている。

神の枝には deity、神格や神、divine、神の・神聖な、がある。ラテン語で神を表す語から英語に入った。Zeus はギリシャ神話の空の神の名、Jupiter はローマの神の名で、後者には空の神と父を合わせた歴史がある。星の名としての木星は、この神の名前を受け継いだ使い方だ。Tuesday は火曜日で、先頭の Tues- が古いゲルマン語の神の名の形につながる。神の名の側がこの一族で、曜日を表す後半は別の祖先を持つ。明るい空から一日、日々の記録、神の名へ伸びた道が見える。diary には今日の出来事、dial には時間の目盛り、journal には日々の知らせ。旅する journey も、始まりには一日という長さがいた。神の名は Zeus や Jupiter、曜日の神名は Tuesday に残る。明るい空を見上げた祖先の言葉が、日を記す暮らしと空の神の名前へ、それぞれ伸びていった。

## 歌にするフック

diary に今日を書き dial で時を読む。journey を進み journal に記し journalist が届ける。deity と divine の空、Zeus と Jupiter が輝く。Tuesday の名にも、その空の一族。

## 必ず見せる原義

- **輝く**：明るく輝く空・昼の原義を、身体の最大の光や明るさの構造で読めるようにする。
