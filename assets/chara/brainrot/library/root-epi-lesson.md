# *epi 近くにの学習解説

語根ごとに共有する解説の初稿。原義は必ず造形に表し、派生語のモチーフはなるべく取り入れます。以前の画像との一致を示す文章ではありません。

## 共有する学習解説

何かの「近くに」、その相手へ向き合う。印欧祖語のこの一族は、ラテン語でob-、ギリシャ語でepi-という形を育てたよ。ラテン語の枝には、前へ出す、ぶつかる、行く手にあるという感覚がいる。ob-は次の音に合わせてop-やof-にも変わるから、綴りが違っても同じ先頭部分のことがあるんだ。opponentは対戦相手で、「向かいに置かれた者」。opponentのop-が、向かってをいうob-の変わった形だよ。oppositeは反対側のだから、向かい合わせの同じ兄弟だ。oppositeのop-も同じ側で、置く後ろとは別の語根。

obstacleは障害物で、前に立って進みを止める物。obstacleのob-が前へ、後ろが立つ別の家族なんだ。立つ側の語根は別だけど、向かってくる先頭の意味が共通している。objectは物体・対象、そして反対するという動詞でも使う。objectのob-が前へ、後ろが投げる側だよ。もとの組み合わせは「前に投げ出す」で、目の前のものにも、相手へ突きつける反論にもなった。offerは提供する。offerのof-が相手へをいう側で、運ぶ後ろとは別の祖先。

相手の方へ運んで差し出す動詞から来た親戚だよ。observeは観察する・守るで、対象へ注意を向けて見守る古い動詞へつながる。observeのob-が対象へをいう側なんだ。obviousは明らかな。obviousのob-が前に、後ろは道の別の語根。古い名は「行く手にある」。通り道にあるから見逃しにくい、という発想なんだ。occurは起こる・思い浮かぶで、もとはこちらへ走って出会うこと。occurのoc-が、相手へ向かうob-の変わった形だよ。

opportunityは機会。opportunityのop-が向かっての側で、港をいう後ろとは別の祖先。古い名には「港に向かって」という組み合わせがあり、港へ進むのに都合のよい状態から、よい機会の意味が育った。ギリシャ語の枝のepisodeは番組の一回・エピソード。昔の劇で合唱の間へ役者が入って来る場面を指し、何かへ加えて入るepi-が働いている。相手、障害物、差し出すもの、港、劇の入り場。向き合う小さな部分が、出会いにも対決にも物語の一回にもなるんだ！

## 歌にするフック

向かいにopponent、行く手にobstacle。objectを見てobserve、offerを相手へ差し出す。港へopportunity、劇へ加わるepisode！

## 必ず見せる原義

- **近くに**：二つの大きい正面が至近距離で向き合う対向胴を主体にする。互いの距離の近さと正面衝突の関係を見せる。

## 語源の根拠

### opponent

Latin opponentem/opponere ← ob- + ponere; ob- ← PIE *epi/*opi

向かい合う表情や対戦用グローブで描く。glove/boxは同根ではない。

[辞書の該当項目](https://www.etymonline.com/word/opponent)

### opposite

oppositeは反対側のだから、向かい合わせの同じ兄弟だ。

「向かいに置かれた」が原義。ラテン語 ponere「置く」から。

[辞書の該当項目](https://www.etymonline.com/word/opposite)

### obstacle

Latin obstaculum/obstare ← ob- + stare; ob- ← PIE *epi/*opi

障害物のバー・ハードルで描く。bar/hurdleは同根ではない。

[辞書の該当項目](https://www.etymonline.com/word/obstacle)

### object

objectは物体・対象、そして反対するという動詞でも使う。

「前に投げ出されたもの」が原義。だから「反対する」の意味も持つ。

[辞書の該当項目](https://www.etymonline.com/word/object)

### offer

offerは提供する。

古英語ではまず「いけにえを捧げる」。商売の意味は1630年代から。

[辞書の該当項目](https://www.etymonline.com/word/offer)

### observe

Latin observare ← ob- + servare; ob- ← PIE *epi/*opi

大きな目が近くの対象をじっと見ている形でobserveを描く。eyeという語は同根ではない。servareも別語根*ser- (1)。

[辞書の該当項目](https://www.etymonline.com/word/observe)

### obvious

obviousは明らかな。

ラテン語で「道の前に立ちはだかる」。行く手にあるから、目に入る。

[辞書の該当項目](https://www.etymonline.com/word/obvious)

### occur

occurは起こる・思い浮かぶで、もとはこちらへ走って出会うこと。

原義は「走って出会う」。出来事のほうから来る、が発想の元。

[辞書の該当項目](https://www.etymonline.com/word/occur)

### opportunity

opportunityは機会。

ラテン語で「港に向かってくる」。追い風が吹く時が好機だった。

[辞書の該当項目](https://www.etymonline.com/word/opportunity)

### episode

Greek epeisodion ← epi- + eisodos; epi- ← PIE *epi/*opi

連続するTVコマで番組の一回を表す。TVは同根ではない。

[辞書の該当項目](https://www.etymonline.com/word/episode)


## 同じ語根につながる形と音

接頭辞・祖語形・音の説明用の項目で、すべてを画像に描く必須モチーフではありません。

- **ob**：Latin ob-（向かって）。 [辞書の根拠](https://www.etymonline.com/word/ob-)
- **epi**：Greek epi-（上に・加えて）、epi/opiの枝。 [辞書の根拠](https://www.etymonline.com/word/epi-)
- **op**：ob-がpの前でop-へ同化。 [辞書の根拠](https://www.etymonline.com/word/opponent)
- **of**：ob-がfの前でof-へ同化。単独英語ofをこの根の語として扱う意味ではない。 [辞書の根拠](https://www.etymonline.com/word/offer)
- **oc**：ob-がk音の前でoc-へ同化。 [辞書の根拠](https://www.etymonline.com/word/occur)
